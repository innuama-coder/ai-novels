# 固定页面风格契约

## 用途

- ID：`editorial-review-desk-v1`
- 名称：编辑部审阅台
- 唯一用途：十分钟小说构思评审

页面是决策工具，不是宣传页、数据仪表盘、小说阅读器或创作编辑器。

页首信息层级固定为：作品名是唯一主标题；“小说构思人审报告”是文档类型；
一句故事身份是副标题。不得把故事梗概、run id 或文件名放入 `<h1>`。

## 固定视觉语言

采用纸质编辑审稿台的克制感：

- 纸白背景 `#F7F3EA`
- 深墨正文 `#18202A`
- 次级文字 `#5E6873`
- 功能蓝 `#2457A7`
- 提问琥珀 `#A65A00`
- 卡片白 `#FFFDF8`
- 分隔线 `#D7D0C3`

禁止渐变、装饰性大图、外部字体、自动动画和主题随机化。

## 固定信息图形

- 总链：先以 SVG 从左到右显示
  “世界观命题 → 世界规则 → 事件环境 → 故事架构 → 人物选择 → 终局契约”，
  每个节点只保留主张与对下一层的推导；下方控制卡显示控制对象和解释边界。
- 世界：以 SVG 系统因果链显示规则间的传递关系，再以 SVG 环境承载图并列显示
  环境特征、故事职责与状态变化；精确权限、资源和危险保留在后续文字卡中。
- 故事：以一张 SVG 合并八阶段因果链和主线/支线/背景线泳道，阶段节点必须显示
  压力、选择和代价；精确后果与新状态保留在后续时间线卡中。
- 人物：以核心人物居中、关系人物向外扩展的 SVG 网络显示全体人物。关系连线
  必须按层级区分并带编号，编号与下方“初态—变化—终态”关系摘要一一对应。
- 片段：连续长文阅读，不使用标签页或轮播。

每个世界系统、环境、故事线、阶段、人物和关系默认先显示一句
`control_summary`。完整运行参数使用原生 `<details>` 渐进展开；主要事件控制链、
硬边界、开放接口和控制总链不得折叠。

图形只负责加快比较，不得替代文字。颜色不能是区分类别的唯一线索。
机器来源 ID 不得作为主视图中的人物名、故事线名或关系对象名称。
每张 SVG 必须有 `role="img"`、`<title>`、`<desc>` 和 `aria-labelledby`；
窄屏允许图内横向滚动，但不得造成页面级横向滚动。

## 固定排版

- 系统字体，正文至少 16px；
- 长文目标行长不超过约 66 个拉丁字符的等价宽度；
- 正文行高至少 1.5，片段行高约 1.9；
- 大屏双列，窄屏单列重排；
- 明确 `h1 → h2 → h3` 层级；
- 可见键盘焦点与跳过导航链接；
- 提供打印媒体样式和减少动态媒体查询。

## 固定交互边界

作者判断由四组未预选单选项和意见框组成。页面只能复制或下载
`status: draft` 的非权威草稿；不得通过网络提交，不得把草稿升级为正式批准。
