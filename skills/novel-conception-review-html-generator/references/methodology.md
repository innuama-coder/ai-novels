# 方法论

## 1. 从评审任务反推页面

页面唯一成功指标是作者在十分钟内判断构思是否符合意图。信息架构因此采用
“故事身份 → 世界承载 → 因果发展 → 人物选择 → 阅读证据 → 分项判断”，而不是按机器包目录展示。

GOV.UK 与 USWDS 都强调从真实用户需要出发、做不可再少的核心并保持一致。
因此页面没有营销 hero、设置面板或自由主题，只有评审所需内容。

## 2. 完整展开优于交互探索

十分钟评审要求可扫描、可回看和可打印。世界、故事、人物、片段与判断全部处于
默认阅读路径；折叠只容纳追溯哈希。这样避免作者因标签状态漏读关键内容。

## 3. 文字与图形承担不同职责

图形表达关系和顺序：

- 世界图用于比较规则系统与承载环境；
- 多线泳道用于看各故事线在哪些阶段行动或交汇，时间线用于看压力、选择、后果、
  代价和新状态；
- 人物关系网络和分层关系图用于看关系对象、职责及其变化。

精确事实仍以可选择、可复制、可被辅助技术读取的文字呈现。视觉信息不能只靠颜色。

## 4. 排版服务于持续阅读

USWDS 建议正文至少约 16px，长文行长通常 45–90 个字符、约 66 个字符为良好目标，
长文行高至少 1.5。页面据此限制片段宽度、增大片段行高、使用留白形成分组，并避免大段粗体或全大写。

## 5. 语义结构服务于快速定位

W3C 建议用 header/nav/main/section/footer、逻辑标题与标注区域支持屏幕阅读器、
键盘和阅读模式。页面提供 skip link、唯一 h1、顺序 h2/h3 和可描述的 form。

## 6. 适配不是缩小

WCAG Reflow 要求多数正文在等效 320 CSS px 下无需二维滚动。双列卡片在窄屏改为
单列；关系层和事实表也垂直化。时间关系仍保留编号与文字，不依赖横向画布。

## 7. 决策控件不制造结论

显式 label 扩大控件可点击范围并让辅助技术获得名称。四个板块的 approve/revise
均保持未选；本地复制只生成 `status: draft`，确保页面不会把“生成成功”偷换为“作者批准”。

## 8. 离线与注入安全

所有内容均来自创作输入，必须视为不可信文本并做上下文适配的 HTML 转义。
页面不引入外部资源，CSP 作为附加防线限制加载；不用 inline handler、`innerHTML`、
`eval` 或远程提交。嵌入 JSON 还额外转义 `<`。

## 9. 验收采用双重确定性

结构检查只能证明页面“像”正确。技能同时：

1. 反解析嵌入 JSON 并与权威输入完全比较；
2. 用当前模板重新渲染并要求 HTML 字节完全相同。

这使内容遗漏、改写、模板漂移和手工修补都成为硬失败。
