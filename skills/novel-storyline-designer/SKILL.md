# novel-storyline-designer

## Responsibility

Design proposal-level storylines.

## Output

| Field | Requirement |
|---|---|
| Storyline list | Main, secondary, hidden, emotional, thematic as needed |
| Each line | Question, start state, change direction, end state |
| Intersections | High-level relationship between lines |
| Constraint trace | Intake constraints and open questions used |

## Boundary

- Do not write scenes, chapters, or event-by-event plot.
- Do not solve PRD trunk causality.
- Do not create storylines that require violating `AVOID-*`.

## Acceptance

Each storyline must have a dramatic question and direction, but remain above scene level.
