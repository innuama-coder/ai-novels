# 小说构思评审片段 SOP

## A. 准入

1. 运行 `manage_writing.py begin`，重验 R1 与人审 plan。
2. 确认 slot 数量、用途、评审问题、POV、前后状态、长度和六类覆盖目标。
3. 确认每个 slot 的 required/allowed source、unit、control、禁写事实和叙述约束。
4. 任一要求只能靠新增设定实现时，停止并报告冲突。

## B. 场景契约

1. 用一句话写 POV 人物的即时意图。
2. 写清妨碍该意图的当下压力和世界规则。
3. 确定一个由行动或揭示形成的转折。
4. 让人物作选择；选择不能由旁人、巧合或系统替代。
5. 写出片段内可见的直接后果和后状态。
6. 指定允许/禁止的感官或信息通道。
7. 只从 brief 的 creative freedom 选择局部动作、物件、对话节奏或意象。

## C. 初稿

1. 从正在发生的动作、交互或环境变化进入，不先解释背景。
2. 在前两段内给出足够的谁/在哪里/正在做什么。
3. 让世界信息通过限制、资源、权限、失败或物件用途出现。
4. 让对白带有即时目的；无对白时，让沉默、选择和环境反馈承担互动。
5. 把 brief 的关键压力、选择、关系变化写成现场，不用概述。
6. 结尾落在后果或新状态上，不用主题句、预告句或作者判断。

## D. 三遍修订

### 1. 因果遍

- 标出压力、转折、选择、后果；
- 删除不能改变状态或加强必要压力的段落；
- 确认结尾由人物选择和世界规则共同造成。

### 2. POV 与权威遍

- 逐句标记信息来源；
- 删除跳头、未授权感官和全知解释；
- 把人物推断与事实区分；
- 将所有局部发明记录为 creative choice；
- 新增权威事实必须为零。

### 3. 语言遍

- 朗读对白与叙述；
- 删除重复说明、机械套语、情绪标签、形容词堆叠和无功能比喻；
- 用动作节拍、停顿和注意力变化组织段落；
- 确认固定文风七原则全部可从页面举证。

## E. 证据审计

对每个 required audit key：

1. 写一句具体 finding；
2. 从最终文本复制最短充分引文；
3. 确认引文直接支持 finding；
4. 不重复同一引文冒充所有维度；
5. 无法举证则重写片段。

随后完成 brief compliance：

1. 绑定最终文本哈希；
2. 分别为 brief 前状态和后状态提供正文证据；
3. 为每项 required fact 提供独立 finding 与正文引文；
4. 逐项确认 prohibited fact 未进入正文并说明检查理由；
5. 无法证明时重写片段，不把 `contract_checks: true` 当作替代。

## F. 交付

1. 三阶段按顺序提交，不能跳过或覆盖旧 evidence。
2. 运行 `finalize_fragments.py`；它只从最终 audit 生成包，不改写文本。
3. 运行 `validate_fragments.py`。
4. `ready` 后把整个 package 交给报告组装技能。
