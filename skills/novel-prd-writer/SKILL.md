# novel-prd-writer

This legacy skill is retired. It must not be used to generate new proposal or PRD documents.

## Required Redirect

For new work:

1. Use `novel-intake-workflow` to produce or confirm the intake brief.
2. Use `novel-proposal-workflow` to produce the proposal after intake is ready.
3. Use the future `novel-prd-workflow` only after proposal acceptance and PRD scope selection.

## Allowed Use

- Identify old PRD material that predates the current workflow.
- Mark legacy PRD content as non-frozen reference.
- Explain why legacy PRD content cannot bypass intake, proposal, accepted storyline, storyline quality evaluation, or human confirmation gates.

## Forbidden

- Do not write a new proposal.
- Do not write a new PRD.
- Do not reuse the old PRD schema as a current proposal or PRD template.
- Do not treat old PRD/HLD/LLD/writing content as intake constraints.
- Do not bypass `novel-proposal-workflow`, accepted storyline, or storyline quality references.

## Acceptance

The only acceptable output is a short quarantine note that names the legacy source, states that it is non-frozen, and points the task back to the current workflow.
