## 1. 研究结论

角色访谈不是收集最多事实，而是建立足以预测关键选择、又允许开发发挥的最小模型：

1. 欲望必须进入冲突；抽象愿望要落到可失去的具体事物。
2. 行动需要主观理由；责任、恐惧、依赖、身份和价值可同时推动人。
3. 过去只在作用于当前信念、策略、关系或选择时进入设计。
4. 一致性不是单调；有根源和触发条件的矛盾可信，无前提反转是作者操控。
5. 人物弧不强制成长；正向、负向、平直、混合和有限变化均可成立。
6. 开放提问负责发现，候选负责比较，确认点决定什么进入规范，始终保留作者控制。

## 2. 角色决策模型

```text
故事位置与外部压力
        ↓
个人欲望、恐惧与价值排序
        ↓
形成经历 → 主观解释 → 自我/世界信念
        ↓
默认保护策略与关系策略
        ↓
压力下的选择、代价与后果
        ↓
更新、固守、崩解或重新解释
```

分开记录事实、解释、策略、行为与变化。“Want / Need / Lie / Truth / Ghost”只作诊断，不是强制字段；平直弧、非人或群体角色未必符合传统“谎言—真相”模型。

## 3. 相关性与分级

拟新增信息至少影响以下一项：关键选择、冲突/代价、关系权力/依赖/误读、变化边界、注意/解释/表达。否则不进入核心设计。

角色分级看因果功能，不看戏份。核心角色完整建模；关键关系角色围绕其影响建模；功能角色只记录任务和边界。这样既避免工具人无逻辑，也避免每个路人都有冗长档案。

## 4. 提问和候选

采用“开放 → 聚焦 → 反例 → 候选 → 确认”：

1. 作者直觉是什么？
2. 它具体影响哪个选择？
3. 什么情况下角色不会照常行动？
4. 作者卡住时，给最多三个机制不同的方案。
5. 作者确认、修改、暂定或授权哪一个？

有效问题问行为与边界，例如：“职责与这段关系只能保一个时，他第一反应保护什么？”“哪次经历让这个策略曾经有效？”“什么证据仍不足以改变他？”

候选不是性格菜单，每个都写成：`重视什么 → 如何解释威胁 → 默认策略 → 获得什么 → 付出什么`。说明谁更可能被牺牲、什么会隐瞒、何种关系会破裂或哪类压力会失效。

未知须拆分：作者未决定；角色不知道；角色知道但隐瞒；作者知道但读者暂不知。只有第一类可能阻塞角色设计，后两类还要交因果或叙述技能处理。

## 5. 形成、矛盾与变化

不要从当前特征倒推方便的悲剧。验证过去事实是否支持该解释、为何形成此解释、策略曾如何保护角色、当前为何产生成本。长期照顾、制度奖励、成功经验、榜样、文化义务或匮乏都可成为来源。

可信矛盾来自同一根源的两面。例如“高度负责”在可控压力下是可靠，在失控压力下可能变成替别人决定。记录触发与反例，避免随机变脸。

变化契约包含起点、反复检验的压力、阈值选择、结果和不变量。平直弧可让角色坚持价值并改变环境；负向弧可让策略更有效而代价更不可逆。

## 6. 关系与非人角色

关系对双方分别记录认知、欲求、依赖/权力、债务、误读、不说之事、背叛边界和修复条件。“兄妹”“同事”等标签只有在改变资源、责任、许可或选择时才有意义。

非人角色先定义外部输入、连续经验、价值更新、能力边界、主观缺失和身份连续性。分开记忆来源与当下解释、身份主张与可证事实。不能因使用语言就默认完整人类身体经验，也不能因非人就否定其主体性。

## 7. 审计

| 审计 | 通过条件 |
| --- | --- |
| 相关性 | 每项细节影响选择、冲突、关系、变化或表达。 |
| 因果性 | 经历、解释、策略和当前行为有可复述链接。 |
| 可预测性 | 给定典型压力，可预测默认行为和例外。 |
| 非机械性 | 多重动机、情境和反例允许可信变化。 |
| 关系双向 | 关键关系双方有自己的理解、欲求和边界。 |
| 变化可验 | 有起点、检验、阈值、结果和不变量。 |
| 可区分性 | 核心角色的注意、归因和表达机制不互换。 |
| 权威清晰 | 确认、授权、暂定、推断与未知没有混写。 |
| 边界合规 | 未偷写事件、POV、披露顺序、场景或正文。 |

## 8. 参考资料

1. [Purdue OWL — Writing Compelling Characters](https://owl.purdue.edu/owl/subject_specific_writing/creative_writing/writers/fiction-basics/writing_compelling_characters.html)：目标、冲突和多重动机连接人物与情节。
2. [OpenLearn — Creating characters](https://www.open.edu/openlearn/history-the-arts/creative-writing/start-writing-fiction/content-section-1.1/?tip=linktip)：人物与困境可生成情节，避免角色被既定情节强推。
3. [Reedsy — Character Questionnaire](https://reedsy.com/blog/character-questionnaire/)：欲望、动机、过去和一致行为是问答核心。
4. [Writers.com — Character Development](https://writers.com/character-development-definition)：人物弧是角色适应冲突的内在旅程。
5. [CharacterChat](https://arxiv.org/abs/2106.12314)：渐进引导、开放对话、候选回复和用户选择可共同维持创作者控制。
6. [IPOCL](https://arxiv.org/abs/1401.3841)：行动需要可归属的角色目标和意图解释。
7. [K. M. Weiland — Truth Chart](https://www.helpingwritersbecomeauthors.com/figure-out-your-characters-arc/)：Want、Need、Lie、Truth、Ghost 可作诊断，但答案应有机形成。
8. [Writer’s Digest — Push Characters to Their Limits](https://www.writersdigest.com/write-better-fiction/how-to-push-your-characters-to-their-limits)：矛盾须有内在根源，不能只作噱头。
9. [Jane Friedman — Showing or Telling](https://janefriedman.com/showing-or-telling-how-to-decide-based-on-line-level-scene-level-and-story-level/)：背景只有与当前旅程和人物弧相关时才值得展开。
10. [NY Book Editors — Consistent Character Voice](https://nybookeditors.com/2015/11/character-development-how-to-create-a-consistent-voice/)：声音来自世界过滤与思维方式，不只是措辞。
11. [Writers.com — What Does Your Character Want?](https://writers.com/story-writing-exercise-what-does-your-character-want)：具体欲望为冲突和行动提供持续骨架。
12. [Reedsy — Create Conflict](https://reedsy.com/blog/create-conflict-in-a-story/)：欲望、阻碍、后果、改变要求和其他角色共同外化冲突。
13. [Writer’s Digest — Hiding and Confronting the Past](https://www.writersdigest.com/write-better-fiction/5-reasons-for-characters-to-hide-and-then-confront-their-past)：过去的揭露应服务当前选择，避免信息倾倒。
