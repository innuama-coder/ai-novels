# HR1 Design Brief

HR1 projects the admitted narrative, storyline, character and information architectures into macro story time, discourse order, duration/density, space transition, synchronization, pacing, tension, recovery and continuity controls. It preserves upstream causality and world facts; it does not invent routes, mechanisms, events or scene-level timing. Success is a coherent, public-Harness-ready control model consumable by HK1.

The agent owns semantic alternatives and evidence. The shared design-stage runtime owns admission, read closure, HDD handling and deterministic packaging.
