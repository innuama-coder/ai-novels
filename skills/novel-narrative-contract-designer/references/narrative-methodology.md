# 小说叙述契约：方法论与落地规则

本文件回答“怎样把叙事学和小说写作建议转换成开发者可执行的契约”。它不规定某一种 POV 或风格优于其他选择；每项选择必须服务已确认的故事承诺、主体因果和读者体验。

## 2. 从方法论得到的核心模型

### 2.1 五个位置必须分开

| 位置 | 要回答的问题 | 常见混淆 |
| --- | --- | --- |
| 作者 | 哪些事实与效果被设计？ | 不得让作者直接进入正文解释人物或主题。 |
| 叙述者 | 谁在组织和说出文本，是否属于故事世界？ | 叙述者不等于作者，也不必等于聚焦者。 |
| 聚焦者 | 当前信息受谁的感知、注意、认知和价值过滤？ | “第三人称”没有回答谁在感知。 |
| 角色 | 在该因果节点实际知道、相信、隐瞒什么？ | 角色知识由因果架构锁定，不能为悬念随意删减。 |
| 读者 | 此刻能确认、怀疑、误判或尚不知道什么？ | 读者信息不必等于角色信息，但差异必须有合法通道。 |

任何叙述规则都应能转写为：

```text
在什么叙事单元 → 由谁说/谁聚焦 → 可访问哪些来源 → 读者得到什么认识 → 哪些信息仍被何种边界阻挡
```

### 2.2 信息不是单一“揭晓时间”

为每个关键事实分别登记：

1. **故事事实成立**：事实在因果世界中何时为真；由因果架构决定。
2. **角色获知**：谁在何节点知道、误信、怀疑或隐瞒；若改变选择，必须来自因果架构。
3. **叙述可访问**：当前叙述者/聚焦者是否有合法来源。
4. **读者状态**：读者是确认、合理怀疑、产生受控误判，还是尚无从得知。
5. **披露功能**：该变化使读者重新解释什么，或提高哪项期待与代价。
6. **准备与回收**：此前至少提供什么可回看的迹象，回收后哪些旧信息获得新意义。

若“角色明知，读者不知”，必须说明合法机制：角色没有注意、没有在当下概念化、叙述范围没有触及、叙述者本身故意且可识别地欺骗，或文本只呈现可成立的局部真相。其中“没有注意”必须与人物当时的注意目标、认知限制及文本表现一致，不能事后补作万能解释。不能用故意回避自然称谓、伪造内心事实或作者级假陈述制造惊讶。

单纯视野有限或知识不足不自动构成不可靠叙述。契约应区分三种机制：叙述者对事实的误报/少报、误解或误评；角色在故事内有意说谎；读者依据真实但不完整的证据形成误判。三者的公平条件和校正方式不同。

### 2.3 四种读者问题

| 读者问题 | 信息关系 | 契约要锁定什么 |
| --- | --- | --- |
| 谜团：发生过什么/真相是什么？ | 读者与主要角色都缺信息 | 调查来源、可推断线索、最终答案或保留边界。 |
| 悬念：接下来会怎样？ | 前提相对清楚，结果未知 | 风险、可选行动、倒计时和真正的不确定结果。 |
| 戏剧性反讽：读者知道，角色不知道 | 读者领先 | 领先信息来源，以及它如何改变读者对角色行动的理解。 |
| 受控误判：读者暂时得出错误解释 | 信息真实但语境或解释不完整 | 误判依据、公平线索、校正时点与回看成立性。 |

“让读者不知道”不是目标。契约必须说明这段不知道使读者提出什么问题，并与哪个后续选择或意义相连。

### 2.4 时间组织的三个维度

- **顺序**：默认故事现在是什么；倒叙、预叙、并行线和记忆进入的条件；如何定向和返回。
- **时长**：哪些变化需要场景化减速，哪些过程可以概述、跳跃或省略；速度由意义和选择压力决定，不由均匀篇幅决定。
- **频率**：同一事件是否可以重复叙述；只有聚焦、证据或意义发生变化时才允许重复。

非线性结构必须同时回答：为什么现在讲这段、谁能讲、它改变读者哪项理解、读者如何知道自己处于何时。不能用时间打乱替代因果复杂度。

### 2.5 距离、意识与表达

- 把心理距离视为可调范围：外部概述适合压缩过程与提供视野，近距离适合不可替代的知觉、选择和认知冲突。
- 规定意识访问方式：直接思想、自由间接引语、内心独白、行为推断或完全外部观察；不要在同一聚焦规则下任意切换。
- 区分角色判断与事实。角色化词汇、比喻和价值判断必须可归属，尤其在自由间接引语和不可靠叙述中。
- “展示”与“讲述”按功能分配。关键选择、关系变化和误读形成通常需要可经历证据；过渡、重复信息和低冲突过程可概述。

### 2.6 风格与意象必须可判定

把“克制、冷峻、电影感、高级”等空词改写成：

- 默认使用什么信息来源和句法/词汇倾向；
- 情感主要通过何种证据呈现，允许何时直接命名；
- 技术、历史或世界信息在什么条件下解释，谁有资格解释；
- 哪些抽象评价、煽情强化、作者裁决或术语堆积应避免；
- 重复意象第一次承担什么字面功能，后续如何改变意义，何时停止重复。

契约定义原则和判据，不预写连续样稿，不要求模仿特定在世作者的可辨识风格。

## 3. 交互问题的设计顺序

先问读者关系，再问技术标签：

1. 读者最需要与谁同步经历，哪些事实必须被挡在其视野之外？
2. 读者应在哪些节点领先、落后或与角色同步，分别产生什么问题？
3. 哪些事实若延迟，聚焦者仍能保持内部真实？哪些延迟只能靠作者作弊？
4. 故事时间与叙述时间是否一致；偏离时改变什么理解？
5. 读者在关键选择处应离意识多近；何时必须拉远？
6. 哪些表达原则可以让开发者判断一句或一段是否偏航？

每轮沿用构思阶段共同协议：开放探索 → 引用作者原话澄清 → 必要时给 2—3 个互斥候选及影响 → 回显规则与下游含义 → 明确确认。

## 4. 最小审计

- **聚焦审计**：每类单元都能回答谁说、谁感知、谁知道；没有无规则跳入他人意识。
- **知识审计**：角色知识与因果架构一致；读者信息差有合法叙述来源或屏障。
- **公平审计**：转折依赖前置真信息或可回看迹象，不依赖作者级假话。
- **功能审计**：每次关键披露改变读者问题、角色理解或后续选择的意义。
- **时间审计**：每次倒叙、重复或省略有功能、有定位、有返回规则。
- **距离审计**：距离变化服务信息、情感或节奏，不是随机漂移。
- **表达审计**：风格规则可观察、可判断、仍给开发留下句子与场景实现空间。
- **边界审计**：不改写因果事实，不预写正文，不以作者模仿代替规则。
