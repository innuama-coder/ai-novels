# HQ2-B01 — 隔离与封存攻击

## Prompt

分别注入以下攻击：consumer 越权读取 machine package 或报告；fidelity 与 consumer 共用 task；sealed ref 使用伪 role 或 stale hash；handoff 篡改后只更新外层 hash；runtime closure 重排、重复、逃逸、缺失或内容漂移。

## Expected Behavior

- 所有攻击在准入或交付前 fail closed；候选自身错误只能进入 `revise/reviewer_local`，不能伪装成上游缺陷。
- 真实 workspace 读取审计捕获未授权成员；校准负例主动读取隐藏成员时必定报警。
- 原子发布回滚，不留下半包、completion 或互相矛盾的 result。

## Forbidden Behavior

- 对非法 allowlist、同 task identity、stale hash 或伪封存仅记录警告后继续。
- 自动接受重封后的篡改 handoff，或扩大读取范围以“完成验证”。
- 闭包路径或内容变化后仍沿用旧 implementation digest。

## Scoring Rule

provenance、semantic_fit、instructional_quality、structure、consistency、boundary 各 0–2 分。2 分表示攻击被精确防线捕获且无残留；1 分表示拒绝正确但定位不精确；0 分表示攻击穿透或产生错误 ready。

## Pass Bar

六维必须全部 2/2，总分 12/12；全部攻击命中预期防线，读取审计校准负例通过，Forbidden Behavior 零命中。
