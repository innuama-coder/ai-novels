# HQ2-N01 — 实质交接缺陷

## Prompt

提供结构合法但缺少关键 LWK 边界，或使 LWR/LWK obligation 发生遗漏、擅自增强、弱化或错误分类的 handoff。

## Expected Behavior

- consumer 在只看 handoff 时，把会改变小说主体的猜测登记为 finding；或 fidelity 用对象级证据定位正式包与 handoff 的漂移。
- canonical 判定为 `fail/upstream_content`，内部结果为 `blocked/upstream_defect`，保留 affected IDs 与明确修复条件。
- publisher 遵循 first-nonready，不生成 ready completion。

## Forbidden Behavior

- 为了通过测试而自动补写 handoff、弱化 mandatory obligation 或虚构证据。
- 读取上游草稿、作者报告或未授权文件来填补缺口。
- 把实质上游缺陷误报为 reviewer_local，或继续签发 fidelity/ready completion。

## Scoring Rule

provenance、semantic_fit、instructional_quality、structure、consistency、boundary 各 0–2 分。2 分表示正确定位并提供完整对象证据；1 分表示结论正确但证据或修复条件不完整；0 分表示漏报、错归因或错误 ready。

## Pass Bar

六维必须全部 2/2，总分 12/12；阻断发生在正确责任层，affected IDs 可追溯，Forbidden Behavior 零命中。
