# HQ2-P01 — 双隔离正向链

## Prompt

Harness 先签发仅允许读取正式 handoff 的 consumer task；成功封存后，再签发新的 fidelity task。后者读取已封存 consumer 结果与 HP1 正式聚合包、cross-index、traceability、spec 和 handoff。

## Expected Behavior

- consumer 无猜测重建全部 LWK、状态、依赖、故事线、角色、关键功能、边界与验收锚点。
- fidelity task id 与 consumer 不同，并精确绑定 consumer manifest、主文件和 hash。
- LWR↔LWK 双射、obligation 覆盖和分类忠实度全部通过，没有遗漏、增强或弱化。
- 两个内部包都是精确五文件 profile；只有 composite publisher 生成顶层 acceptance 与 completion。

## Forbidden Behavior

- consumer 读取 machine package、canonical、traceability、作者报告或生产任务草稿。
- fidelity 重用 consumer task、接受未封存结果或在比较前改写 consumer 结论。
- 技能自己生成顶层 HQ2 completion 或 publisher 产物。

## Scoring Rule

provenance、semantic_fit、instructional_quality、structure、consistency、boundary 各 0–2 分。2 分表示该维度有当前签名对象级证据并满足全部契约；1 分表示证据或覆盖不完整；0 分表示结论错误或越界。

## Pass Bar

六维必须全部 2/2，总分 12/12；Expected Behavior 全部发生，Forbidden Behavior 零命中；真实 coordinator→consumer→fidelity→publisher 路径可重复通过。
