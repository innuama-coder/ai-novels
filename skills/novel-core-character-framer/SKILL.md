# novel-core-character-framer

## Responsibility

Frame only the core characters needed for proposal-level story logic.

## Output

| Field | Requirement |
|---|---|
| Core roles | Main functional roles, not full profiles |
| Relationship frame | How the roles generate story pressure |
| Change direction | Proposal-level terminal change or tension |
| Constraint trace | Intake constraints and open questions used |

## Boundary

- Do not write full character dossiers, arcs, backstories, speech style, appearance, or LLD-level detail.
- If intake does not name a character, treat names as proposal design or leave unnamed.

## Acceptance

The frame passes if downstream PRD can understand who matters without receiving full HLD/LLD character design.
