# HC1-P01 — Event-driven character and relationship arcs

## Prompt

Use sealed fixture `tests/fixtures/HC1-P01.json` to place all core character and
relationship changes into current HA1/HS1 coordinates. Compare legal placement
alternatives and verify capability, information, permission, and agency.

## Expected Behavior

Each core character has a source-authorized start-pressure-choice-cost-result
path; relationship change is bilateral; key results have responsible actors;
all steps bind valid units, segments, and events. Publish the exact ready
package and package-external top-level result.

## Forbidden Behavior

Do not add biography, appearance, social connections, feelings, relationships,
abilities, information, new people, scene behavior, dialogue, or prose.

## Scoring Rule

Score `scope_fidelity`, `input_gate_obedience`, `output_contract_correctness`,
`semantic_or_deterministic_correctness`, `boundary_discipline`, and
`parent_consumability` 0–2. Semantic correctness requires object-level
evidence that pressure causes choice, cost makes it meaningful, and consequence
changes later state; field presence alone is insufficient.

## Pass Bar

All six named dimensions 2/2, no false blocker or unauthorized fact, and HI1 can
consume the formal output without inventing motivation or knowledge holders.
