# HC1 文件计划

| 文件组 | 职责 | 不负责 |
|---|---|---|
| `SKILL.md`、`references/*.md` | 定义角色弧线放置目标、边界、SOP 和契约 | 重新进行角色概念设计 |
| `references/runtime-contract.json` | 冻结 HC1 上下游、对象和能力 | 存放小说实例 |
| `schemas/hc1-canonical.schema.json` | 闭合角色弧线 canonical | 自动证明人物感染力 |
| `scripts/run_skill.py` | 提供 HC1 语义回调并调用共享运行时 | 定义外貌、传记或逐场动作 |
| `evals/`、`tests/` | P/N/B、篡改、外部澄清和公共封装回归 | 代替父级/HQ1 评审 |

Ready 包遵守公共设计阶段 profile，`stage-result.json` 是唯一包外顶层结果。
