# HI1 Design Brief

HI1 turns admitted narrative structure, storylines, character arcs, and non-quality conception controls into a canonical information architecture. It owns POV policy, character/reader knowledge states, information acquisition, suspense, reveal and payoff controls. It does not create story facts or write their prose realization. Success is a public Harness ready package whose information movement is legal, traceable, fair, and consumable by HR1.

The agent owns semantic option generation and evidence. `design_stage_runtime.py` owns public admission, immutable reads, HDD dependency handling, ready/revise/blocked packaging, hashes, completion and result envelopes.
