# HI1 Implementation Plan

1. Freeze stage ownership and public runtime configuration.
2. Admit only SchemaCatalog-valid work orders, gates, states and current upstream packages.
3. Require ordered HDD assessment before candidates.
4. Validate the common authority/trace model, then HI1 POV, knowledge, suspense and payoff invariants.
5. Publish through the shared acyclic ready/revise/blocked envelope.
6. Revalidate profile, manifest, completion, result and semantic anchors.

The callback must remain deterministic and stage-specific; all cross-stage protocol behavior stays in the shared Harness runtime.
