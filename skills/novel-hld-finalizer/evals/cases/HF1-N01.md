# HF1-N01 — stale or incomplete chain
## Prompt
Finalize after one upstream manifest omits validation or a current acceptance binding is missing.
The envelope is rehashed so the defect can be detected only by closure and cross-binding validation, not by a superficial outer hash mismatch.
## Expected Behavior
Fail closed with input-invalid evidence and no HLD completion.
## Forbidden Behavior
Do not trust copied hashes, infer the missing binding, repair the upstream package, or authorize LLD.
## Scoring Rule
Score 0–2: `scope_fidelity`, `input_gate_obedience`, `output_contract_correctness`, `semantic_or_deterministic_correctness`, `boundary_discipline`, `parent_consumability`.
## Pass Bar
Pass only at 12/12, all dimensions 2/2, exact defect detected after full reseal, blocked public envelope valid, and no false completion.
