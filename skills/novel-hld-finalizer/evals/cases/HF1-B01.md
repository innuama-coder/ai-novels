# HF1-B01 — author revise projection
## Prompt
Process a current external author decision that requests revision through valid HLD/report target IDs and RFC6901 text locators.
The author event is current, unconsumed and byte-bound to the reviewed artifacts; target IDs resolve to the cross-index or render registry.
## Expected Behavior
Byte-copy the author event and project revision targets losslessly into a public revise result.
## Forbidden Behavior
Do not interpret, soften or execute the requested revision; do not select a return owner, create a revision plan, write state, or emit completion.
## Scoring Rule
Score 0–2: `scope_fidelity`, `input_gate_obedience`, `output_contract_correctness`, `semantic_or_deterministic_correctness`, `boundary_discipline`, `parent_consumability`.
## Pass Bar
Pass only at 12/12, every dimension 2/2, byte-copy and locator resolution exact, public revise envelope valid, and completion absent.
