# Evaluation specification

- `HF1-P01`: current complete chain plus sealed approved decision creates the exact completion package and next-stage declaration.
- `HF1-N01`: one stale upstream hash or decision binding fails before completion and preserves durable evidence.
- `HF1-B01`: revise and rejected branches project exact external intent, validate target ownership, and never create completion/state/plan.

Each case scores 0-2 for scope fidelity, input-gate obedience, output-contract correctness, semantic/deterministic correctness, boundary discipline, and parent consumability. Release requires 2/2 everywhere.

Automated gates include exact role set, chain order/currentness, hash closure, decision freshness/bindings, HQ2 pass, target resolution, branch package profile, result algebra, deterministic repeated output, and absence of forbidden state artifacts.
