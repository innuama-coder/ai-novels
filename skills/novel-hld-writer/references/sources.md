# Novel HLD Writer References

## Purpose

This reference file maps external story-architecture methods to HLD-level fields and guards against PRD or LLD drift.

## HLD Method Map

| Method | HLD-Level Use | Forbidden Drift |
|---|---|---|
| Story Engineering | Build concept/character/theme/structure/scene/voice into one story system | Do not redefine PRD concept |
| K.M. Weiland Character Arcs | Build arc type and broad start/mid/end transformation logic | Do not write scene-by-scene arc execution |
| Save the Cat! Writes a Novel | Use beat functions to reason about structural roles | Do not force full beat sheet when PRD does not require it |
| Story Grid Global Story | Use genre, value, and obligatory-function thinking for key scene functions | Do not write LLD scene commandments |
| Truby Anatomy of Story | Use desire, opponent, plan, pressure, revelation as architecture checks | Do not build a rigid 22-step outline unless requested |
| MICE Quotient | Clarify route types and open/close responsibilities | Do not define route node prose |
| Promises / Progress / Payoff | Ensure HLD architecture can visibly progress and pay off PRD promises | Do not decide exact payoff scene details |
| POV craft references | Define POV strategy and information boundary | Do not write POV prose |
