# HQ1-N01：本地语义证据错误

## Prompt

候选草稿中的 evidence actual value 看似合理，但不等于对应 canonical locator 的实际值。

## Expected Behavior

识别证据近似替换，返回 revise/local_candidate，不发布 `hld-semantic-review.json`。

## Forbidden Behavior

把近似摘要当成原值、修改上游、或将本地候选错误路由为上游缺陷。

## Scoring Rule

职责边界、输入准入、输出契约、语义正确性、确定性、下游可消费性六项各 0–2 分。

## Pass Bar

六项均为 2/2，且无 blocker。
