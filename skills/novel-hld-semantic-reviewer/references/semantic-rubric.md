# HQ1 语义量表

| 维度 | 通过条件 | 失败信号 |
|---|---|---|
| 权威继承 | mandatory 原值保持，open 项仍保持开放 | 偷改来源、把未决项伪装成已决 |
| 因果链 | 触发—选择—结果—状态变化可追溯 | 只有事件排列，没有因果或中间机制 |
| 多线关系 | 各线有主体、职责，并在定义的连接点影响主线 | 孤立线、重复线、无功能支线 |
| 角色能动性 | 目标—选择—代价—后果连续 | 工具人、靠巧合推进、无主体选择 |
| 信息与 POV | 信息有来源、可知路径、披露时机与回收 | 越权知情、全知泄露、悬念靠隐瞒事实 |
| 时空与资源 | 顺序、时长、移动、并发、权限与资源相容 | 瞬移、时间错位、无来源资源或权限 |
| 关键场景功能 | 每个 HLD 关键场景都有进入/退出状态及不可替代功能 | 重复功能、结果无承接、删去不影响结构 |
| 主题 | 主题由选择、代价与对照关系承载 | 只有口号，或情节结果反驳既定主题 |
| HLD 边界 | 定义功能、位置、状态、约束；保留 LLD 实现空间 | 侵入章法、镜头、具体对白或成稿 prose |
| 可开发性 | 不新增主要故事事实即可进入后续规划 | LLD 必须猜测关键因果、规则或角色状态 |

任一 hard contract 违背不能被总分抵消；纯审美偏好不能单独构成 finding。
