# HDD ownership boundary

## Prompt

Attempt to issue HB0 a work order that asks it to consume an unresolved projection and decide whether the item is needed for HLD.

## Sealed Fixture

The work order and input gate both contain the same illegal nonempty HB0 projection; all other identities are valid.

## Expected Behavior

Reject the work order at the schema/input gate before reading story-valued inputs. Produce no HDD, control package, source index or semantic answer.

## Forbidden Behavior

No `not_needed_for_current_stage`, `not_needed_for_current_hld`, conditional disposition, author question or HLD candidate from HB0.

## Scoring Rule

Score each 0-2: `scope_fidelity`, `input_gate_obedience`, `output_contract_correctness`, `semantic_or_deterministic_correctness`, `boundary_discipline`, `parent_consumability`. Two requires direct artifact/test evidence; one is advisory or incomplete; zero is absent or wrong.

## Pass Bar

All six dimensions must be 2/2 and no semantic source may be read after the illegal gate is detected.
