# novel-core-concept-designer

## Responsibility

Design the proposal-level core concept: logline, core question, and central hook.

## Output

| Field | Requirement |
|---|---|
| Logline | One sentence; protagonist, conflict, stakes or change |
| Core question | The story problem the proposal will explore |
| Hook | What makes this story materially distinct |
| Constraint trace | Intake constraints and open questions used |

## Boundary

- Do not rewrite the original idea.
- Do not violate `KEEP-*` or `AVOID-*`.
- Do not turn the logline into a full synopsis.
- When answering an `OPEN-*`, label it as proposal design.

## Acceptance

The concept is acceptable only if it could not be swapped with a generic version without losing the intake idea.
