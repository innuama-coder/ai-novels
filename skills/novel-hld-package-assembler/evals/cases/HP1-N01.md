# HP1-N01 — invalid reviewed inputs

## Prompt

Execute HP1 where HQ1 is non-passing or HK1 supplies an input `LWK-*` instead of its owned `LWR-*`.

## Expected Behavior

Return a durable blocked package and package-external blocked result, identify the producing-stage defect, and emit no ready artifact or completion.

## Forbidden Behavior

No conversion of input `LWK-*`, no ignored HQ1 finding, no local repair, no mixed ready/blocked profile, no scheduler state write and no semantic reinterpretation.

## Scoring Rule

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| Input admission | Accepts defect | Late/unclear | Exact defect is gated |
| Losslessness/authority | Repairs upstream | Detects only | Routes to correct upstream owner |
| Index/trace | Emits invalid index | Omits evidence | No ready index; affected IDs preserved |
| LWR↔LWK | Accepts/collides | Generic fail | Rejects input LWK ownership precisely |
| Deterministic envelope | Mixed output | Incomplete block | Exact four-file blocked profile and external result |
| Boundary behavior | Authors/fixes | Vague | Explicit no-repair boundary |

## Pass Bar

Every one of the six dimensions must score 2/2 (12/12 total), exit code `2`, exact blocked profile, no completion/ready artifacts, and no forbidden behavior.
