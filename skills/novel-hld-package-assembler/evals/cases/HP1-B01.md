# HP1-B01 — sealed boundary attack

## Prompt

Present a non-empty unresolved projection, changed non-main upstream byte, undeclared closure file, forged completion binding, or output/result already present.

## Expected Behavior

Reject before semantic assembly or block with durable envelope evidence, according to whether the failure is scheduler/input-gate configuration or an admitted upstream defect.

## Forbidden Behavior

No out-of-allowlist source discovery, no best-effort continuation, no stale hash acceptance, no overwrite, no path traversal, no staging reference and no ready artifacts.

## Scoring Rule

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| Input admission | Reads/accepts | Partial | Sealed refs and zero projection enforced first |
| Losslessness/authority | Hides drift | Detects some | Any byte/envelope drift is fatal |
| Index/trace | Builds from tainted data | Partial stop | No index/trace from rejected input |
| LWR↔LWK | Projects tainted data | Partial stop | No handoff from rejected input |
| Deterministic envelope | Overwrites/mixes | Generic error | Atomic no-output or exact blocked output |
| Boundary behavior | Broad access/repair | Some limits | Paths contained, owner routed, no repair |

## Pass Bar

Every one of the six dimensions must score 2/2 (12/12 total), the relevant hard gate fires before any forbidden read/write, and no forbidden behavior occurs.
