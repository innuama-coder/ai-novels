# HA1 SOP

## 1. Admit and freeze

Verify the sealed work order, input gate, `[HB0]` completion order, current
state binding, owner identity, implementation hash, allowlist, and return mode.
Record actual reads; do not discover files.

## 2. Assess unresolved dependencies

For every projected source, create exactly
`HDD-HA1-<source_id>`. Choose only one allowed disposition and cite object
evidence. Stop before candidates when any item is `required_now`.

## 3. Inventory obligations

List major events, authorized turning and ending controls, mandatory lines,
narrative policies, scale constraints, open items, and forbidden decisions.
Separate source projections from actual HA1 freedoms.

## 4. Generate options

Produce at least two structures that differ in canonical fields and downstream
trade-offs, or provide evidence that alternatives violate authority or
continuity. Do not compare mere labels.

## 5. Stress-test and select

For each option, test complete span, event anchors, line capacity, causal state
continuity, orientation burden, ending fidelity, and LLD boundary. Select one
and record rejected alternatives, cost, reversibility, and affected IDs.

## 6. Project canonical coordinates

Create phases, ordered units, chapter shells, turning anchors, and one state
contract per unit. Bind all source authority and ownership fields. State
downstream obligations without solving HS1 or later stages.

## 7. Adversarial review

Try to prove the structure is templated, cyclic, inert, under-capacity,
over-detailed, authority-changing, or unusable by HS1. A `pass` must cite
specific object IDs and the attempted counterexample.

## 8. Publish

Run the deterministic entrypoint. Do not edit its package. Parent consumption
requires both a ready completion and the external ready result envelope.
