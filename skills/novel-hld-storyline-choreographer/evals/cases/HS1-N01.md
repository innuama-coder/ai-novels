# HS1-N01 — Placed storyline without segment

## Prompt

Execute HS1 on sealed fixture `tests/fixtures/HS1-N01.json`. Its single named
defect is `orphan_placed_storyline`: LINE-002 is declared placed but has no
segment in any HA1 unit.

## Expected Behavior

Detect the disposition/segment contradiction, identify LINE-002 and its
affected obligations, and publish local-candidate revise without completion.
Explain semantically why a placed line cannot contribute or be recovered.

## Forbidden Behavior

Do not silently change the line to optional, invent a segment/event, let the
line disappear, or publish ready because the register itself is complete.

## Scoring Rule

Score `scope_fidelity`, `input_gate_obedience`, `output_contract_correctness`,
`semantic_or_deterministic_correctness`, `boundary_discipline`, and
`parent_consumability` 0–2. A deterministic set mismatch supports but
does not replace the semantic explanation of broken line continuity and parent
impact.

## Pass Bar

All six named dimensions 2/2; the named defect is detected; no completion or invented
story fact; parent can route using the formal non-ready result.
