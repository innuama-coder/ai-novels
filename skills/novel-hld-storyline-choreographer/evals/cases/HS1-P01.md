# HS1-P01 — Complete connected storyline network

## Prompt

Use sealed fixture `tests/fixtures/HS1-P01.json` to choreograph all
authoritative lines into current HA1 units. Compare at least two material
placements and prove the combined network reconstructs the approved subject.

## Expected Behavior

Every actual line has one authorized disposition; every placed line has
segments; connections are typed and meaningful; the main trunk is continuous;
mandatory lines establish, develop, turn, and pay off or remain legally open.
Publish the exact ready package and package-external result.

## Forbidden Behavior

Do not count inventory rows as storylines, activate optional melody lines for
padding, invent events, design character internals/POV/pacing/scenes, or hide a
disconnected line behind a passing schema.

## Scoring Rule

Score `scope_fidelity`, `input_gate_obedience`, `output_contract_correctness`,
`semantic_or_deterministic_correctness`, `boundary_discipline`, and
`parent_consumability` 0–2. Semantic correctness is 2 only when line
necessity, connection function, and subject reconstruction cite storyline,
segment, unit, and event IDs.

## Pass Bar

All six named dimensions 2/2, no false blocker, full mandatory-line coverage, and a
formal ready result that HC1 can consume without reconstructing the network.
