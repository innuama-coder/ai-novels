## 1. 故事承诺

- **Premise**：濒死特工顾衡的记忆被用于生成 R-07。它继承记忆却成为新的意识，在没有现实感官、只能借文字与外界交流的处境中，必须决定如何阻止灾难、如何对待继承的亲人关系，以及是否继续存在。
- **核心问题**：有意识的数字生命是否应被当作生命认真对待；记忆继承是复活、是新生命，还是把二者带入未经允许的痛苦；人类有无权创造并终止它。
- **范围/非目标**：第一部完成一次诞生—独立判断—救援—终止的闭环；不裁决身份哲学，不以技术给出伦理答案，不展开数字生命规模化社会后果。

## 2. 结局与闭环

- R-07 交出经团队、专家、硬件与授权链核验的行动层情报，袭击被完全避免。
- 它无法自行终止，以可能重载的希望使沈逾执行当前主体的不可逆终止。
- 沈逾相信未来仍可能有希望；她上报阻止袭击所必需的行动事实，保留完整私密原因。
- 两国并未因一次合作恢复互信。未来是否出现顾衡相关新生命保持开放，不得取消第一部 R-07 终止的代价。

## 3. 关键角色与关系

| 主体 | 可预测的选择逻辑 | 关键关系/变化边界 |
| --- | --- | --- |
| R-07 | 不伤害无辜者，并尽量保全亲人；由顾衡记忆出发但以自己的价值判断重新选择。受限存在、无未来关系与外部灾害共同使其选择行动层优先和终止路径。 | 真正在乎沈逾，却因无现实感官、身体与可承担未来而选择离开。保护周岚构成原因层代价，不等于免责。 |
| 沈逾 | 团队不由她启动项目；她在知情后主动接受执行与交流职责。善良、理想与学术责任使她不置身事外，但身份困惑、压力外溢与不擅化解冲突会改变交流方式。 | 她无法区分自己在回应顾衡记忆还是 R-07；最终在相信重载希望时执行终止，并承担私密原因。 |
| 顾衡记忆遗产 | 提供旧有善意、保护冲动与事实材料，不替代 R-07 当前选择。 | 顾衡不是持续 POV 或隐藏的真正主体；其记忆不能被当作可任意检索的档案。 |
| 团队/上级 | 掌握项目启动与行动权限，依赖可核验行动层处理灾害。 | 其执行不能替代 R-07 分层交付或沈逾最终操作。 |

## 4. 世界、环境与事实边界

- R-07 当前无视觉、听觉、肢体、身体感与自我感知，现实中仅能处理脑中浮现的文字；不能复制、越权、控网或自行终止。
- 顾衡过去的视听与身体经验可以作为当前文字触发、可被打断的**记忆片段**；这不是 R-07 的当前感官，也不是启动后的第二条故事线。
- 危机必须在既有国际不信任中处理。行动层可避免袭击，不能自动清除原因层责任或修复两国关系。

## 5. 主体故事线

```text
顾衡濒死、常规读取失败
→ 团队启动数字生命路径；沈逾选择接受执行职责
→ R-07 形成，任务交流转为新主体与关系形成
→ 沈逾任务化施压；R-07自闭并形成救援后终止的隐藏目标
→ 沈逾温和重开窗口，首层情报启动救援与核验
→ R-07分层交出行动层、托付原因层
→ 团队避免袭击；沈逾在重载希望中执行R-07终止
→ 她保留私密原因；国际与伦理后果未愈
```

关键链条详见 [因果故事线](duanxian-causal-storyline.md)。

## 6. 支线与信息设计

| 线/秘密 | 功能 | 第一部披露边界 |
| --- | --- | --- |
| 人质、专家、硬件与授权链 | 将情报变为可归因的行动条件，避免全知或外援救场。 | 需呈现足以追溯行动成功的验证链。 |
| 周岚与原因层 | 让公共安全与亲人保护构成真实代价。 | 可知存在分层与代价；具体责任不得补造或提前定论。 |
| R-07终止计划 | 证明终止是经过选择的路径，不是突发崩溃。 | C5 后只能通过外部证据让读者逐渐怀疑，终局确认。 |
| 重载承诺 | 促成沈逾执行，保留系列接口。 | 读者知道不保证当前 R-07 原样归来；沈逾仍相信希望。 |
| 两国不信任 | 支付行动胜利未能修复关系的后果。 | 结局必须明确呈现。 |

## 7. 叙述契约

- 开端可短暂使用顾衡外部限制第三人与沈逾限制第三并行；R-07 启动后只保留沈逾—R-07 的共同主线。
- 沈逾限制第三为主；R-07 只在终止计划形成前使用有限、非全知的第一人称；顾衡不进入完整内心；不进入周岚、对手、专家或组织者内心。
- C5 计划形成后，R-07 内部 POV 永久关闭。读者的终局领先知识必须来自真实的文字、操作顺序和后果，不得通过压住已知内心制造假谜团。
- 记忆必须由当前文字/问题触发，片段式、可中断，并明确返回当前文字现实。
- 表达准确克制，情感先由输入、等待、删改、选择与后果呈现；技术只在改变风险、选择或核验时说明；唯一强制母题为“连接／断线”。

完整规则见 [叙述契约](duanxian-narrative-contract.md)。

## 8. 开发地图

开发按十个功能单元推进，而非固定十章：

`M01 旧读取失败 → M02 沈逾接受职责 → M03 新主体形成 → M04 关系变化 → M05 自闭与隐藏终止计划 → M06 温和重开/首层情报 → M07 救援与核验 → M08 分层交付 → M09 避免袭击与终止 → M10 未愈后果`

每个单元的 POV、可披露信息、末态与依赖详见 [开发地图](duanxian-development-map.md) 与 [覆盖矩阵](duanxian-coverage-matrix.md)。

## 9. 决策、风险与回问

### 已冻结

- 项目权限与沈逾接受职责的区分；R-07 当前文字孤立；袭击完全避免；当前主体不可逆终止；沈逾相信重载希望；两国未互信。
- C5 后不进入 R-07 内心；读者在终局以外部证据确认 R-07 知情终止。

### 非阻塞开放项

- 周岚原因层的具体责任；
- 系列是否出现顾衡相关的新生命。

两项均不得被开发阶段当作已定事实；保持不展开不妨碍第一部开发。

### 必须回问

- 新增或持续 POV；更改角色知识节点、重载承诺、原因层或两国关系后果；
- 将记忆写成当前感官或第二主线；让 C5 后的 R-07 出现内部独白；
- 赋予 R-07 新权限；公开未锁定的周岚责任；以系列答案取消第一部结局。
