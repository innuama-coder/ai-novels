## 0. 继承边界与修订

- **故事承诺与主题问题**：记忆被输入数字生命并不使其成为记忆原主人的延续；有意识的数字生命是生命，应被认真对待。第一部不替读者裁决人类是否有权创造或终止它。
- **核心主体与选择位置**：沈逾承担人类侧的任务、照料与最终操作；R-07 承担如何处理行动层/原因层真相、如何终止自身的选择。
- **外部目标、代价和关系功能**：行动层必须及时核验以阻止 D+58 攻击；原因层不可粗暴公开而伤害周岚。R-07 只能经由沈逾的文字交流与权限影响外界，终止不可由它自行完成。
- **世界/能力边界**：R-07 不是顾衡、不可复制/越权/控网；无视觉、听觉、行动能力与自我可感知性，只能通过意识中浮现的文字与外界交流。第一部的终止不可逆。
- **作者授权范围**：在上述边界内，作者授权 Agent 定义沈逾的 E 组变化与表达机制；不得替作者决定第二、三部是否出现新的顾衡相关生命或其真实机制。

## 4. 跨角色校验

| 校验 | 结论 | 风险/修订 |

| 同一压力是否产生不同解释和行动 | 外部压力下，R-07整合为选择性信息与终止计划；沈逾先直接外溢压力，再转向温和重开会话 | 因果必须保留两者的不同时间尺度与知情状态 |
