# 小说构思阶段 1.0.0

发布日期：2026-08-05  
状态：正式冻结（frozen）

## 冻结范围

本版本冻结从作者 idea 到获批构思交付的完整链路：

1. 访谈：六类创作访谈、完整性审计、三板块简报与作者批准；
2. 自主构思：故事线、世界、环境、事件、角色、整体审查与机器交付；
3. 人审呈现：十分钟评审规划、小说片段、内容组装、一致性审查与离线 HTML；
4. 最终交付：外部作者决定、批准分支、最终 completion 与开发交接。

权威调用链为：

`I0 → I1 → I2 → I3 → I4 → I5 → V1 → V2 → 作者批准 → B0 → S1 → W1 → E1 → T1 → C1 → Q1 → P1 → H1-A-plan → H1-B → H1-A-assemble → H1-C → H1 → 作者决定 → final`

## 1.0.0 的硬约束

- 访谈批准前不得进入 B0；D1/R1 不属于正式自主构思路径。
- 自主阶段不得跳序，不得由调度器代替领域技能补写内容。
- P1 是机器权威构思包；H1 必须忠实呈现 P1，不得增删或改写实质控制信息。
- 人审报告必须覆盖世界设定、角色定义、故事线设计和样章，并在十分钟内支持作者作出判断。
- 作者决定必须来自外部；只有 `approved` 可以生成 final 与开发交接。
- 产品版本 `1.0.0` 与内部 Schema/Contract 版本相互独立，内部版本不因封版而改写。

## 正式交付物

- 访谈证据包、V1 审计、V2 HTML 简报及作者批准；
- B0–P1 各阶段正式包、completion、状态与追溯记录；
- P1 机器可读完整构思稿；
- H1 人类可读评审包、小说片段与离线 HTML；
- 作者决定回执；
- 获批 final completion 与开发交接。

`harnesses/novel-conception-autonomous/docs/final-delivery-contract.md` 和
