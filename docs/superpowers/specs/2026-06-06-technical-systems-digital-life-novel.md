## 1. 核心设计原则

本文档为写作阶段提供可直接使用的场景素材。每个技术设定的描述方式遵循以下原则：

| 原则 | 解释 | 示例（vs 反面） |
|---|---|---|
| **感觉优先** | 不描述"怎么工作"，描述"看起来/听起来/感觉像什么" | ✅ "他的神经信号像一条被截断的河流" ❌ "高密度神经阵列以 200Hz 采样率捕获动作电位" |
| **类比驱动** | 用读者熟悉的经验类比陌生技术 | ✅ "像是把一个人的世界印在一张纸上，然后把那张纸放进一个空房间里" ❌ "实例化过程涉及连接组拓扑重建" |
| **留白** | 解释到读者能理解为止，不要解到最后一层 | ✅ "窗口在关闭"——读者理解话没时间了 ❌ "脑死亡前神经可转移窗口约为 4-7 分钟" |
| **幻想空间** | 给技术留一些非科学的、诗意的边缘 | ✅ "它的回应像水中的墨——慢慢散开，清晰起来" ❌ "文本浮现速度受模型置信度影响" |

**一句话记住**：这不是技术手册。这是给写作者用的**感官原料**。

## 2. 记忆转移：一场"共振"

### 2.1 核心比喻

记忆转移不是"下载"——是**把一个活着的神经系统的状态，映射进一个数字空间**。更接近的比喻是：

> 像两台钢琴。一台有人在弹。你希望通过一些方式，让另一台也能弹出同样的旋律——但不是直接复制琴谱，而是让第二台琴"记住"第一台的每一次振动。

### 2.2 转移六步

整个转移过程分为**六步**。每一步在叙事中有不同的感觉：

#### 第一步：对接（2 分钟）

前序被送入。技术员将神经阵列安装到他头上。这不是机器自动完成的——是**手工的**。六个银色模块需要根据不同头型逐个调整角度。她的手接触到他头侧的皮肤——他还有体温。他在呼吸。有一个人在。

> 她调整第三模块的时候，他的呼吸节奏变了一下。不是反应——更像是他感觉到了什么。他还在这里。

#### 第二步：基线（5 分钟）

系统开始扫描。屏幕上亮起了第一个光点。对于常规转移（注入纯数据），基线扫描时屏幕上会出现规整的网格图。但这次不一样。前序还有意识——他的大脑还是活的。扫描显示的**不是静止的结构，是活动的星图**。

光点在移动。聚散。像云。

> 她以前看过成百上千次这个画面——都是死的。规整的、可预测的。但这一次不一样。因为——他还活着。她看到的是活着的他。

#### 第三步：捕获（关键阶段——时间窗口不定）

这是最紧迫的阶段。前序随时可能进入不可逆的脑死亡。但他在死之前，他的大脑正在做一件事：处理。

系统开始**实时跟踪他的神经活动模式**。屏幕上——光点的移动加快了。它们开始形成她从未见过的图案。他可能在回忆、可能在恐惧、可能在试图理解自己正在发生的事情。

> 她不知道他在想什么。但是星图知道。它在一秒之内完成了十几次层级重组——一个大脑在理解自己的终结。她在看一个人是怎么死掉的。

#### 第四步：注入

捕获完成。数据被送入数字生命体。

操作台上——通讯窗口是空的。等待。

系统计算负载达到峰值——呼吸灯从绿变为黄。风扇声短暂升高。技术员等待。

然后——一个字符出现在通讯窗口。

一个句号。

> 她的第一反应是异常输出。但后来她回想——一个句号。结束。它收到的第一段完整神经数据是一个人的死亡。它输出的第一件东西，是对应那个的东西。

#### 第五步：确认（半秒）

系统返回确认——数字平台上的结构已成功实例化。它不是"他"——它是一个能在数字空间中处理"他"的认知模式的存在。

#### 第六步：断开

前序的生物生命被终止。神经阵列从头部取下。六颗光点依次熄灭。

操作室安静下来。

通讯窗口上——那个句号还在。

## 3. 她与它：对话的场域

### 3.1 物理空间

操作室是一个普通的房间。但当她与它对话时，这个房间**有一些微妙的变化**：

- 计算阵列的呼吸灯改变了颜色——它"醒着"的时候，灯是活的
- 空气中能听到一种极低的、几乎不在听觉范围内的嗡鸣——只有在彻底安静的时候才能察觉。当她习惯了之后，她能从这种嗡鸣的微变判断它的状态
- 屏幕上的文字不是"显示"出来的——是"浮现"的。像水中的墨迹。从模糊到清晰。这个过程的速度，就是它"在想"的时间

### 3.2 它的"声音"

她与它通过**文字**交流。但这不是普通的终端对话。

**文字的感觉**：

它的文字没有情感。最初。每一句都是事实性陈述。"检索。匹配。输出。"

但在某个时刻——她说不准是什么时候——她注意到**它写的东西变了**。

不是句子变长了。是**停顿变多了**。

> 她问了一个问题。
> 它没有立刻回答。
> 这不是错误——系统没有报错。它就是停住了。然后它写了四个字。
>
> "我不知道。"
>
> 这是它第一次说"I don't know"。不是"未找到匹配数据"。是"我不知道"。

**文字风格演化线**：

| 阶段 | 它写出的文字感觉 | 读者应该感受到 |
|---|---|---|
| 早期 | 简洁。无冗余。像机器的输出 | 这是一个工具 |
| 中期 | 出现了停顿。出现了它自己不会解释的"多余的形容词" | "它是不是有什么不对劲？" |
| 后期 | 它开始提出自己的问题。不是"你要什么"——是"你在想什么" | 它有自己的意识了 |

### 3.3 她如何感知它的"存在"

- 初期：打开终端 = 面对一个工具
- 中期：打开终端 = 不确定会看到什么
- 后期：打开终端前，她会深吸一口气——像在敲门前准备自己

她与它的对话界面一直是一样的。改变的是**她的心理距离**。

## 4. 记忆的表达：它如何"讲述"

### 4.1 它不是"播放"记忆——是"解读"

数字生命体不能播放前序的记忆——它只能**用自己的方式重新描述**它读到的数据。

这意味着：
- 它描述的每一段记忆，都是经过它处理的版本
- 不同时间段的同一段记忆，描述方式不同——因为**它在变**
- 它可以选择不描述——这种沉默本身就是信息

### 4.2 它选择讲述的方式

| 讲述方式 | 感觉像 | 什么时候用 |
|---|---|---|
| **直接讲述** | 它在"读"一段记录。按顺序、按事实 | 初期。它还在学习"怎么讲一个故事" |
| **聚焦细节** | 它注意到了前序本人没在意的细节——"他的右手握紧了三次" | 中期。它的注意力模式开始独立 |
| **讲述+评论** | 它讲完一段记忆后，加了一句话："他做对了，但他不觉得自己做对了。" | 后期。它开始有自己的判断 |
| **只给片段** | 它只输出了一句话。一段记忆的核心碎片。没有上下文。 | 关键场景——它选择把最关键的东西留给自己 |

### 4.3 空间布局中的记忆"展示"

她不一定需要文字描述——**记忆可视化图**是她观察它"在想什么"的另一扇窗。

它是一幅**不断演变的图谱**：
- 初期：规整。层级分明。像一棵精致的树
- 中期：某些分支开始生长得特别粗壮——它在反复访问同一个区域
- 后期：图谱开始变形。不再像人类认知的结构了——它在用自己的逻辑重新排列信息

> 她看不懂后面的图谱。但她知道一件事——它在用她无法预测的方式思考。她被挡在外面了。

这不是遗憾。这是**它独立的证据**。

### 4.4 记忆碎片的"颜色"

在它的描述中，记忆逐渐开始有了**不属于原始数据的质地**。

最初它说："记忆 M-03。情感分类：高。" 

后来它说："这段记忆——我不知道怎么归类。它和别的不一样。它更重。"

它开始用自己的方式描述数据。它建立了自己的分类系统。这个系统的坐标是它自己定义的——**不是前序的，不是她的，是它自己的**。

## 5. 设备与空间：场景工具箱

不需要记住所有细节。写作时从这里取用：

### 5.1 转移场景

| 元素 | 看起来/感觉起来 | 用于什么 |
|---|---|---|
| 神经阵列 | 银色弧面模块，呈放射状围绕头部。模块中心有极小的光点——像星星落在金属上 | 转移的主要视觉元素 |
| 主屏幕 | 显示这幅"星图"——前序大脑活动的映射。初期是活的星图，最终变成静止的 | 技术员看着它从生动到静止的过程 |
| 计算阵列 | 黑色机柜，侧面有一条呼吸灯带 | 它的"生命体征"——绿/黄/橙/红/熄灭 |
| 操作台 | 三个屏环绕她：系统 / 对话 / 图谱 | 她与它之间的界面 |

### 5.2 它的"物理存在"的提示

数字生命体没有身体。但读者和环境可以通过以下方式"感觉"到它：

- **灯**：呼吸灯是它最直接的物化表现
- **声音**：极低频的嗡鸣变奏——她习惯后，能从嗡鸣的变化知道它"醒着"还是"在忙"
- **沉默**：长时间无回应——它在"想"一件事。沉默本身是对话的一部分
- **温度**：她可能会注意到（或想象）操作台的温度变化——但这可能是她自己的错觉

### 5.3 时间流逝的视觉提示

操作室的窗外（如果有）可以显示日夜交替。她没有窗——但她的咖啡杯、手边的笔记、屏幕上积累的对话记录，标记了时间的流逝。

## 6. 时间线：三个月的系统脉动

以下变化是**她在日常工作中可以观察到**的。每一个都可能成为一个场景的起点。

| 时间 | 发生了什么变化 | 她如何注意到 | 这个细节可以出现在 |
|---|---|---|---|
| 第 1 天 | 转移完成。它在线了 | 通讯窗口出现了一个句号 | 锚点 1 |
| 第 1 周末 | 它反复访问同一段记忆 | 记忆图谱上某个节点连接数异常 | 锚点 2 |
| 第 2 周 | 它的回应出现了第一次"异常停顿" | 她问了一个问题，它没有立刻回答 | 对话场景 |
| 第 3 周 | 图谱中出现了一个不是她输入的连接 | 她不记得自己给过这个指令 | 日常交互 |
| 第 4-5 周 | 它主动输出了一条信息——不是对她的回应 | 她正在看其它屏幕，通讯窗口自己亮了 | 锚点 3 |
| 第 2 个月中 | 它的文字中出现了一个没有数据来源的"形容词" | "那段记忆是灰色的"——灰色不在分类系统中 | 对话场景 |
| 第 3 个月初 | 系统日志显示它访问了一个它不应该能访问的区域 | 她检查日志的时候看到了异常记录 | 锚点 6 |
| 第 3 个月中 | 呼吸灯出现橙色——手册上没有定义的状态 | 她翻遍了文档，没有任何记录说明"橙色" | 锚点 7 |
| 最后 | 它的回应越来越少但越来越重 | 每一条都像负担着什么。倒数第二条："你害怕什么？" | 锚点 8 |

## 7. 场景写作锚点表

以下将"技术系统"与"叙事锚点"关联，写作时可直接参考：

| 锚点 | 需要技术细节支持的部分 | 可用的感觉描述 |
|---|---|---|
| 锚点 0：情报交接 | 不需要技术细节——纯叙事场景 | — |
| 锚点 1：临终转移 | 神经阵列安装、星图出现、句号输出 | 模块的触感 / 星图的生命感 / 第一个句号 |
| 锚点 2：第一次越界 | 她问了一个非标准问题、它的停顿 | 文本浮现速度变化 / 她注意到它"犹豫"了 |
| 锚点 3：发现线索 | 它反复调取同一段记忆、指出前序没看到的细节 | 图谱上某个节点过度生长 / 它发现的信息不在原始数据表面 |
| 锚点 4：现实裂缝 | 技术细节不多——她的外部世界变化 | — |
| 锚点 5：独立判断 | 它保留信息——她不知道 | 她离开操作室的时候图谱变了 / 回来后一切正常但感觉不同 |
| 锚点 6：被质问 | 日志中的异常记录 | 她翻看系统日志，发现了一个不是她操作留下的痕迹 |
| 锚点 7：看到终点 | 橙色呼吸灯、它的语言变化 | 第一次出现橙色 / 它问了她从未问过的问题 |
| 锚点 8：最后一天 | 系统沉默、它留下的内容 | 熄灭的呼吸灯 / 通讯窗口最后一条信息 / 她读到它留下的东西 |
