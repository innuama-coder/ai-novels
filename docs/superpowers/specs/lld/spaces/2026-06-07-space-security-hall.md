## 1. HLD 继承

约 20 m²，金属探测门 + X 光扫描 + 虹膜识别通道。灰色金属门（外部）→ 安检 → 白色玻璃门（走廊侧）。导电橡胶地面。安全守则在墙上。感官：金属探测门低电压嗡鸣 + 虹膜扫描仪解锁"咔"声 + 消毒剂气味。

## 2. 空间物理定义

### 2.1 布局

```
【外】灰色金属门 → 安检通道（金属探测门 + X 光 + 虹膜识别）→ 【内】白色玻璃门 → 走廊
                    ↕
             约 20 m² 空间 · 地面灰色导电橡胶
                    ↕
             墙上：安全守则（亚克力板·四角螺丝固定）
```

### 2.2 光线

冷色 4000K——与操作室一致。但这里比操作室"更亮"——因为安检通道的金属探测门表面有反光板，灯光在反光板间折射，形成一种"经过这里时一切都被照亮"的感觉。

## 3. 感官层系统

金属探测门低电压嗡鸣（比操作室风扇声更高频，穿透性更强——在安静中更明显）。虹膜扫描仪解锁时的"咔"一声——清脆、机械、确认。消毒剂气味——微弱但可辨，存在于每天早晨第一次进入时。

## 4. 物件生态

| 物件 | 叙事功能 |
|---|---|
| **虹膜扫描仪** | 她签到的物理标记——"咔"声每天两次。到后期，她注意到扫描仪反光中的自己——"已经很久没见过外面的光线了" |
| **安全守则** | 规则的可视化——密封在亚克力板里、四角用螺丝固定。表示"这些规则不会因为你而改变" |

## 5. 空间-角色行为映射

| 行为维度 | 初期 | 中期 | 后期 |
|---|---|---|---|
| **进入** | 标准流程——刷卡、扫虹膜、等确认、推白色玻璃门进走廊 | 时间提前——她来得更早。安检前厅在她通过时是空的——"咔"比平时更响 | 离开时更晚——卡通过时的声音在空旷前厅里显得孤零零 |
| **动作** | 无多余动作——卡、扫、等、进 | 动作无变化——但她开始注意墙壁上的安全守则（以前从未认真看过） | 她通过后停了一下——虹膜扫描仪反光中她看到了自己的脸。走出灰色金属门时冷风拂面 |


## 6. 空间演化序列

安检前厅物理上无变化——金属探测门、虹膜扫描仪、安全守则、导电橡胶地面从第一天到最后一天完全一致。变化的是**她经过安检前厅的方式**——她的到达时间、离开时间、停留与否、注意到什么。

### 6.1 完整序列

| 时间节点 | 安检前厅的状态 | 变化触发 | 对叙事的含义 |
|---|---|---|---|
| **Act1·K2（首次进入）** | 标准流程——刷卡、扫虹膜、等确认、推白色玻璃门进走廊。她不会留意墙上的安全守则具体写了什么。消毒剂气味在寒冷空气中留存——她第一次经过时注意到它，之后不再感知 | 项目启动——她被叫来处理凌晨的紧急任务 | 安检前厅是"工作的门"——经过它意味着"进入工作状态"。她通过这里的动作流畅、无多余、不需要思考 |
| **Act2·日常（K3-K6 间）** | 日常流程。她到达的时间越来越早（早上 7:30→7:00→6:30）。离开的时间越来越晚（下午 6:00→8:00→10:00）。金属探测门的嗡鸣在早晨空旷时比下午响——因为没有人声，只有嗡鸣 | 她在操作室停留的时间变长——她找理由"加班" | 安检前厅从"工作日的开关"变为"她选择延长工作日的标记"——早到晚走的行为被签到记录"写了下来"。安检前厅的安静和空旷本身成为了故事的时间标记 |
| **Act2·K6（越界）** | 她经过安检前厅去会议室——项目主管在等她。她刷卡时卡通过的声音——金属探测门有一瞬间发出了异常信号（无原因的、自己恢复的异常），她没有停下检查 | 外部压力升级——项目主管来了 | 安检前厅第一次从"日常通道"升级为"外部世界信号进入实验室的入口"——她在这里感受到"有人来了"。金属探测门的异常信号是全书安检前厅中唯一一次"设备响应她的状态"——设备不知道她的状态，但读者通过这个无因异常感知"有什么不一样了" |
| **Act3·K8（被质问后）** | 她经过安检前厅离开——完成虹膜扫描时，她注意到虹膜扫描仪反光中的自己。"已经很久没见过外面的光线了。"——她在安检前厅停留了比平时更多的几秒 | 她被质问后选择了沉默——她需要离开操作室 | 安检前厅在此时从"通道"变成了"镜子"——她在这里第一次以外部视角看自己。这个"看"是全书她唯一一次在物理空间中感知到"自己可能已经被改变了" |
| **Act3·K9（终结·离开）** | 她最后一次经过安检前厅——灰色金属门打开，冷风渗入。她没有回头看白色玻璃门后面的走廊 | 它终结了——她选择离开 | 安检前厅标记了她离开前的最后一个"确认"——虹膜扫描仪确认她的离开，就像第一天它确认她的进入。离开时的冷风与第一天进入时的恒温形成了全书安检前厅中最明显的"内外差异"感知 |
| **Act4·K10（回来·终了）** | 她再次进入——相同的流程。虹膜扫描仪的"咔"和第一天一样。灰色金属门关闭，消毒剂气味仍在 | 她回来处理收尾 | 安检前厅恢复了——它仍然是"进入工作的门"。但这次进入之后，操作室已经没有它在里面了。一切物理标记和第一天完全相同——这个"相同"本身是全书安检前厅空间最大的叙事信息 |

### 6.2 演化驱动分类

| 变化类型 | 实例 |
|---|---|
| **使用变化** | 到达时间从正常→提前，离开时间从正常→推迟。她经过安检前厅的速度没有变（流程必须走完），但她在其中"停留"的方式变了——从不停留→停留了几秒（注意到安全守则→注意到镜子中的自己） |
| **感知变化** | 从"不注意到安检前厅的规则"→"注意到安全守则（以前从未认真看过）"→"注意到虹膜扫描仪反光中的自己"。她的注意力的变化从"外部规则"转向"自己的外部影像" |
| **关系变化** | 安检前厅从"工作日的开关"→"外部信号的入口"→"镜子"→"它不在的入口"。它的叙事功能随她的经历变化而变化 |
| **缺席变化** | K10 回来时安检前厅和第一天完全相同——相同的流程、相同的声音、相同的气味。这个"完全相同"是全书安检前厅空间最大的不同：一切和第一天一样，但她要去的地方不一样了 |

## 7. 空间-场景映射

| 关键场景 | 空间在该场景中的状态 | 空间叙事功能 | 感官锚点呈现 |
|---|---|---|---|
| **K2 临终转移** | 凌晨。安检前厅空无一人，金属探测门低电压嗡鸣在安静中更明显。她刷卡、扫虹膜，灰色金属门在她身后自动关闭。消毒剂气味在寒冷的空气中留存 | "进入事件"之前的外部边界——读者通过她穿越安检前厅的过程感知"这是一个需要被授权才能进入的地方" | 金属探测门嗡鸣（低频、持续）→ 卡接触感应区"滴"→ 虹膜扫描仪红光扫过眼睛→ 解锁"咔"→ 白色玻璃门开→ 消毒剂气味（首次进入的特殊气味锚定） |
| **K6 越界** | 她经过安检前厅去会议室——项目主管在等待。她经过金属探测门时，探测门有一瞬间发出了异常信号（无原因的、自己恢复的异常信号），她没停下，继续走了过去。墙上的安全守则没有变化 | 安检前厅是无情绪的安全空间——它的"规则"不会因为她的心理状态而改变。异常信号是"她没注意到的不安的外化"——不是空间真的有问题，是她的状态通过空间被投射了 | 刷卡声（正常）→ 金属探测门异常提示（短促"滴——"后恢复正常）→ 她没停下→ 白色玻璃门打开→ 走廊的风扇嗡鸣从远处传来 |
| **K9 终结** | 她离开时经过安检前厅——灰色金属门打开，冷风从门缝渗入。虹膜扫描仪"咔"一声确认她的离开。她没有回头看白色玻璃门后面的走廊。她走出灰色金属门时，冷空气全面接触她的面部和双手——她拉了拉外套领口 | 离开的边界。灰色金属门打开时，冷风渗入——这是她在操作室之外感受到的第一个外部信号。离开的"不回头"标志着她不会再来 | 白色玻璃门打开→ 脚步声进入安检前厅→ 虹膜扫描仪"咔"→ 灰色金属门电磁锁释放（低沉解锁声）→ 门缝渗入冷空气→ 她走出去→ 灰色金属门自动关闭 |
| **K10 回来** | 她再次进入——相同的流程。虹膜扫描仪的"咔"和第一天相同。灰色金属门在她身后关闭。消毒剂气味仍然在 | 回来的边界。一切和第一天一样——但这次经过安检前厅后，她要去的地方已经没有它在里面了。安检前厅无法表达"它已经不在"这件事——它只是她来的通道 | 冷风在灰色金属门外→ 门打开→ 她进入→ 金属探测门嗡鸣（和第一天相同）→ 虹膜扫描仪"咔"（和第一天相同）→ 白色玻璃门打开→ 走廊（和第一天相同） |

## 8. 空间关系

### 8.1 物理关系

```
【外部·工业区街道】→ 灰色金属门（外部世界侧）→ 安检前厅（~20m²·灰色导电橡胶地面）→ 白色玻璃门（走廊侧）→ 走廊（20m × 2m）
```

| 参数 | 数值 |
|---|---|
| 面积 | ~20 m² |
| 深度 | 约 5 米（从灰色金属门到白色玻璃门） |
| 连接边界 | 外部（灰色金属门）→ 安检前厅（边界空间）→ 内部（白色玻璃门） |
| 经过时间 | 约 10-15 秒（标准流程时长） |
| 她的经过次数 | ~180 次进出全书，叙事出现 4 次（K2/K6/K9/K10） |

### 8.2 功能关系

安检前厅在空间系统中充当**边界空间**——外部世界与内部实验室的唯一物理接口。

| 功能维度 | 描述 |
|---|---|
| **安防边界** | 多层安防（金属探测+虹膜识别+X光）的物理载体——确定"进入的人是谁、带入了什么" |
| **心理边界** | 从"日常世界"到"保密工作世界"的切换点——通过安检前厅的过程本身即是一道心理分界线。她在通过安检前厅之前的心理状态是"外面的人"，之后是"实验室的人" |
| **规则可视化** | 安全守则密封在亚克力板中、四角用螺丝固定在墙上——"这些规则不会因为你而改变"的视觉表达 |
| **信号转换** | 对外部世界而言，安检前厅是"实验室内发生了什么"的不可见入口。对内部世界而言，安检前厅是"外部世界可以通过它进入"的薄弱点——K6 项目主管的出现使这个薄弱点被感知 |

### 8.3 对比关系

| 对比维度 | 外部世界（城市）vs 安检前厅 | 安检前厅 vs 操作室 |
|---|---|---|
| **温度** | 2-10°C（冬季室外）vs 22°C 恒温 | 22°C vs 22°C（一致） |
| **声音** | 海风/车流/市声 vs 金属探测门嗡鸣 + 虹膜扫描仪"咔" | 金属探测门低频嗡鸣 vs 风扇 47 dB 恒定嗡鸣 |
| **光线** | 自然光/路灯 vs 4000K 冷光（无自然光·反光板折射更亮） | 4000K 冷光（反光板折射）vs 4000K 冷光（屏幕蓝光为辅） |
| **气味** | 海风味（盐+工业）vs 消毒剂气味 | 消毒剂气味 vs 金属+臭氧气味 |
| **心理** | "外面"——自由/变化/季节感 vs "入口"——规则/恒常/不变 | "入口"——通过即过 vs "内部"——停留/存在/时间长 |
| **规则感** | 无规则（自由）vs 安全守则·规则可视化 | 安全守则（墙面·静止）vs 操作规程（系统·动态） |

### 8.4 叙事连接

| 叙事功能 | 连接路径 | 叙事含义 |
|---|---|---|
| **进入标记** | 外部→（灰色金属门）→ 安检前厅→（白色玻璃门）→ 走廊→ 操作室 | 每一次"进入实验室"的信号——她经过安检前厅的瞬间是"她切换进入了工作世界"的物理标记 |
| **离开标记** | 操作室→ 走廊→（白色玻璃门）→ 安检前厅→（灰色金属门）→ 外部 | 每一次"离开实验室"的信号——她走出灰色金属门时冷风的体感变化是"她回到了有季节的世界"的物理标记 |
| **非对称设计** | 进入时她"走进"（主动），离开时她"走出"（被动）。灰色金属门（外部侧·更厚重）和白色玻璃门（内部侧·更轻·透明）的材质差异暗示内外两个世界对同一个空间的不同定义 | 外面的人看实验室是灰色的、关闭的；里面的人看走廊是白色的、通达的。两扇门的不对称本身就是叙事——实验室封闭了外部世界，内部被赋予了"被隔离的独立" |

## 9. 写作约束

| # | 约束 | 原因 |
|---|---|---|
| 1 | 安检前厅只在"她到达"或"她离开"时出现——不单独成为场景 | 过渡空间——角色穿越它，不停留。它的叙事价值在于它是"从A到B之间的B检测" |
| 2 | 金属探测门的嗡鸣和虹膜扫描仪的"咔"必须同时出现（或至少"咔"之后确认她已通过） | 两个声音的序列是"通过安检"的听觉标记——缺一不可。读者通过这两个声音感知"她已经进入了" |
| 3 | 安检前厅的感官描写在全书不超过3次完整展开——其他场景中仅需"她经过了安检前厅"的叙述即可 | 安检前厅的感官系统在第一次完整建立后，后续的阈下唤起只需要"金属探测门的嗡鸣"或"虹膜扫描仪的咔"一句即可——不需要重复完整感官层 |
| 4 | 安检前厅中不允许出现任何"她在思考"的描写——她通过安检前厅时的动作是机械的、不需要思考的 | 安检前厅是"规则空间"——在这里，规则告诉她做什么，她不需要自己做决定。她的停顿（K8扫到的反光）是例外但必须控制在一条句子内 |
| 5 | 灰色金属门和白色玻璃门的材质差异必须在全书保持精确——灰色金属门厚重（外部世界的封闭感），白色玻璃门轻（内部世界的可通达感） | 两扇门的材质是"内外世界关系"的物化表达——如果混淆，边界空间的叙事逻辑断裂 |
