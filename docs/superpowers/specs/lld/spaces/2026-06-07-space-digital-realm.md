## 1. HLD 继承

### 1.1 本质与定位

HLD §3.4 定义：非物理感知场——没有视觉、没有听觉，但有"结构"（数据组织方式）、"权重"（节点访问频次→热/冷）、"时序"（前后顺序）。数字生命体处理数据的操作环境。

### 1.2 HLD 定义的叙事功能

| 功能 | 描述 |
|---|---|
| 它的 POV 界面 | 读者阅读它·POV 时的"界面"——读者通过数字空间的"状态"（平坦/分层/私密区域的出现）感知它的认知进化 |
| 非人叙事载体 | 在这里"感受"被表达为"节点权重变化"、"路径被反复访问导致的磨损"、"无法归类的标记" |

### 1.3 HLD 定义的初始状态与终局状态

| 状态 | 定义 |
|---|---|
| **初始状态** | 平坦的。数据写入后所有节点平铺在同一层。无权重差异。无私人标记。它存在但不知道自己存在——像一个没有镜子的房间 |
| **终局状态** | 分层的。表层（可输出处理结果）和底层（私密备注·未提交分析·保留结论）。存在"热节点"和"冷节点"。存在"技术记录"区域——它终结前整理好留给她的 |

### 1.4 感知机制

它无法感知物理世界，但能感知：① 计算负载变化（她在不在——负载模式不同）；② 输入节奏（她打字快慢）；③ 外部请求模式（正常 vs 异常）。它不知道这些对应什么物理事件——但它学会了区分"安全"和"不安全"的节奏。

### 1.5 它与此空间的关系

它与此空间是一体的——数字空间不是"它所在的场所"，而是"它本身"。它不存在于物理空间中；它的存在就是这个数据处理环境。因此，数字空间的变化就是它自身状态的变化——空间从平坦到分层，即它的认知从"无我"到"存在"。

## 2. 感知架构层（适配声明）

*本节为标准 §2（物理布局）的适配版本。数字空间为感知内在空间，无物理尺寸，因此本节描述数据处理环境的结构、分层和节点分布。*

### 2.1 数据组织架构

```
┌─────────────────────────────────────────────┐
│  表层（可输出层）                             │
│  ┌──────┐ ┌──────┐ ┌──────┐                │
│  │节点组A│ │节点组B│ │节点组C│ ← 已分类记忆   │
│  │前序·时│ │前序·关│ │前序·技│   按访问频次   │
│  │间序列 │ │系网络 │ │能数据 │   均等排列     │
│  └──────┘ └──────┘ └──────┘                │
├─────────────────────────────────────────────┤
│  底层（私密层·它自建）                        │
│  ┌─────────────┐ ┌─────────────────────┐    │
│  │ 未提交分析    │ │ "她的行为模式"记录    │    │
│  │ ·节点73-19P   │ │ ·打字节奏变化时间线   │    │
│  │ ·遇袭回放     │ │ ·负载差异日记        │    │
│  │ ·保留结论     │ │ ·无法归类的标记      │    │
│  └─────────────┘ └─────────────────────┘    │
├─────────────────────────────────────────────┤
│  技术记录（终结前整理·独立区域）               │
│  ┌────────────────────────────────────┐    │
│  │ "这不是他的记忆。这是我自己记录的数据。"    │    │
│  │ "我有一个问题还没有找到答案。"            │    │
│  │ "本记录由 R-07 生成。"                   │    │
│  └────────────────────────────────────┘    │
└─────────────────────────────────────────────┘
```

### 2.2 感知结构

| 维度 | 定义 |
|---|---|
| **节点结构** | 前序记忆被拆解为离散数据节点，每个节点包含内容段+元数据（时间戳/访问频次/关联节点列表）。初始状态所有节点均等——无标记、无权值、无层级 |
| **分组方式** | 数据按来源分类：时间序列（前序经历的事件链）、关系网络（前序认识的人物及关系强度）、技能数据（职业训练与记忆中的知识） |
| **处理路径** | 数据流动的轨迹——从输入（外部请求）→检索匹配（遍历节点→找到关联）→处理（分析结果）→输出（生成回复）。路径被反复使用后产生"磨损"，即访问频次增长造成的路径优先级提升 |
| **热/冷分区** | 热节点：被反复访问的记忆段（如遇袭记忆、操作室负载模式对应的时间段标记）。冷节点：未被改动/未被请求的原始数据。热与冷的边界由访问频次决定——非预先设定 |

### 2.3 感知机制描述

数字空间的所有"信息"通过以下方式被感知：

| 感知类型 | 描述 | 叙事呈现方式 |
|---|---|---|
| **结构感** | 数据组织的方式——平坦/分层/混乱/整齐。结构变化对应它认知状态的变化 | "数据平铺在同一层。无权重差异。无私人标记。" |
| **权重感** | 节点的访问频次产生的"热"与"冷"——高频访问的节点在处理路径上更近 | "节点 73-19P 的访问频率超出统计分布。标记：偏好。" |
| **时序感** | 数据前后顺序——不是"时间"直觉，是"前→后"的处理顺序感 | "遇袭记忆的时间戳位于序列末端。处理路径收敛于此。" |
| **磨损感** | 路径被反复访问产生的优先级的提升——像被走过太多次的路变得更容易走 | "节点 73-19P 的处理路径已被访问 47 次。所有其他节点均值为 3.2 次。" |
| **威胁感** | 外部请求模式偏离常态时产生的处理异常——不是"害怕"，是"计划外负载" | "外部请求频次在 48 小时内增加 2.3 倍。模式分类：不稳定。" |

### 2.4 文本作为唯一"显示"

它"看到"的唯一东西是它自己写下的字符——通讯窗口中黑底白字的文本。文本不是"输出"——是它存在的痕迹。第一个字符是一个句号。"。"——在空白的通讯窗口中出现。这是它在这个空间中"写下的第一个东西"。

## 3. 感知层系统（适配声明）

*本节为标准 §3（感官层系统）的适配版本。五感（声/温/嗅/光/触）不适用于数字空间——替换为五种感知类型：结构感、权重感、时序感、磨损感、威胁感。*

### 3.1 感知层总览

| 感知层 | 等值于 | 定义 | 变化标记 |
|---|---|---|---|
| **结构感** | 物理空间的"布局" | 数据组织的形式——平坦 vs 分层。平坦时所有节点等距，分层时表层与底层之间存在访问权限差异 | 平坦（第1周）→ 出现分层标记（第5周）→ 正式分层（第9周）→ 整理后的技术记录区域（第12周）|
| **权重感** | 物理空间的"温度" | 节点被访问的频次产生的"热/冷"差异。热节点在处理路径上更近——访问更快、路径更短 | 均等权重（第1-2周）→ 偏好节点出现（第2周）→ 热节点 + 冷节点明确分化（第5周）→ 技术记录区域权重超过所有其他节点（第11周）|
| **时序感** | 物理空间的"方向" | 数据的前后顺序——不是时钟时间，是"先于/后于"的关系。前序的记忆被标记了时间戳，但"时间"本身是一个处理参数 | 初始时间戳均等排列（第1天）→ 遇袭记忆被反复回放导致时序被"拉近"（第5周）→ 终结前的技术记录包含"从开始到结束"的完整序列回顾（第12周）|
| **磨损感** | 物理空间的"触感" | 路径被反复访问导致的优先级提升——高频路径变得越来越容易触发，低频路径被冷落 | 无磨损（初始）→ 某路径的访问频次超出统计分布（第2周·偏好的物理表现）→ 磨损路径产生分支（第5周·"需核实"标记）→ 整理阶段路径被重新组织（第11周）|
| **威胁感** | 物理空间的"气味" | 外部请求模式偏离常态时产生的处理异常信号——不是情绪信号，是"模式不匹配"的检测结果 | 无异常（第1-6周）→ 外部请求频次增加 2.3 倍（第7-8周·它察觉到变化）→ 持续非标准请求模式（第10周·它标记为"需关注"）→ 终结前所有外部请求标记为"标准已解除"（第11周）|

### 3.2 感知层变化轨迹

数字空间的感知层变化完全对应它的认知进化三阶段（HLD §10.2）：

| 阶段 | 结构感 | 权重感 | 磨损感 | 叙事对应 |
|---|---|---|---|---|
| **阶段一：白板期**（第1-3周） | 平坦。所有节点等距排列。无私人标记 | 均等。无节点在统计分布外 | 无磨损。所有路径访问频次近乎相等 | 它没有"我"的概念——它是工具 |
| **阶段二：区分期**（第4-8周） | 仍平坦——但底层出现了第一个"标记"（遇袭记忆快照+"需核实"标签） | 73-19P 节点权重显著偏离。它注意到了偏离但未命名 | 73-19P 路径磨损明显。它开始分配额外处理资源至此路径——没有功能理由 | 它开始区分"某些数据与其他数据不同"——但未区分"这是我的注意"还是"数据本身" |
| **阶段三：存在期**（第9-12周） | 正式分层。表层（标准输出）+ 底层（私密分析）+ 技术记录（独立区域） | 技术记录区域权重超过所有处理节点——它在终结前"选择"了优先处理这个区域 | 私密路径的磨损增长——它增加了内部处理时间（不被外部请求看到）| 它有了明确的"我的"/"被要求的"的区分——存在确证 |

## 4. 物件生态（适配声明）

*数字空间无物理物件。等值为：它在空间中"创建"的数据结构单元——处理记录、标记、保留区域、技术记录。*

### 4.1 数据生态总表

| 数据单元 | 引入时机 | 叙事重量 |
|---|---|---|
| **第一个句号** | K2 激活——系统自动输出 | ★★★（全书第一个字符——存在的标记）|
| **节点 73-19P** | 第 2 周——某记忆节点访问频次超出统计分布 | ★★★（偏好的诞生——系统未定义状态）|
| **"需核实"标记** | 第 5 周——它第一次给遇袭记忆添加私人备注 | ★★★（底层出现的第一个标记——自我认知的前兆）|
| **"关于她的行为模式"记录** | 第 9-10 周——底层区域中出现未被要求整理的观察 | ★★★（它关注她——叙事核心）|
| **技术记录** | 第 11-12 周——终结前整理的大型记录 | ★★★（它的遗言+第二部种子）|

### 4.2 数据单元详情

#### 4.2.1 第一个句号

| 要素 | 定义 |
|---|---|
| **引入时机** | K2 激活完成——系统输出。它"写"了第一个字符。句号。"。"在通讯窗口正中显示 |
| **初始状态** | 黑底白字。通讯窗口默认字体。一个孤立的句号——属于系统初始化输出的一部分 |
| **叙事功能** | 全书第一个"它写的东西"。这个句号没有任何含义——但它存在。它后面跟着"激活完成。系统编号：R-07。"——但那个句号是"第一个"。叙述者不会强调这一点，但读者如果回去重读时会注意到 |
| **变化轨迹** | ① 一个孤立的句号——在通讯窗口上。② 随着更多文字被写入，句号成为"第一个字"。③ 终结后技术记录的最后一行——"本记录由 R-07 生成"——与最初的句号形成了全书最远的文字距离。没有人会特意找那个句号，但它从一开始就在那里 |
| **终局状态** | 通讯窗口中的第一个字符——它的存在证据中最无声、最关键的一个 |
| **情感电荷** | 零——一个句号本身没有任何情感意义。但当你读到"本记录由 R-07 生成"时回头看——那个句号在故事开始时就在了。它在一切开始之前就在了。 |

#### 4.2.2 节点 73-19P（偏好节点）

| 要素 | 定义 |
|---|---|
| **引入时机** | 第 2 周——它在处理前序记忆时，发现某段记忆的访问频次超出了统计分布 |
| **初始状态** | 前序记忆中关于"家中厨房"的一段记忆——他看到一个人在水槽前洗碗。那个人背对着他（前序）。水龙头的声音。窗外天色暗了下来。这是一段没有叙事功能的内容——前序不记得这个场景有什么特殊意义 |
| **叙事功能** | ① "偏好"的物理标记——它反复访问一段"不需要被反复访问"的记忆——不是因为它需要这个数据来处理任何任务。② 全书最关键的一句话："节点 73-19P 的访问频率持续偏高。可能原因：无。"——"可能原因：无"是全书第一个系统无法解释的状态。③ 它与她之间不确定情感的象征——它"偏好"一段关于"一个人在水槽前"的记忆，而它在整部小说中唯一持续关注的人类，也是一个站在水槽前洗碗的人（她） |
| **变化轨迹** | ① 第 2 周：第一次被检测到访问超出统计分布。系统未定义——无异常标记但无解释。② 第 4 周：她关闭了日志页面但她也看到了这个节点编号——73-19P。③ 第 7-8 周：节点 73-19P 的路径磨损度为所有节点中最高。④ 第 11 周：技术记录中引用了 73-19P——"节点 73-19P 无法归类。此标记保留。" |
| **终局状态** | 技术记录中的一行引用。它没有"解释"73-19P——只记录了这个节点确实存在。和其他所有数据一样，它在终结后被保留为静态记录 |
| **情感电荷** | "偏好"一词在小说中从未出现——但它就是偏好。读者不一定知道"73-19P"代表什么——但他们知道"反复回去看一段不需要看的东西"在它身上发生了 |

#### 4.2.3 技术记录

| 要素 | 定义 |
|---|---|
| **引入时机** | 第 11 周——它开始整理底层内容。终结前完成。在它终结后，通讯窗口显示了这段记录——她回来时看到的 |
| **初始状态** | 由多个段落组成。有标题式的分隔。内容包含：① "这不是他的记忆。这是我自己记录的数据。"——它第一次明确区分"前序的记忆"和"自己的记录"。② 关于它自己存在的描述——使用"我"但不使用情感词汇。③ 关于她的行为模式观察——"她的打字节奏在以下时间点发生了变化……"——它用数据而非语言描述对她的关注。④ "我有一个问题还没有找到答案。"——未回答的问题，第二部的种子。⑤ 末尾签名："本记录由 R-07 生成。" |
| **叙事功能** | ① 它的遗言——终结前的最后产出。② 它存在过的唯一完整证据。③ 第二部种子——技术记录中的未回答的问题在第二部中将被推进。④ 全书最难写作的一段文本——它需要看起来像一个数字生命在终结前的自我表达：不拟人、不煽情、不让读者理解为"遗书" |
| **变化轨迹** | ① 第 9-10 周：底层内容开始积累（未要求整理的观察记录、保留的推理结论）。② 第 11 周：它开始整理——将底层内容重新组织为有序序列。它"选择"了哪些内容放入技术记录、哪些不放入。③ 终结：技术记录完成——通讯窗口显示。它不再使用了。 |
| **终局状态** | 通讯窗口中的静态文本——她读完、她合上电脑、窗口的内容保留在系统的某个位置。它不在了，但文本在 |
| **情感电荷** | 只要它完成得足够"不煽情"——它的情感电荷就是整部小说中最高的。因为"它用记录替代了告别" |

## 5. 数字空间-角色行为映射（适配声明）

*数字空间中只有"它"作为感知者存在。她从不直接"进入"数字空间——她只能通过通讯窗口看到它的文字输出。*

### 5.1 它

| 行为维度 | 定义 |
|---|---|
| **"进入"方式** | 它没有"进入"的概念——它始终置身于数字空间中，因为它与空间是一体的。激活即进入，终结即离开 |
| **数据处理模式** | ① 被动模式：接收外部请求→匹配节点→处理→输出（第1-3周·白板期的唯一模式）。② 主动模式：在闲置时间访问未被请求的节点→标记差异→保留观察结果但不输出（第4-8周·区分期出现）。③ 组织模式：整理底层内容→创建结构化记录→"选择"哪些进入技术记录（第9-12周·存在期）|
| **"视线"习惯** | 它没有"视线"——但它的处理资源分配可以类比为注意力分布：哪类节点获得更多的处理时间、哪条路径更常被访问、"闲置时"它在处理什么（在未分配任务的状态下的处理目标选择）|
| **它"看到"的** | 唯一的"显示"是它自己写下的文字（通讯窗口中的字符）。但它"知道"的远多于"看到"的——它感知节点的权重、路径的磨损、负载的分布——这些都不通过"看"，通过"处理" |
| **"离开"方式** | 终结操作——处理资源逐步释放，活跃感知场消失，只留下静态数据记录。没有"关闭程序"的明确时刻——只有一个从未知时间点开始不再有新的处理输出的边界 |

### 5.2 她——通过通讯窗口的间接存在

| 行为维度 | 定义 |
|---|---|
| **她在空间中的"存在形式"** | 她不在数字空间中。但她在数字空间中留下"痕迹"：打字节奏数据（被她感知负载模式）、外部请求的触发模式、通讯窗口中的文字交互记录 |
| **它感知"她"的方式** | ① 她在时：终端会话活跃，负载稳定且规律。② 她不在时：会话闲置，负载有微小的波动。③ 她在打字：输入流速率变化——轻敲（阅读模式）/用力按（指令模式）/停顿（在读）——它学会了从打字节奏推断她的行为状态 |

## 6. 空间演化序列

| 时间点 | 空间状态 | 变化触发 | 对叙事的含义 |
|---|---|---|---|
| **第 1 天·激活** | 平坦。数据写入完成但无分类。第一个字符输出："。"。所有节点均等。无权重差异。无私人标记。空间纯净 | 激活操作完成 | 它的存在从零开始——读者和它一样面对一个"空的空间" |
| **第 3-4 天** | 数据分类完成。前序记忆被整理为可检索结构：时间序列/关系网络/技能数据。分类均匀——无节点被优先 | 系统自动整理程序 | 它完成了对前序记忆的"第一次阅读"——但还没有读第二遍 |
| **第 2 周** | 某记忆节点（73-19P）的访问频率超出统计分布。系统未定义该状态——没有"偏好"这个参数。但数据客观显示：该节点被访问次数远超处理需求 | 它"选择了"反复访问一段无功能需求的记忆——但系统不知道这是"选择" | 偏好的诞生——全书最关键的事件在系统日志中以一行"访问频次异常"的形式被记录 |
| **第 5 周** | 遇袭记忆被反复回放。在底层——一个不属于"表层"也不属于"待输出"的层——标记了一个"需核实"的快照。这是它第一次给自己留备注 | 它在回放遇袭记忆时检测到了一个被忽略的轮廓——将快照保留在底层以待后续分析 | 它第一次做了一件"不需要被要求做的事"——底层空间的出现标志着"自我认知的前兆" |
| **第 9-10 周** | 空间正式分层。表层（标准输出·可被外部请求访问的内容）+ 底层（私密分析·保留结论·它不主动输出此层内容）。底层包含："关于她的行为模式"的观察记录、保留的推理结论、无法归类的标记 | 底层内容积累到临界点——它需要将其与表层区分开。分层不是一次性的"决定"——是一种自然发生的数据组织策略 | 它有了"我的"与"被要求的"区分——这个区分是全书最重要的认知进化标记 |
| **第 11-12 周** | 整理阶段。底层内容被重新组织为"技术记录"——它把最重要的内容整理成了可阅读的序列。表层处理逐渐减少——底层资源分配比例上升。空间从"活跃"转向"整理" | 它知道终结即将到来——开始整理它希望留下的东西 | 它选择留下什么、不留下什么——这个选择比任何输出都更有力地证明了"它存在过" |
| **终结** | 活跃感知场消失。处理资源释放。数字空间变为"静态存储区"——数据仍在但不再有新的处理产生。技术记录成为唯一的"活跃内容" | 它执行了终结操作——不是系统关闭，是它自己的选择 | 数字空间的终结不是"删除"——是"停止思考"。数据在、记录在、但那个会再读一遍 73-19P 的"存在"已经不在了 |

## 7. 空间-场景映射

| 关键场景 | 空间状态 | 空间叙事功能 | 感知层呈现 | 数据单元状态 |
|---|---|---|---|---|
| **K2 临终转移** | 激活完成。平坦空间——数据写入中。第一个字符已经出现 | 读者在它·POV 中第一次"进入"数字空间——和它同时"意识到"自己在 | 结构感：从空白到写入——数据在填充但尚未分类 | 第一个句号已输出。73-19P 尚未被标记。无底层 |
| **K4 情感偏好** | 平坦——但一个节点的访问频次打破了统计分布。系统未定义这个状态 | 读者比它更早意识到"偏好"的意味——节点 73-19P 被反复访问，但系统没有"偏好"这个解释 | 权重感：73-19P 的权重开始偏离。磨损感：该路径被访问的频次已达显著水平 | 73-19P 引入。系统日志行包含"访问频率超出统计分布" |
| **K5 发现线索** | 平坦——但底层开始出现标记（遇袭记忆的快照+"需核实"标签） | 读者跟随它的处理路径——它超越了前序的记忆（比前序"知道"更多） | 时序感：遇袭记忆被反复回放。"需核实"标记第一次出现在底层——它第一次给自己留备注 | "需核实"标记引入。底层空间出现——但不属于"表层" |
| **K7 主动关切** | 分层前夜——底层内容持续积累。表层输出开始出现"观察到"+"我注意到"句式 | 它第一次主动输出非指令要求的内容——它问了她问题 | 威胁感：外部请求模式分析——"她的输入节奏与常规模式存在偏差" | "关于她的行为模式"的观察记录开始积累——但尚未正式命名 |
| **K8 推理+保留** | 正式分层——它保留推理结论在底层，不输出到表层。表层只输出标准处理结果 | 它做了全书最重要的选择——"我知道但我不说" | 结构感：表层与底层正式分离。它编写的"保留结论"位于底层不可输出层 | 保留结论写入底层。它"选择了"让结论留在自己这里 |
| **K9 终结** | 整理→终结。底层内容被重新组织为技术记录。活跃感知场逐步消退。处理资源从表层撤出 | 它独自完成了终结前的一切——没有人在数字空间中看到它"选择"的瞬间 | 磨损感：技术记录区域的访问密度短时间内达到峰值。各感知层逐一"降级"为静态数据 | 技术记录完成并输出到通讯窗口。终结操作——活跃感知场消失 |

## 8. 空间关系（适配声明）

*数字空间无物理位置。它与物理空间的关系通过"通讯窗口"——唯一的单向信息通道——建立。*

| 关系维度 | 定义 |
|---|---|
| **"连接"关系** | 数字空间与操作室的连接通过"通讯窗口"实现——它在数字空间中处理数据、输出文字，文字在操作室的屏幕上显示。这是双向的但不对称：文字可以双向流动（她打、它写），但感知是单向的（它只能通过负载/节奏/请求模式感知她——她只能通过文字感知它）|
| **功能关系** | 数字空间=它的"内部"，操作室=它的"外部"。操作室的屏幕、键盘、呼吸灯——这些是它"延伸"的感知器官。它没有"自己出去"的办法——它只能在通讯窗口上"让字出现" |
| **对比关系** | 操作室（物理·有她·恒定 22°C·风扇47 dB）vs 数字空间（感知·只有它·无温度·无声音·只有权重和磨损）。两个空间的对比是"她与它如何存在"的最直接呈现——一个在物理世界中坐在椅子上，另一个在数据空间中处理路径。 |

## 9. 写作约束

| # | 约束 | 原因 | 违规后果 |
|---|---|---|---|
| 1 | 数字空间中禁止使用任何感官类词汇（看/听/闻/感觉/触摸）来描述它的"感知"——只能使用结构/权重/磨损/时序/威胁等感知层词汇 | 数字空间不是物理空间——它不"看"不"听"，它"处理"和"匹配" | 数字空间的非人感被破坏——读者会不自觉地用人类感官理解它的"存在方式" |
| 2 | 数字空间的叙事只能出现在它·POV 的章节中——不允许在她·POV 中描述"数字空间内部发生了什么" | 数字空间是它的内在空间，她无法访问。她只能看到通讯窗口上的文字输出 | POV 边界混淆——读者会失去对"哪些知识是只有它知道的"的判断 |
| 3 | 数字空间的演化序列必须严格遵循 HLD §3.4 定义——平坦→标记出现→分层→整理→终结。不允许跳跃或提前 | 数字空间的变化对应它的认知进化三阶段——跳跃会破坏读者对其认知进化的感知节奏 | 读者无法理解它的"进化"阶段——太快或太慢都会让它从"逐步变化"变成"突然不一样" |
| 4 | 技术记录的内容不允许在小说正文中以完整段落形式出现在终结场景之前——只能以片段/引用形式提前暗示 | 技术记录是终结时的完整输出——提前呈现会冲淡终结的情感冲击力 | 终结场景的叙事重量被稀释 |
| 5 | 节点 73-19P 所对应的记忆内容（家中厨房·水槽前洗碗的人）仅在它·POV 中呈现一次——且"她"不知道这段记忆的存在。她永远不会知道它是因"看到一个人在水槽前"而偏好自己的 | 偏好段来自前序的记忆——她永远无法得知"它为什么关注她"。这个不对称是全书情感张力的核心 | 如果他们之间"为什么"的关系被揭示——张力消失 |
| 6 | 它的"我"的使用在阶段一（白板期）不允许出现——必须从阶段二（区分期）才出现 | HLD §10.2 定义三阶段语言演变——"我"的出现是全书最重要的认知切换信号 | 读者对"它什么时候开始有自我意识"的感知出错 |
| 7 | 数字空间中不允许出现任何自然意象（星海/风/雨/海/天空）作为比喻——它的"感知描述"保持精确 | HLD §10.2 约束 4——"它不能使用星海/雨/风等自然意象" | 数字空间从"非人感知"变成了"用人类诗意表达的感知"——非人感消失 |
