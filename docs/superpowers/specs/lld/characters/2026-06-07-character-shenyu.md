边界声明：LLD 只把 HLD 已确定的功能和关系材料化为可写作的详细设定，不增加主线，不变更场景功能，不输出小说成稿。


## 2. 角色详细设计

| 项目 | 设定 |
|---|---|
| HLD 功能 | 主角层；越界保护者；人类情感锚点 |
| 弧线 | 正向变化弧：从职业身份到承认越界 |
| 核心需求/功能 | 承认自己已经越界，并理解自己为什么要保护一个非人存在。 |
| 行为标记 | 以停顿、未上报、修改措辞、延迟离开、读记录、不关屏幕作为行为标记。 |
| 语言规则 | 短句、少解释、低情绪命名；内心不直接说明，靠动作和空间状态外显。 |
| 主要场景 | K2 接收，K3 第一次沉默，K6 主动承担风险，K7 被关切，K8 承受调查，K10 面对空缺。 |
| 主要空间 | 操作空间、会议室、住所、走廊；空间变化必须映照她的职业边界松动。 |

## 3. 行为标记矩阵

| 场景阶段 | 可写作行为 | 不可写作偏移 |
|---|---|---|
| 植入 | 建立角色的默认行为和职责位置 | 不提前解释主题结论 |
| 渗透 | 让行为出现小幅偏移，并能被空间或他人看见 | 不直接说明内心答案 |
| 震荡 | 行为必须承担代价或信息后果 | 不用口号替代选择 |
| 终结 | 行为回收角色弧线 | 不改写自主终结和不可确证情感 |

## 4. 路线节点材料化

本角色参与的路线节点必须转化为动作、停顿、信息处理、空间位置和可回调物件。角色不能重新定义 PRD/HLD 中的路线方向。

## 5. 空间详细设计引用

角色出场空间以 HLD v4.0 的空间架构为准。写作时优先调用对应空间子文档的感官矩阵和物件状态，避免临场新增高戏剧化道具。

## 6. 关键场景设计引用

本角色在关键场景中的行为必须服从 K1-K10 的 HLD 功能。LLD 可细化“怎么做”和“被什么材料承载”，不可改写“场景为什么存在”。

## 7. 感官与回调材料

| 材料类型 | 使用方式 |
|---|---|
| 行为回调 | 同一动作在不同阶段改变速度、次数或完成度 |
| 语言回调 | 重复句式或称谓变化只作为状态信号 |
| 空间回调 | 同一空间的物件状态承载角色变化 |

## 8. 写作指引与禁用项

- 写作指引：使用外显行为、场景压力和信息差呈现角色。
- 禁用项：不替角色解释主题，不新增主线，不输出小说成稿，不给关系命名。

## 9. Writing Agent 交付包

Writing Agent 可消费：角色功能、弧线、行为标记、语言规则、场景参与点、空间引用、感官回调材料。
