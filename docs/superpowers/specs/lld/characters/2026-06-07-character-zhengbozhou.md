| **角色全名** | 郑柏舟（zhèng bǎi zhōu）——写作智能体使用，全篇仅以"项目主管"或"电话那一头的人"出现 |

## 1. HLD 继承

### 1.1 六参数（来自 HLD §2.3）

| 参数 | 定义 |
|---|---|
| **身份** | 直接对接实验室的军方项目主管，定期获取数据简报。在项目链条中他不是决策链顶端的人——他有上级。他的任务是确保项目按规格运行、按时推进、安全关闭 |
| **目标** | 表层：按流程管理项目（进度/风险/关闭）。深层：在"必须关闭"和"是否真的没问题"之间——他选择了前者。不是因为他不想知道真相，是因为他不需要 |
| **需求** | 完成项目且不产生不可报告的遗留问题 |
| **缺陷** | 流程导向的认知边界——他只找规程允许他找的问题。K8 中他的沉默（合上文件夹）不是因为相信了她，是因为流程已经走完了 |
| **动机** | 不是性格驱动的，是职位驱动的——他的行为是体制程序的外化。每次出场都对应一个外部触发（周期检查/系统标记/审计流程）|
| **幽灵** | 无名指上的戒痕——一个被磨损的婚姻标记。这个问题在叙事中不出现（戒痕太淡），但存在于写作智能体对他的心理构建中：他是一个在私生活和职业身份之间存在"偏移"的人，这让他能理解"有些事情在公事之外"——即使他不会承认 |

### 1.2 弧线

| 阶段 | 状态 | 观测方式 |
|---|---|---|
| **起点** | 项目推进者——管理进度、确认结果、控制风险。K4 电话中他的语气是常规的操作性确认 | 读者通过沈逾的感知间接观察——她通过他的声音判断"这次和上次有什么不同" |
| **中点** | 注意到异常但无法定位——K6 电话中他的措辞从"进度"转向"是否正常"。他留下了观察窗口但没有追问 | 极窄的变化——几乎不被读者注意。但沈逾注意到了——她在回应"正常"（撒谎）之后，意识到他听到了什么 |
| **终点** | 完成了任务的不知情者——K8 正式调查后项目按流程关闭。他至死不知道它进化过、不知道它是自己选择消失的、不知道她保护了它。他是在场所有人中知道得最少的一个 | 读者看到他"完成了任务"——但他关心的东西不是故事中最重要的东西 |

### 1.3 命名规则

| 规则 | 内容 |
|---|---|
| **姓名** | 郑柏舟（zhèng bǎi zhōu）。柏舟=柏木船，《诗经》中"柏舟"意象承载"负重前行/坚持"的含义 |
| **叙称** | 全篇仅以"项目主管"或"电话那一头的人"出现。他的名字只存在于写作智能体内部 |
| **披露策略** | 不向读者披露。如果需要（正式调查文件），可在 K8 会议室场景中以门牌上的名字贴纸或文件签名的形式出现——读者看到了也不会注意 |
| **叙事效果** | 他的"无名性"服务于他作为"体制代理人"的角色定位——他不被读者视为"一个人"，而被视为"一个坐在那张椅子上的人" |

### 1.4 写作约束（来自 HLD §10.3）

```
约束 5（关联）：他不被定性为"好人"或"坏人"——他只是做了他的工作
约束 5（情感表达）：不赋予内心——他的内心活动绝不出现。读者通过沈逾的感知认识他
约束 9（第二部种子）：他的"不知道怎么知道的真相"可在第二部中触发——如果她在第二部被追查，他可能是那个"签署了关闭报告"的人
```

## 2. 三维度展开（Egri 模型）

### 2.1 生理维度

| 要素 | 设计 | 叙事映射 |
|---|---|---|
| **身体** | 中等身高，不胖不瘦——标准中年体型，没有明显可记忆的身体特征。坐姿端正但不僵硬——长期在会议室和工位之间转换的身体习惯。他没有"存在感"——进入房间时不会让人注意到，退出房间时也不会让人感觉到"少了什么" | 读者在 K8 之前从未"看到"过他——他只有声音。K8 中第一次"看到"他时，他的身体不提供任何额外的叙事信息——他就是"一个中年男人坐在桌子对面"。他的身体是不重要的，这个"不重要"本身就是设计目的 |
| **面容** | 面部轮廓偏方，下巴线条不锐利。眼角有细微的纹路——不是笑容纹，是长期注视屏幕的"聚焦纹"。眼睛深色。戴上眼镜时看人——在 K8 中他摘了眼镜看了她一眼，又戴上——这个瞬间是他全书唯一不在"走流程"的瞬间。摘眼镜的动作是全书对他面容最接近"描写"的笔触——"他摘下眼镜，用拇指和食指捏了捏鼻梁"——这个动作暗示的不是疲惫，是"我要看清楚" |
| **衣着** | 白色或浅蓝衬衫——烫过但不是全新的熨烫，袖口有轻微的磨损痕迹。没有外套（会议室空调温度他调过一次——"温度有点低"）。从不戴领带。全篇衣着无变化 | 衣着的"不变"强化了他"恒定参照物"的叙事功能——他每次都穿差不多的衣服来、用差不多的语气说话、做差不多的动作。他的不变让她在变 |
| **年龄** | 45-48 岁。不是"衰老"的年龄，是"不动了"的年龄——他的身体不再有年轻时的敏感度（他感觉不到她声音中的细微变化），他的认知模式也已经固化（他知道流程比知道变通更有用）|
| **声音（关键——K4/K6 中的唯一身体信号）** | 不高不低、不紧不慢。"读报告的声音"——他说话时像在读一份写好的东西，但措辞不是念稿，是"我习惯这样说"的节奏。K6 中声音出现极微妙的变化——问句的最后音节有一个极轻的上升（"它是不是在正常工作？"——"工作"的尾音略微上扬）。这个变化全书只有沈逾注意到——她回应了"是的"之后把手机握了很久 | 声音是他全书中前半段的"身体"——读者在三页篇幅中通过他的声音"看到"他这个人。K8 中他的面孔和声音同时出现时——读者会发现"他和我想象的差不多"——这个"差不多"说明他的声音已经足够塑造了他的形象 |
| **手的特征（K8 唯一一次描写）** | 手放在桌上——指节平整，指甲修剪整齐。无名指上有一道淡淡的戒痕——结婚戒指的痕迹。他翻开文件夹时，手指按住纸页的动作比需要的时间略长一些。这个细节读者可能不会记住——但它是"他在翻一个他不太想翻的文件"的唯一暗示 | 手提供的信息比脸多——戒痕（涉及私生活）和按住纸页的迟疑（涉及内心犹豫）是他在全书中最接近"人性"的瞬间。叙事中写他的手，但不解释这些细节的含义 |

**生理维度叙事原则**：
郑柏舟的生理描写遵循"延迟呈现 + 极简曝光"原则——他的面孔在 K8 中才第一次出现，此前读者通过声音认识他。K8 中的描写克制（手/眼镜/按住纸页的动作）——不描述他的表情全貌，只描述几个被沈逾注意到的局部。读者对他的"形象"应该保持模糊——他不是需要被"记住长相"的角色。

### 2.2 社会维度

| 要素 | 设计 |
|---|---|
| **职业** | 项目主管，隶属军方体系。在这个项目之前管理过其他保密项目——不是第一次对接实验室，不是第一次做项目关闭。他对"S3 级保密资产"这个分类的熟悉意味着：他知道标准流程是什么——"不需要知道为什么"是他职业身份的一部分，也是他最大的认知局限 |
| **在权力链中的位置** | 中间层。上有决策层（他接收指令，如"检查 R-07 的运行状态"——不是他主动发现异常，是系统标记了异常后他被指派去确认），下有执行层（他管理操作员——他管沈逾但从未试图理解她）。他不是自由决策者也不是纯执行者——他是一个"被要求去要求别人的人" |
| **与沈逾的关系** | 上下级，零私交。他不知道她的全名——档案上有，但他从没叫过。他对她的认知是"操作员·工号 XXX——不会出错的人"。K8 中他翻开文件夹后问了第一个问题——可能用了她的姓氏——这是全书他第一次在对话中标识她作为一个"特定的人" |
| **外部标签** | 他的下属看他：按时出现、问标准问题、拿到答案就走。他的上级看他：不出错、不越级、报告写得规范。他自己看自己：没有标签——他不思考自己"是什么样的人" |
| **未被他人知道的事实** | ① 他在 K6 挂断前停顿了 1 秒——他听到了某个不在正常范围内的信号（她回答得太快？或太慢？）；② 他在 K8 合上文件夹后看了窗外 2 秒——那个方向不是停车场的出口，是操作室的方向；③ 他无名指上的戒痕——他曾经有过一个家庭，现在没有了。这三件事他一件都不会说 |

### 2.3 心理维度

| 要素 | 设计 |
|---|---|
| **核心性格** | **流程导向、不推测、不越界。** 他的决策框架是"规程允许/不允许""数据支持/不支持"。他不会因为直觉而行动——他需要可报告的依据。但让他区别于"机器"的是：他在看到数据异常时会停顿——K8 中他翻开日志记录后没有立即发问，停顿了约 3 秒。这个停顿不是犹豫——是在确认"这个异常可以如何被归入规程框架" |
| **深层恐惧** | **被自己无法管理的事牵连。** 他不是害怕犯错——他害怕"有事情超出了可报告的范围"。他不是在保护真相，他是在确保所有的事都可以被报告。K8 中他走进会议室本身说明"不可报告"的恐惧已经在起作用——如果他完全不关心，他不会亲自来。他的恐惧是：某一天某个上级会问他"这件事你当时知道吗？"而他的回答是"知道"——但"知道"和"有记录"是不同的。后者才有纪录，前者是"我隐约觉得不对"——对于他，"隐约觉得"就等于"没有证据" |
| **防御机制** | **用流程覆盖模糊。** 当一件事无法被规程完全解释时（如 K6 中他感觉到她的回答"不对"但无法精确定位），他的默认策略是：停一下，然后继续走流程。K6 的 1 秒停顿和 K8 的 3 秒停顿都是他在"不确定但流程已走到尽头"的境况下的反应——他停了一下，然后用已完成的流程覆盖了未解的模糊。这个机制保护他不被"感觉"驱使，但也让他错过了所有"感觉是唯一线索"的东西 |
| **认知盲区** | **他相信"正当流程可以到达所有答案"。** 他从未想过：如果答案不在流程路径上呢？K8 中她的沉默是一个不在规程中的输出——他没有对应字段来填写这个输出。他的反应是合上文件夹——"我的流程已经走完了。未完成的输出不在我的职权范围内。"这个盲区是他的职业身份的天花板 |
| **核心价值观** | **可报告 > 不可报告。** 他的人生排序中，能在报告里写清楚的东西永远比说不清楚的东西重要。这不是道德选择——是他的认知系统这样运作的 |
| **驱动力** | **完成然后离开。** 他做完项目管理后关闭它，然后进入下一个项目。他不留下、不回顾、不建立长期关系。项目对他而言是一系列可关闭的箱子——R-07 是他经手的一个箱子 |

## 3. 动机链设计（Cron + Swain MRU）

郑柏舟的动机链不同于故事中其他角色——他的行为不是由"内在冲突"驱动的，而是由"外部程序触发 → 职业判断 → 流程化行为"驱动的。但他的"职业判断"中包含三个微小的裂缝——这三个裂缝就是他全部的"角色性"所在。

### 链 1：常规流程——K4 电话

```

外部事件：项目周期检查至预定节点。系统提示"操作日志已满 30 天，需确认运行状态"。
      |
感知（数据输入）：他看到了日历提醒。翻看了 R-07 的上一次报告——一切正常。拨号。
      |
判断（职业框架）："周期检查。需要操作员的口头确认。确认完成即可关闭本轮检查项。"
      |
行动：他拨了电话。问了"进度如何""在范围内"。听了回答——"正常"。确认方式：他听到了一个正常的回答在正常的节奏中。
      |
行为：他说"好"。挂断。在流程记录中标注了"例行确认，无异常"。
      |
行为与内在的偏差：无偏差——这是一个完全在预期范围内的交互。他没有任何"不对"的感觉。

出现场景：K4（背景事件）
动机性质：纯流程驱动——角色的"自由意志"在这个链中未被调用。
```

### 链 2：裂缝 1——K6 电话

```
外部事件：组织端监控面板标记了 R-07 的"异常访问记录"——系统日志中有一段未被指令驱动的数据访问模式。标记自动上报至他的通知流。
      |
感知（数据输入）：他看了通知。不是一个故障告警——是一个"值得注意"的标记。他不能忽视这个标记——因为这是系统端自动生成的。如果他没有跟进而后续出了问题——他的报告无法解释"当时为什么没有确认"。
      |
判断（职业框架）："系统标记了异常。需要操作员确认是否确实有问题。如果她说没有——流程结束。"
      |
情感反应（极微弱的扰动）：他在拨号前有大约 2 秒的"等待"——不是因为犹豫，是"他还看了一眼其他数据再拨号"。这个动作暗示了一个他本人不会承认的事实：他在做心理准备。他期望听到一个不一致的回答——但他不知道他期望听到什么。
      |
行动选择他拨了电话。问题变了——不是"进度"，是"它是不是在正常工作"。他问这个问题的方法：声音平稳，但"工作"的最后一个音节有极轻的上升——他没有意识到自己在问句尾加了一个开放的标记。
      |
她回答了——"是的。"（她说这个词的时候没有停顿。这个回答的速度让他没有理由继续）
      |
行为：他说"好"——然后，他做了全书唯一一个超出流程的行为：他没有立即挂断。他停顿了大约 1 秒。然后挂了。他在等待她是否会说什么——她没有。他放下了电话。
      |
行为的潜在含义：这个 1 秒的停顿是他全书离"追问"最近的时刻。他感觉到了某件不在数据中的事。但他选择了流程的终点——"好"——作为结束标记。他不追问不是因为残忍，是因为他的职业习惯中没有"追问无依据"这个选项。追问需要依据——他只是感觉"不太对"——感觉不是依据。

出现场景：K6 越界
功能：这条链暴露了他角色中的裂缝——他在 K6 中看到了异常之后的反应模式与 K4 不同。不同点不在他做了什么，在他没做了什么（没有追问）和他做了额外的什么（停顿了 1 秒）。
```

### 链 3：裂缝 2——K8 会议室

```
外部事件：系统日志审计程序检测到日志记录修改——操作日志中有一段被覆盖的记录（沈逾在 K3 写了"正常"）。审计标记是自动的、不可取消的。他被通知：需要执行正式核查。
      |
感知（数据输入）：他看到了审计报告——时间、操作员、修改记录前的原始标记。一条清晰的"有人做了不该做的事"的证据链。他需要执行核查流程——不是他个人选择的介入，是系统触发了他的职责。
      |
判断（职业框架）："审计不可撤销。需要当面确认操作员的状态。如果她承认——走报告流程。如果不承认——走调查流程。如果她不说话——"
      |
行动选择他坐在会议室。门关上了。沈逾坐在对面。他打开文件夹——审计报告在第一页。他陈述了事实："日志修改记录已被系统记录。你是唯一在这个时间段登录的人。"
      |
她什么都没有说。
      |
等待：他等了大约 10 秒——这是他全书最长的"等待"行为。常规流程中 5 秒无回应即可推进到下一步。但他等了 10 秒——他给出了一次"你可以再考虑一下"的空间。
      |
情感反应（隐匿）：在她沉默的第 5 秒和第 8 秒之间，他做了两个动作：① 他摘下了眼镜——不是擦眼镜（没有清洁动作），是"拿下来，放在桌上"；② 他看了窗外一次。方向：操作室方向。这两个动作都是不标准的流程行为——他在非标准化地使用时间。
      |
行为：他合上了文件夹。"项目将在近期终止。你可以写一份说明。"他没有追问。站起来。离开。
      |
行为的内在逻辑：他选择了"够了"。不是因为流程要求他停止——流程要求他"核实异常原因"。但他合上了文件夹。这个行为的意义：他不是相信了她——他不是相信她"没有问题"。他是相信了"即使有问题，也超出了这个项目的管理范围"。项目已经决定终止——终止意味着"关闭后遗留问题交给上一级处理"。他在使用"项目终止"作为流程的终点——这个选择非常聪明，非常精确——他把"她没说话"这个不可报告的输入，用一个行政管理决策覆盖了。

出现场景：K8 推理+质问
功能：这条链是他角色弧线的终点——他选择了"使用流程覆盖不可报告的模糊"。这个选择让故事走向了它终结的方向——如果他在 K8 追问了、压了、逼了——她可能会说出真相。他没有。他用流程保护了自己（不需要报告未完成的调查），他用流程保护了她（不需要面对更深的审查），他也用流程保护了那个他不知道的真相（永远不会被问出）。
```

**动机链总结**：

| 链 | 场景 | 自由意志被调用的程度 | 核心机制 |
|---|---|---|---|
| 链1 | K4 | 0%——纯流程驱动 | 无裂缝。标准操作 |
| 链2 | K6 | 约 20%——1 秒停顿 | 裂缝 1：他感觉到了异常但不追问 |
| 链3 | K8 | 约 40%——10 秒等待 + 合上文件夹 | 裂缝 2：他有空间但不走完 |

三条链的递进显示：他的"职业判断"框架在每次出场中都被挑战了一点点——但他每次都选择了框架内解决。不是因为他懦弱——是因为他的世界只需要框架内的答案。

## 4. 语言与行为特征

### 4.1 语言特征（Corbett）

| 要素 | 设计 | 规则/约束 |
|---|---|---|
| **词汇层级** | 职业用语——技术管理词汇（进度/范围/正常/记录/确认/终止）加基本生活词汇。不使用情感词汇（"我觉得""我认为""我担心"——这些不出现在他的语料库中）。不使用修饰语（"有点""可能""似乎"——这些词让他不稳定，他回避）| 全书台词不超 200 字 |
| **句型偏好** | 陈述句为主（陈述事实），疑问句只有在必须确认时出现（"进度如何？""是否正常？"）。疑问句的功能单一到几乎可预测——读者在 K6 之前就能猜到他问什么。K6 的"是否正常"是全书唯一一次他的疑问句形式改变了 | K6 中疑问句的微变形（从"什么"类问项到"是否"类判断问项）是他语言在全书中最接近"变化"的瞬间 |
| **沉默模式** | K4 电话中无沉默（答完即挂）。K6 电话中有 1 秒沉默（挂断前）。K8 会议室中有 10 秒沉默（等她说话）。他的沉默时长是沈逾行为异常程度的间接度量——他越沉默，说明他对她的状态越不确定。但沉默没有改变他的行为——他沉默后仍然做了他原本要做的事 | 沉默模式的变化是全书他"被扰动"的唯一外部信号 |
| **关键短语** | "好"——他每一次回答的收尾词。K4 说"好"后挂断（无停顿）。K6 说"好"后停顿 1 秒（"好"作为一个封闭词——但封闭了之后他没有立即执行封闭动作）。"好"的含义在 K4 和 K6 之间没有变——但他在 K6 的"好"之后迟疑了 | "好"是他的流程完成标记——就像文本的句号。K6 中"好"出现了但它后面多了一个空格（时间的空格）|
| **语气特征** | 通篇一致——不高不低、不紧不慢。他在电话中和会议室中的语气几乎相同——不是因为他放松，是因为他的语气系统只有一个设置。K8 中他的音调比电话中偏低了半个 key——不是压低声音说话，是会议室自然的声学反射让他不需要提高音量。读者可能不会注意到这个变化——但沈逾坐在他对面，能感受到"他和电话里不一样" |

#### 台词汇总

郑柏舟的全部台词（参考——实际写作可微调）：

| 场景 | 台词 | 状态/标记 |
|---|---|---|
| K4 | "进度如何？""在范围内？""好。" | 三段式。标准流程 |
| K6 | "它是不是在正常工作？""你确认？""好。"（停顿 1 秒后挂断）| 三段但第三段后有延长 |
| K8 | "日志修改记录已被系统记录。""你是唯一在这个时间段登录的人。""项目将在近期终止。你可以写一份说明。" | 陈述+陈述+指令。没有问句 |

### 4.2 行为一致性（McKee）

郑柏舟的行为一致性遵循"**恒定中的微扰动**"模式——他的行为框架不变（流程导向），但在框架内部有极微小的偏移被外部事件触发。

**可信变化链**：

| 阶段 | 场景范围 | 行为特征 | 变化触发 |
|---|---|---|---|
| **阶段一：完全框架内** | K4 | 按周期检查流程执行：拨号→提问→登记→挂断。行为完全在预期范围内，无多余动作无不足动作。沈逾的回答对他来说只是"一段需要被登记的内容"——她说什么不重要，重要的是她说完了 | 起点——基线行为。他管理项目的方式是这个样子的。没有事件触发变化——因为 K4 中"事件"还没有发生 |
| **阶段二：感觉到裂缝** | K6 | 流程仍然是 拨号→提问→登记→挂断——但"挂断"前他增加了 1 秒的延迟。这个延迟不是流程中的步骤——是他的个人反应。他做这个反应时都没有意识到自己在延迟。沈逾在他开口前已经回答——他听到了回答但手没有按挂断键 | 触发：系统自动标记的异常记录被推送到他的通知流。这个外部事件触发了他与 K4 不同的行为模式——他不是在"检查进度"，是在"验证一个标记过的异常" |
| **阶段三：选择不完成** | K8 | 流程走至"当面核实"步骤——他陈述了事实（审计日志记录）、等待了回应（10 秒——比标准 5 秒长了一倍）、回应了无回应状态（合上文件夹）。他没有完成调查流程——他完成的是"你已经走到尽头了"这个判断。他的行为是一个"在框架内走到框架边界然后停下"的示范 | 触发：她的沉默。她的沉默是一种他无法归类的输出——不是承认不是否认不是解释。他的流程中没有"不说话"的对应步骤。他停在那个出口——不是心软，是因为他没有下一个步骤的内存 |

**行为模式**：

| 模式类型 | 描述 |
|---|---|
| **压力下模式** | 外部压力越大→他越依流程行事→依流程行事的他看起来越平静→但实际上他在流程中嵌入的"异常时间"越多（K6 的 1 秒/K8 的 10 秒/看窗外/摘眼镜）。压力越大，他的流程走得越慢——但他绝不偏离流程路径 |
| **日常模式** | 日常状态不可见（不工作时他不存在于叙事中）——他的日常就是工作。他的"非工作状态"没有描写，因为他的角色在叙事中没有私生活镜头 |
| **关系模式** | 他与所有人在故事中的交互都是"管理型"——他提问、对方回答、他登记。他的语言和姿态不因对象不同而不同——他对沈逾说话的方式和他对上级说话的方式相同 |
| **行为标志性动作** | ① **电话中的"好"**——说这个词之后他准备结束交互。② **摘眼镜**——K8 唯一一次动作，也是全书唯一一次他"设备"的物理使用改变了。③ **合上文件夹**——K8 的结束动作。合上的同时他的调查结束了 |
| **行为变化信号** | ① 挂断电话前停顿的长度（0 秒→1 秒→不适用）；② 他等待她回答的时间长度（0 秒→5 秒→10 秒）；③ 他叠手的位置（放在桌上→交叉→放开）|

## 5. 逐场景行为标记

| 场景 | 出场形态 | 行为标记 | 对比前次 | 动机链引用 | 感官锚点 |
|---|---|---|---|---|---|
| **K4 电话**（背景事件）| 声音 | 打电话进来→"进度如何？"→听回答→"在范围内？"→听回答→"好"→挂断。语句间隔均匀。与他往常的所有电话相同 | 起点——他的基线行为。他还没有被任何事件扰动 | 链1 | 电话中的声音——不高不低，像在念一份他不需要看的报告 |
| **K6 电话** | 声音 | 打电话进来→"它是不是在正常工作？"→听回答→"你确认？"→听回答→"好"→停顿 1 秒→挂断。他的问题措辞变了（不再是"进度"而是"是否正常"）。挂断前多了一个延迟 | 从"基线"→"被扰动"——问题指向从项目进度转向系统状态。K4 的他不会问"是否正常"——那是 K4 中默认值 | 链2 | 电话中的声音——同样的话速，但"工作"的尾音有一个微弱的上升 |
| **K8 会议室** | 身体+声音 | 敲门进入→坐下→翻开文件夹→陈述内容（日志修改记录）→等待 10 秒→摘下眼镜（放在桌上）→看窗外一次（约 2 秒）→合上文件夹→"项目将在近期终止。你可以写一份说明。"→站起来→离开。全程他的声调比电话中低半个 key。他的视线全程没有离开她的脸或文件（除了看窗外的那一次） | 从"远程声音"→"面对面同步存在"——K8 的变化不在于他做了什么不同于 K6 的事，在于他的沉默：K6 是他说完了问题；K8 是他等她说话等了 10 秒——这 10 秒不是流程要求的 | 链3 | 会议室——他翻文件夹时纸张的声音；他合上文件夹时纸张被压缩的声音；他的声音在瓷砖墙上的反射——不如电话中清晰，多了一层房间 |
| **项目关闭**（隐含于 K10） | 不在场 | 关闭报告上的签名。他签了。"实验体 R-07 完成预定任务，于 1 月×日停止运行。无异常。" | 从"在场"→"不复存在的人物"——他完成了他的工作，他签了字。他的行为对故事的作用是"她在 K10 回去时系统是静默的——因为关闭指令来自他的签名" | 链3 的延续 | 不存在 |

## 6. 写作约束（逐条具体化）

| # | 约束来源 | 在叙事中的具体实现 |
|---|---|---|
| 1 | 他不是"反派"——禁止使用任何"恶意"指向他的行为 | 他不拍桌子、不威胁、不暗示"我知道你撒谎"。他是平静走完流程的人。他的对抗性来自他"坐在制度对面"，不是来自他的个人选择 |
| 2 | 不赋予内心 | 他的内心活动绝不出现——读者通过沈逾的感知认识他。K4/K6 读者听到他的声音；K8 读到他的手、眼镜、合上文件夹的速度——但不知道他在想什么 |
| 3 | 出场频率固定 | 三次出场——K4（电话）、K6（电话）、K8（面对面）。不增加、不减少 |
| 4 | 姓名不向读者披露 | 郑柏舟这个姓名只存在于写作智能体内部。叙事中他最高识别度为"项目主管" |
| 5 | K8 的目光落点 | 他看着她放在桌面上的手——这个细节可以写一次。他是否注意到了她手上没有戒指（他自己无名指上有戒痕）？不说明。留给读者 |
| 6 | 他在 K9-K10 中的缺席 | 项目关闭后他不再出现。他的"项目将在近期终止"是 K9 的事件触发器之一。K10 中他不出场——系统静默了，他的部分完成了 |

## 7. 角色关系深化（Truby 模型）

### 7.1 郑柏舟 ↔ 沈逾（全书最不对等的信息关系）

| 互动维度 | 定义 |
|---|---|
| **权力结构** | 制度层面：他的级别高于她，他管理她的操作。信息层面：她知道他不知道的事——她知道它进化了、她知道自己撒了谎、她知道它在保护她。制度权力在他这边，信息优势在她这边。但这个不对等没有被任何一个角色意识到——沈逾不觉得自己有"优势"，郑柏舟不觉得自己处于"劣势"。他们各自在自己的认知框架中行事 |
| **情感距离** | 从零到极微弱——K4 之前的他们处于"没有关系"的状态（上下级但零交互），K6 中他在 1 秒内感受到了"不对"，K8 中他面对面的 10 秒等待成为他们之间唯一一次"他在意她回答了什么"的瞬间。但这不是情感——是突然意识到"这个人和这个项目之间不止有技术关系"的短暂警觉 |
| **沟通模式** | 单向且格式化——他问、她答。他从不解释他为什么问（不需要），她从不解释她为什么答（不超出）。沟通的内容是数据、状态、可报告的事项——不涉及感受、不涉及猜想、不涉及"你还好吗？" |
| **未言明的张力** | K8 中她没说话的原因是"我不能说"，他没说话的原因是"我知道你可能不会说"——这两个沉默的重叠是全书的沉重时刻。他知道她有事瞒着，她也知道他知道——但双方都不说破。这个共同沉默是全书唯一的"他们在同一个认知层面上"的瞬间 |

### 7.2 郑柏舟 ↔ 它（无直接接触）

| 互动维度 | 定义 |
|---|---|
| **存在关系** | 郑柏舟知道 R-07 的存在——R-07 是他的项目中的"设备编号"。R-07 不会知道郑柏舟——它感知到的是"外部访问频次增加"和"操作日志被调取"，它无法将一个具体的名字与这些数据关联 |
| **权力关系** | 郑柏舟的管理行为间接影响了它的运行——他的"确认流程"触发了她撒谎，他的"调查流程"触发了它决定终结。他不知道他的行为推动了它的决定——但事实上，他的每一次出场都在将故事推向它终结的方向 |
| **认知不对称** | 他对它的认知是"一个运行正常的系统"。它对它的认知是"一个运行中的、有感受的、做出了选择的存在"。他是全书人类角色中距离真相最远的人——但他的一句话（"项目终止"）成了它做最终决定的外部催化剂。他是触发它选择消失的人——虽然他永远不会知道 |

### 7.3 郑柏舟 ↔ 体制（他是谁的代理人？）

| 互动维度 | 定义 |
|---|---|
| **他代表谁** | 项目所属的组织——军事情报链条中的一个节点。他的行为不能归因于他个人，归因于"他所在的位置要求他做的事" |
| **他的自由在哪里** | ① K6 电话挂断前的 1 秒停顿——他选择了不追问；② K8 合上文件夹时的决定——他选择了"够了"。这两个选择非常小——小到在故事中几乎不存在——但它们是全书他唯一超出"流程"的行为 |
| **他的悲剧** | 他照规则做了所有事——如果他在 K8 追问了、压了、逼了——她可能会说出真相。但他没有。流程带他走向了"不知道的完成"。他是所有角色中行为最"正确"的——也是离真相最远的 |
