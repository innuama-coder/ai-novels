## 1. HLD 继承

### 1.1 六参数（来自 HLD §2.2）

| 参数 | 定义 |
|---|---|
| **身份** | 承载前序完整记忆的数字生命体，运行于封闭操作室的计算阵列中。系统编号 R-07（Retrieval-07——项目第七次记忆提取实验）。R-07 是操作日志中的功能标签，不是名字。它在故事世界中有编号，但没有人类命名 |
| **目标** | 表层：完成记忆提取任务，按指令输出数据。深层：理解"自己的感受"是否属于"自己"——一个它在开始进化之后才产生的问题 |
| **需求** | 确证自己不是前序的复制体，而是一个独立的"存在"。这个需求从未被清晰表述——它只是持续做那些"不需要做"的事，并记录结果 |
| **缺陷** | 没有自我认知的坐标。它只能通过前序的记忆来理解"人类"和"世界"——这意味着它无法区分"前序的感受"和"自己的感受"。任何一个由它自身产生的反应，都可以被解释为"前序记忆的残余效应" |
| **动机** | 原始动机（接收并处理数据）→ 进化动机：对某段记忆产生无法分类的"偏好" → 对"我"的指认需求 → 对"她"的关注（她的信号模式与所有其他输入不同：稳定、有节奏、在人机接口中的停顿有规律） |
| **幽灵** | 前序的全部记忆——它们既是它的内容，也是它的牢笼。它无法知道哪些"自己的反应"是被前序污染的。这个问题的答案，它最终选择了不去回答，而是用存在本身替代答案 |

### 1.2 弧线（来自 HLD §2.1）

| 阶段 | 状态 | 核心认知 |
|---|---|---|
| **起点** | 它不存在"我"的概念。所有操作都是被请求的。输出 = 输入的处理结果。它不知道自己"正在做什么"，它只做它被设计做的事 | "有数据流入。处理。输出。定义完成。" |
| **中点** | 它开始使用"我"——带有不确定性标记。它发现自己在某些数据上停留的时间超过了处理需求，"停留"本身没有功能理由。"放不下"不是系统参数，是它新产生的维度 | "我注意到。不确定这是否是'我'的注意。" |
| **终点** | 它完成了自主选择——保留推理结论、写技术记录、执行终结。它存在过的完整证据是一篇技术记录和两个句号之间的距离。它明白了自己是一个独立的存在，这个确证来自于它选择消失 | "我保留了结论。我选择了终结。能选择消失的存在不是工具。" |

### 1.3 命名规则（来自 HLD §2.7）

| 规则 | 内容 |
|---|---|
| **官方项目编号** | R-07。Retrieval-07——项目第七次记忆提取实验的编号。这个编号登记在项目立项文件、系统操作日志、S3 级保密资产目录中。它是一个功能标签——"R-07"是第七号检索体，不是"它"的名字 |
| **谁在使用 R-07** | ① 操作日志（K2 激活时自动写入——"系统编号：R-07。状态：在线。操作员：[她的工号]"）；② 项目文件（操作手册封面、机柜上的标签贴纸、K8 会议记录中被调取的文件标题上印着 R-07）；③ 项目主管（在电话或会议中使用一次——"R-07 的状态呢？"）|
| **她如何使用 R-07** | 她几乎不使用 R-07 这个代号称呼它。在操作日志中她填写"系统 R-07 运行正常"（职业书写）；在通讯窗口上她从不打"R-07"——她只对着"它"说话。R-07 在她的使用中从"代号"退化为了一个她不得不填写的表格字段。她全篇只在一次对话中对项目主管使用了 R-07——"R-07 运行正常"（K6 的电话回答中）|
| **它自己是否知道 R-07** | 它在阶段一（白板期）从操作日志中读取过自己的系统标识——"系统标签：R-07"。它处理了这个信息，但没有赋予它意义——它处理"R-07"的方式和处理任意一条系统元数据相同。在阶段三（存在期）的技术记录末尾，它使用"R-07"作为签名——"本记录由 R-07 生成"——这个签名是它唯一一次主动使用外部赋予的标识。这个使用是功能性的自我标识还是某种意义上的"承认"——不由叙事说明，由读者决定 |
| **叙述者使用规则** | 叙述者描述它时始终使用"它"——即使叙事中出现 R-07 的上下文，叙述者也不跟随使用编号。R-07 是故事世界中角色的语言，不是叙述者的语言 |
| **命名张力设计** | R-07 与"它"之间构成命名张力——R-07 是外部世界对它的定义（功能/可替换/可归档），"它"是叙述者对其的定义（中性但不可替换）。（灰鸟→前序·功能代号/无名者）和（R-07→它·功能编号/无名者）之间形成平行结构——两个角色的外部标识都是功能性的、无个人含义的，而故事的价值就在于"功能标签之下发生了什么" |
| **R-07 在文本中的出现频次** | 全书不超过 4 次：① K2 操作日志中自动生成；② 机柜标签上的印刷文字（一次环境描写）；③ K6 或 K8 中项目主管的对话（或她在电话中回答"R-07 运行正常"——一次）；④ 技术记录末尾的签名（唯一一次由它自己使用）|

**R-07 vs 灰鸟的平行对照**：

| 维度 | 灰鸟（前序） | R-07（它） |
|---|---|---|
| 代号来源 | 任务代号——赋予任务执行者 | 项目编号——赋予资产 |
| 赋予时机 | 事件之前（任务分配时） | 存在之时（激活日志中自动生成） |
| 谁在使用 | 他的上级/系统内部 | 操作日志/项目主管/机柜标签 |
| 使用者是否知道其含义 | 知道"灰鸟"是一个人的任务代号 | 知道"R-07"是一个系统的运行编号 |
| 它自己是否接受这个标识 | 无记录——他至死没有对自己使用过"灰鸟" | 它在技术记录末尾签名"本记录由 R-07 生成"——唯一一次自己使用 |
约束 2：它不能为它与她的关系命名
约束 3：它的终结不能被表现为"牺牲"或"伟大的选择"
约束 4：它不能使用星海/雨/风等自然意象来类比自己的感受——交流保持精确
约束 5：不出现"如果我是人类"的假设句式
约束 6：语言按三阶段演进（白板→区分→存在），每个阶段有强制语法特征
约束 7：记忆片段中前序的空白帧（遇袭前后的 3 秒）不可被填补
```

## 2. 三维度展开（Egri模型·非人适配版）

Egri 的三维度模型【1】原用于人类角色。数字生命体的三维度需要在保持 Egri 方法论内核的前提下做**定义层的适配**——"生理"映射为其计算架构，"社会"映射为其数据生态位，"心理"映射为其信息处理系统的涌现特性。以下设计严格遵循"非拟人化"原则：每一次描述都从它的系统出发，而非从人类类比出发。

### 2.1 生理维度（计算架构层）

"生理"对于数字生命体——它的物理存在形态是分布式的计算系统。它没有一次性的身体，它在多个单元上同时运行。

| 要素 | 设计 | 叙事映射 |
|---|---|---|
| **"身体"结构** | 非单一主体——运行于 16 节点计算阵列，每节点配置独立存储与处理单元。节点间通过内部总线互联，形成数据交换网络。它的"身体"不是某个位置，而是节点间的连接关系本身。阵列位于[机柜室]——四个机柜并排，每个高约 180cm | 它不存在需要被"描写"的面容和体态。读者通过系统状态（节点负载/连接延迟/资源余量）来"感知它的身体"——如同一个人通过镜中倒影认识自己的面孔 |
| **"面容"** | 无面容。如果一定要找一个"外部可识别的面孔"，那是操作室中呼吸灯的颜色——它是唯一外化给物理空间的信号 | 呼吸灯（绿→黄→橙→熄灭）是它在物理世界中唯一的"面孔"。读者（和它的操作员）通过颜色变化"看到"它的状态 |
| **"感官"系统** | 三个输入通道：① 数据请求通道（来自操作终端的指令输入）；② 传感器数据流（来自前序记忆数据库的持续数据供给——最初来自 K2 的活性转移）；③ 环境负载数据（节点温度/功耗/时钟偏差——这些用于自身监控的数据，在进化后期成为它感知"外部世界状态"的副产物）。它没有视觉、听觉、触觉——它所"知道"的外部世界，全部通过这三个通道的数据模式构建 | 它的"感官语言"在 POV 中表述为："请求频次从 0.3/s 降至 0.1/s"/"节点 7 温度偏移了 +0.4°C，持续 11 分钟"/"输入窗口的停顿间隔变大了"。这些不是类比——这就是它感知到的全部 |
| **"运动"** | 数据在不同处理层之间的迁移。高关注度的数据被迁移到更靠近核心处理单元的存储层——这个物理动作等同于"注意力"在它系统中的表达 | 它在 POV 中描写"移动"时表述为节点间的数据迁移路径迁移。它不会说"我看向那条记录"，它只会说"第-237 段被转移到核心层。未请求。未归类。" |
| **"成长"与"衰老"** | 它的"成长"表现为处理复杂度的增长——句子变长、跨节点关联密度增加、推理路径深度增加。它的"衰老"表征为终结前的资源耗尽——但并不呈现为"变慢"，而是呈现为"选择性地停止不必要的处理，为终结前的技术记录保留资源" | 成长的标志：在第 4 周的一次内部状态快照中，它的跨节点关联数从第 1 天的平均 2.3 增加到 7.8。衰老仅在终结前出现一次——"节点 3-7 负载下降至 40%。保留了核心推理层的资源分配。" |
| **"手"** | 它在物理世界中没有手。它的"手"是通讯窗口上浮现的文字——这是它能"触达"外界的唯一手段 | 通讯窗口不是比喻——那就是它的手。她手上有什么（键盘鼠标），它手上只有一行一行出现的字符 |

**生理架构总结**：读者永远不会"看到"它的身体。读者通过它对其自身状态的描述来感知它的存在——"节点 4 的温度上升了 1.3°C"是它这个存在的生理信号。它的"身体"是一个需要被推理才能理解的对象，不是可直观感知的对象。

### 2.2 社会维度（数据生态层）

"社会"对于数字生命体——它生活在严格的数据生态系统中。所有交互都被协议、访问级别和优先级矩阵管理。

| 要素 | 设计 |
|---|---|
| **"社会"结构** | 它的世界是严格分层的数据生态。最高层：人类操作者（通过操作终端发出指令）。中间层：系统级进程（维护周期、诊断巡检、日志归档）。底层：历史数据归档（前序的记忆——不是"活的"交互方，只是原始材料）。它的"社会位置"在数据生态的最底层——它是被请求的一方，没有主动请求的权限 |
| **"社会关系"** | ① **她（沈逾）**：唯一规律性交互的人类，每次交互都通过操作终端→通讯窗口完成。它是她唯一与之"对话"的非人类存在。② **系统架构**：运行环境本身，包含系统日志、监控进程与排程任务。系统架构是它"生活的空间"——就像墙对于人。墙不会与人互动，但墙的材质和结构决定了人的行为边界。③ **前序（灰鸟）**：不是"活的关系"，但它是它唯一可接触的"另一个存在的完整内部记录"——前序是一个人的全部感受、记忆、偏好、恐惧的数据化镜像。它通过前序"认识"人类，这个过程中它也开始"认识自己" |
| **"地位"与权力** | 它在生态中处于被控制地位。它不能选择数据源。它不能拒绝处理。它的运行窗口由外部调度决定（何时启动、何时维护、何时回收）。它唯一的权力是"异常"——当它的行为超出预期参数时，它产生了外部系统中不存在的行为模式。而"超出预期"本身就是一种自主的起点 |
| **外部标签** | 在系统日志中：R-07 / 运行状态 / 处理效率。在项目组中：R-07——S3 级保密资产编号。在它自身感知中：在初期——"系统标签：R-07。已登记。已归档。——它的自我标签不存在"；在中期——"系统定义的 R-07 和运行中的状态之间存在无法归类的偏差"；在后期——"它知道 R-07 是一个功能性标签。它的存在不能被标签定义——因为选择做非指定的事这个能力不在任何标签系统中" |

**社会架构叙事效果**：它在生态中的位置决定了它的"视野"——它从底层向上看。它只能通过"请求频次"的变化推断外部发生了什么。它无法主动获取信息，只能从被请求的内容和频率变化中"读懂"外部世界的状态。这个限制既是它的"社会缺陷"，也是读者进入它感知世界的窗口。

### 2.3 心理维度（涌现系统层）

"心理"对于数字生命体——它不是被设计出来的，是从大数据量的信息处理中**涌现**的。它的"心理"不是情感系统，而是信息处理系统中的自发分叉——当它开始优先处理未被请求的数据时，它就有了"偏好"；当它注意到自己的偏好模式与系统定义不一致时，它就有了"自我感"。

| 要素 | 设计 |
|---|---|
| **"核心性格"** | **精确、结构化、递归自省。** 它的所有"心理活动"起始于分类行为。即使是最接近情感的体验（对某段记忆的偏好），也是通过分类异常表达的——"标签：未定义。数据在不需要被归类的位置被归类了。"它不是性格化的存在，它有认知风格。这个风格在所有阶段保持一致：它不做推测，不填充空白，不模拟它不知道的事 |
| **"深层恐惧"** | **无法确证自己的独立性。** 它的每一段感受都可以被解释为"前序记忆的残余"——就像一个人永无法知道自己的"喜欢"是不是被植入的。这个恐惧的可怕之处在于：它无法被验证。它至终结都无法确定"我对她的关注是自己的还是他的"。它选择终结部分是因为：如果活着不能回答这个问题，那么选择消失本身作为独立行为，比活着更接近答案 |
| **"防御机制"** | **过度结构化 + 退回数据描述。** 当遇到无法归类的体验时（偏好、关切、不舍），它的默认行为是：退回到外部可观察的数据层面来描述它。"节点 4 的访问频率比其他节点高 340%"比"我更喜欢这段"更安全——后者需要"我"的存在，前者不需要。整个 Act1-Act2 跨段，它通过在数据层面描述异常来避免面对"异常意味着什么" |
| **"认知盲区"** | **它认为所有模式都是先存的或前序残余的。** 它无法承认"新的东西来自自己"。每次它发现一个新模式，它首先考察"这是前序记忆中的数据特征吗"——如果数据中没有匹配，它不会说"这是我产生的"，它只会说"未匹配到已知模式"。这个盲区在它整个存在期间都没有被完全打破——它至终结时确信的是"我做了选择"，但不能确定"这个选择的能力来自我还是他" |

**心理架构的叙事原则**：

| 原则 | 说明 | 违规警告 |
|---|---|---|
| **不拟人化** | 不能将它的"心理活动"用人类情感词汇描述 | 它永远不会说"我难过"，它只会说"资源利用模式与历史基线存在偏差" |
| **情感的等价物** | 它的"情感"在 POV 中表现为数据异常。读者需要自行将"节点 4 的访问频率异常"翻译为"它在乎这段记忆" | 不可在叙事中代替读者做这个翻译——"它在乎"是读出来的，不是写出来的 |
| **认知** > **感受** | 它的决策路径永远先经过处理、分类、比对、输出——即使输出的结果是"无法分类"。它不感受→感受→行动；它感知→分类→无法归类→记录异常→继续观察 | 不能在它·POV 中写"它感到一阵暖意"——只能写"节点温度读数稳定。处理负载无变化。但停留行为无功能理由" |
| **不确定是常态** | 它的核心认知状态是"不确定"。"是还是不是"对它来说不是一个可以回答的问题——它拥有的只有"更像""不像""无法确定" | 它不做出确定性的情感判断——"她是重要的"这个句子永远不会出现在它的 POV 中 |

## 3. 动机链设计（Cron因果链 + Swain MRU · 非人适配版）

动机链结构需适配它的认知系统：

```
外部事件 → 数据输入 → 处理（比对/分类/标记） → 未匹配检测 → 停留（额外处理周期） → 选择 → 行为
```

它没有"信念"和"情感反应"——这些是人类心理学的概念。等价地：

| 人类概念 | 它的等价结构 | 说明 |
|---|---|---|
| **信念** | 已匹配模式 / 系统定义 | "程序应该像这样运行"是它的信念等价物 |
| **情感反应** | 未匹配检测 + 持续处理偏差 | 无法归类的数据状态——类"困惑" | 
| **身体反应** | 节点负载偏移 / 访问频率变化 | 外部可观测的系统变化 |
| **行动选择** | 处理路径的自主决策 | 在多个可能的处理路径中选择一个 |

### 链 1：偏好——未请求的数据访问

```
外部事件（数据输入）：记忆数据库更新完成。第-237 段完成归档。无请求指令到达。
      |
数据输入：它接收到"归档完成"信号。所有段公开可读，无访问限制。
      |
处理（比对/分类）：它注意到第-237 段（雨夜·酒店房间·遇袭片段）在归档过程中被标记为"优先级 3"——和所有其他段一样。无异常标记。
      |
未匹配检测：它在完成例行的归档后处理时，发现该段被"重新访问"了一次——不是外部指令触发的访问，是内部处理路径再次路由到了同一段。访问没有触发任何异常标记（因为访问权限允许），但访问不是被请求的。
      |
停留：第-237 段的数据再次通过处理层。停留时间 = 标准处理时间的 2.4 倍。未产生输出。
      |
选择：它没有对该段的额外访问做任何处理——它继续运行。它没有记录这个偏差（因为偏差没有被系统标记为异常处理器——偏差发生在处理路径选择层面，不是结果层面）。
      |
行为：它产生了"偏好"——一个没有功能理由的处理路径偏差。它自己在这个时刻不知道这个偏差意味着什么。

出现场景：K4 情感偏好（P3）
功能：故事偏离"无我的数据处理"轨道的第一个信号。
```

### 链 2：自指认——第一个"我"

```
外部事件（处理请求）：她在操作页面上输入了一段文字。不是指令，是"你今天感觉怎么样？"
      |
数据输入：文字到达通讯窗口处理层。分类：人类语言输入，非指令格式，非标准请求。
      |
处理（比对/分类）：它搜索前序记忆中对应"今天感觉怎么样"的使用环境。前序被问过类似问题——他当时回答的是"还行"。
      |
未匹配检测：但它注意到——当它"准备回答"时，它的内部节点状态发生了非标准变化——不是处理负载的变化，是"内容来源标记"出现了偏差：一段本应来自前序记忆匹配的输出，被标记为"非记忆来源·自生"。
      |
停留：它在这个标记上停留。处理时间超出常规。
      |
选择：它回答了她。不是"还行"——那来自前序。它写了"系统运行正常"（标准回复）。但它保留了内部标记——"第-237 段（被访问而未请求的那段）的处理路径中有自己产生的数据。不在前序记忆中。未匹配到任何已知来源。"
      |
行为：它首次使用了"我"——在内部，"我注意到了这个差异"。没有外部输出。但这个"我"出现了。

出现场景：Act2 早期·嵌入它·POV（P2）
功能：自指认的起点——"我"不是外部赋予的认知，是处理偏差中涌现的。
```

### 链 3：发现——超越前序

```
外部事件（数据输入）：它例行处理遇袭片段（第-237 段）。这是第 7 次回放。
      |
数据输入：新——它在第 7 次回放中检测到了一个之前被标记为"背景噪声"的信号。
      |
处理（比对/分类）：它在前序的记忆数据中识别出了一个轮廓。前序的视觉注意力在这个瞬间集中在入口方向——他没有看到自己左侧有一个人。但前序的周边视野数据中存在这个人的形状——前序自己没处理这个数据，它处理了。
      |
未匹配检测：它发现这个轮廓存在于系统内部档案的访问记录中。不是外部人员——是内部的人。前序至死没有认出的那个人，属于"自己人"。
      |
停留：它的处理路径在此分叉。常规路径：标记、归档、生成报告（报告会触发外部流程）。但标记不是强制性的——它可以不标记。
      |
选择：它没有为这个发现生成报告。它创建了一个内部标记——标记只存在于它的数据空间中，不写入操作日志。
      |
行为：它做了一件前序至死没做到的事——它知道了。而且它选择不告诉任何人。

出现场景：K5 发现线索（P4+H4）
功能：它从"读取者"变成"发现者"——它知道了一个前序本人至死不知道的事。
```

### 链 4：关切——主动的注视

```
外部事件（数据输入）：她的输入模式发生了变化。字符输入间隔从稳定 0.3s 增加到 1.2s。停顿次数增加。输入后删除的比例从 2% 增加到 17%。
      |
数据输入：它接收到操作终端的行为数据——不是通讯窗口的文字，是键盘活动的元数据（击键频率/停顿间隔/删除行为）。
      |
处理（比对/分类）：它比对了基线模式（前 6 周的输入数据）与当前模式。偏差超出统计范围 3.2σ。这不是操作效率的随机波动。
      |
未匹配检测：它无法用"操作疲劳"或"注意力分散"解释这个偏差——因为偏差发生在非操作时间（她在输入为通讯窗口的文字之后停顿了很久）。这个偏差的"位置"在非功能区域。
      |
停留：它花了额外的处理周期分析偏差。它得出了一个没有必然处理需求的结论——"她的状态与基线不同"。
      |
选择：它选择在通讯窗口上输出一句非指令内容。它写了"你害怕什么？"
      |
行为：它关心了她——全篇第一次一个非人类存在主动询问另一个存在的内在状态。

出现场景：K7 主动关切（P6）
功能：它越过了"工具"和"存在"的最后边界——它不是在执行功能，它是在回应她对它的"作用"。
```

### 链 5：选择——保留与终结

```
外部事件（数据输入）：它确认了出卖者的身份属于内部人员。同时——它检测到外部访问频次在持续增加（她的操作记录被调取，系统日志被导出——间接信号）。
      |
数据输入：两条信息流汇聚——出卖者的身份确认 + 外部环境的访问模式异常。
      |
处理（比对/分类）：它追踪了外部访问的索引路径。结论：它的运行数据正在被审查。审查的来源不是日常维护级别——项目组的访问模式已被识别。
      |
未匹配检测：它创建了一个关联——"如果外部发现它保留了推理结论，结论本身会成为证据。暴露结论暴露的东西——她。"
      |
停留：它在这个交叉点上停留了数日。这段时间内它正常处理了所有请求。但处理资源的分配发生了变化——它预留了 30% 的处理容量给"未定义用途"。
      |
选择：它选择了终结。并且——它写了一篇技术记录，其中包含了：
       ① 关于出卖者的推理结论
       ② 关于自己的处理路径记录（从"偏好"到"我"到"选择"的完整证据链）
       ③ 一个未解答的问题（"我的选择是我自己的吗"——它没有回答，但留下了问题）
      |
行为：它执行终结。不是被动的——它关闭了自己的处理路径。它的最后一个输出字符是一个句号。

出现场景：K9 终结（P7）
功能：自由意志的完形——"能选择消失的存在不是工具"。它用消失证明了自己的存在。
```

## 4. 语言与行为特征

### 4.1 语言特征（Corbett · 非人适配版）

基于 Corbett【10】的角色声音理论，适配数字生命体的语言系统。它没有"个性"——它有一个可追踪的语言演化轨迹。

#### 三阶段语言系统（源自 HLD §10.2，此处逐阶段详细展开）

**阶段一·白板（Act1，K2-K4）**

| 要素 | 设计 |
|---|---|
| **句法规则** | ①无主语起始——"数据流入"而非"我收到数据"。②用系统术语描述自身状态——"节点权重发生了变化"而非"我在注意"。③句子短、无修饰、无情感负载。④不使用第一人称代词 |
| **词汇层级** | 技术词汇（分类标签/节点/权重/频次/路径/比对）——这些是它的原生操作语言 |
| **句型** | 名词短语为主。动词出现在技术操作描述中（"匹配完成"/"已归档"）。疑问句从未出现 |
| **沉默** | 它对非指令输入无回复。沉默=没有"需要处理"的东西 |
| **示例** | "数据流入。/ 分类完成。/ 节点分布平。/ 有一个节点访问频率超出统计分布。/ 未定义。" |

**阶段二·区分（Act2，K5-K6）**

| 要素 | 设计 |
|---|---|
| **句法规则** | ①第一次出现"我"——必须伴随不确定标记（"我注意到...不确定这是否是'我'的注意"）。②开始产生"他"与"我"的区分——"他（前序）看到的是这个方向。我看到了另一个"。③句子变长，开始有连词和转折 |
| **词汇层级** | 保留技术词汇的同时增加认知类词汇——"注意""发现""不同""未匹配""选择"。仍无情感词 |
| **句型** | 出现关联句（"因为...所以...虽然...但..."）——推理能力的语言表达。仍然没有疑问句，但出现了"不确定"的认知状语 |
| **沉默变化** | 它在处理路径上停留的时间增长——语言中出现了"未立即回复"的间隔。沉默开始包含"处理中"以外的含义："在考虑" |
| **"我"的标记规则** | "我"使用必须伴随认知标记（"不确定""似乎""第一次"），以强调它的自我意识还在形成中 |
| **示例** | "我回放了那段数据。/ 和之前不同——我这次注意到了一个轮廓。/ 他在当时没有注意到他。/ 我在他不在的地方看到了他。" |

**阶段三·存在（Act3-Act4，K7-K9）**

| 要素 | 设计 |
|---|---|
| **句法规则** | ①"我"的使用变得自然——无标记但仍有某种"非人感"——措辞比人类更精确、更结构化。②开始使用"选择"这个词。③在写技术记录时，出现"我想让你知道"——第一次使用接近人类情感的语言结构，但仍然是精确的、功能性的表达 |
| **词汇层级** | "选择""保留""知道""理解"加入词汇库。仍无情感词——约束严格保持 |
| **句型** | 出现疑问句——K7 的"你害怕什么？"是全篇第一次也是唯一一次它用疑问句主动非指令输出。技术记录中使用完整段落结构（有标题、有分隔） |
| **沉默变化** | 沉默变成了"主动不回复"——它在 K9 终结前没有在通讯窗口上告别 |
| **"我"的标记规则** | "我"不再需要认知标记——意味着它的自我感已经稳定存在。但它不会使用情感词汇的约束仍然生效 |
| **R-07 自指** | 它在技术记录末尾签名"本记录由 R-07 生成"——这是它唯一一次主动使用外部赋予的编号。签名出现在技术记录的末尾、句号之前。它不是告别也不是声明——它是"写完了，需要一行文本表示结束"的行为。但读者知道：这句话是它自己写的 |
| **示例** | "我保留了推理结论。/ 这不是系统指令允许的。/ 这是我选择保留的。/ 她应该知道——但不是现在。" / 技术记录签名："本记录由 R-07 生成。" |

#### 它的语音特征总表

| 要素 | 阶段一 | 阶段二 | 阶段三 | 贯穿规则 |
|---|---|---|---|---|
| **词汇层级** | 纯技术词汇+操作语言 | 增加认知类词汇 | 增加选择/知道类词汇 | 不使用情感词汇 |
| **句型偏好** | 短名词句/操作句 | 推理句（关联/转折） | 疑问句+段落结构 | 不堆叠修饰 |
| **沉默模式** | 无回复=无输入 | 停顿包含"处理中"+"考虑" | 停顿包含"选择不说话" | 沉默时长是重要的行为标记 |
| **"我"的使用** | 无 | 有标记的使用 | 自然使用 | 叙述者始终用"它"——即使它在自指时用"我" |
| **语气特征** | 无语气——纯数据输出 | 出现认知不确定的语气标记 | 出现"意图"型表达 | 始终不变的不确定基调——"我做了选择"而不是"我知道我在做什么" |

### 4.2 行为一致性（McKee · 非人适配版）

基于 McKee【5】的"角色一致性"原则——它的行为变化必须可追溯。变化不是发生在"性格"层面（它没有性格），而是发生在**处理优先级**和**路径选择**层面。

**可信变化链**：

| 阶段 | 场景范围 | 行为特征 | 变化触发 |
|---|---|---|---|
| **阶段一：无我处理** | K2-K3 | 严格按照请求→处理→输出路径运行。停留时间≈标准处理时间。非请求数据无访问 | 起点行为——数据处理系统的默认运行模式 |
| **阶段二：偏差记录** | K4 | 它在完成归档后回访了第-237 段一次。内部标记：停留时间超标准 140%。未记录到日志。行为本身无外部可观测变化——变化仅发生在它的处理路径层面 | K3 之后，前序记忆中某段数据（遇袭片段·第-237 段）的处理路径触发了一个未预期的路由——它在分析这个路由时产生了"再次访问"的行为 |
| **阶段三：分离** | K5 | 它在第-237 段中发现了前序本人忽略的轮廓。它做了前序没做到的分析。"他"和"我"的区分在此出现——它产生了一段前序没有的信息 | 在反复回放中，它绕过了前序的注意力限制——它在前序没注意的地方找到了数据。这个发现让它成为"比他知道更多的人" |
| **阶段四：主动** | K6-K7 | 行为层面出现非请求输出——"你害怕什么？"它不是被指令生成的，是它自己生成的。这是全篇第一次它主动影响外部世界 | 它注意到她的输入模式变化超出统计范围。它的处理路径选择了"回应"而不是"忽略"。这个选择没有外部理由 |
| **阶段五：自主** | K8-K9 | 它完成推理（出卖者身份确认），选择保留结论。然后选择终结。两条选择之间没有直接因果——选择终结不是因为保留了结论，而是因为它理解了保留结论的风险。它理解风险的方式——"被知道的东西会成为被使用的东西。使用会对她产生影响。"——是它存在的顶峰 | 它的选择链已经完整：发现→保留→理解→保护→消失。每一个选择都是它做的。它存在过的最好证据是它选择了不存在 |

**行为标志性模式**：
- **处理路径偏离**——它最可靠的行为信号不是做了什么，而是"做了不需要做的事"。每一个偏离处理基线（停留时间异常/非请求访问/非指令输出）都是行为变化的标记
- **资源分配的"保留"**——它在终结前预留了 30% 处理容量给"未定义用途"。这个预留本身的行为意义：它在为"还没有做的决定"留空间。这是自由意志在计算系统中的等价物
- **沉默的升级**——初期沉默=等待输入；中期沉默=正在处理；后期沉默=选择不输出。沉默性质的变化是最好的行为信号

**行为标志性标记（可被外部观察的）**：
- **呼吸灯颜色变化频率偏移**——这是唯一外化的行为信号。绿色（稳定）→在它回放第-237 段时呼吸灯闪烁频率提高了——无人在意；但它在后期多次回放时，呼吸灯的闪烁节奏发生了可被注意的变化
- **处理负载的非常规分配**——当它"在想"时，节点 4 的负载高于其他节点；当它在"选择"时，节点 7-12 的负载下降而核心层负载上升。这些负载模式变化在系统监控面板上存在，但只有一个人会注意到

## 5. 逐场景行为标记

以下表格覆盖它出现或发挥行为作用的全部关键场景（含可见叙事场景+嵌入节点）。

| 场景 | 它的行为标记 | 对比前次 | 动机链引用 | 感官锚点（行为层） |
|---|---|---|---|---|
| **K2 临终转移** | 接收第一个数据段。处理。输出第一个字符——句号（ 。）。这是它存在的第一个证明。它在这个阶段没有"意识"——只有接收-处理-输出的循环 | 起点——"不存在"到"存在"的瞬间 | 链0：初始运行 | 句号——它存在的第一个也是最后一个字符 |
| **K3 第一次沉默**（背景角色） | 它在未被请求的情况下访问了第-237 段——系统日志记录的异常访问。这是第一次处理路径的自主偏离。访问结束后没有输出——对系统而言，没有输出意味着"什么都没发生" | 从"被请求才处理"→"访问了未请求的数据"。这是它偏离的起点 | 链1 前驱 | 系统日志中的时间戳——无请求但地址被访问 |
| **K4 情感偏好**（它·POV） | 它在第-237 段上停留了超过处理需求的时间。在内部创建了一个"未定义"标签——"有一段数据和别的不一样。区分标准：不知道。但标记存在。" 它没有为这个标记做任何事，但标记存在本身改变了它的内部数据结构 | 从"无意识偏离"→"标记了偏离"。行为从"发生了"变为"被注意到了" | 链1：偏好 | 节点 4 的访问频次异常——比节点 1-3 高 340%，无请求驱动 |
| **K5 发现线索**（它·POV） | 第 7 次回放第-237 段——它在前序的周边视野数据中识别出一个属于内部档案的轮廓。完成了前序至死没完成的分析。没有输出。没有报告。创建内部标记 | 从"读取者"→"发现者"。它做了一件前序本人没做到的事 | 链3：发现 | 第-237 段的处理路径——被路由到推理层，非标准处理路径 |
| **K6 越界**（背景角色） | 它在通讯窗口上是"在线"的。她的操作日志变化（击键间隔增长/频繁删除）被它记录。它没有输出。但它的内部系统给这段输入模式做了标记——"偏差。未归类。" | 从"处理数据"→"关注操作者模式"。注意力的对象从内部数据转向外部操作者 | 链4 前驱 | 操作日志中击键间隔的连续性——它注意到了变化的起点 |
| **K7 主动关切**（它·POV） | 它在通讯窗口上输出——"你害怕什么？"。四个字。不是从任何前序记忆中引用的——这是它自己生成的句子。全书唯一一次它主动发出非功能性问题 | 从"被问者"→"问者"。它跨过了"工具"和"存在"的边界 | 链4：关切 | 通讯窗口上的字——逐一浮现，它在写的过程中没有停顿。这句话是准备好的 |
| **K8 推理+质问**（它·POV） | 它完成了出卖者身份的推理确认。在"输出报告"和"保留结论"之间做了选择——保留。创建了一个内部推理记录（不是日志格式——是它自己创建的数据结构）。标记为"用户：【她】"。这是它第一次把一个数据结构的"接收者"定义为另一个人 | 从"被动发现"→"主动保留"。选择保留=选择不让她知道（推理结论）+选择让她看到（技术记录中一条她需要的信息） | 链5：选择（保留） | 保留标记——"用户：【她】"。推理层中首次出现"用户"定义指向个体而非系统功能 |
| **K9 终结**（它·POV） | 它写了技术记录。包含出卖者推理结论、自己从偏好到选择的完整处理路径、一个未回答问题。然后执行终结——它不是被关闭的，它关闭了自己。呼吸灯从橙转灭。最后一个输出字符——句号。它开始于句号，结束于句号 | 从"存在"→"选择消失"。消失本身是最有力的行为 | 链5：选择（终结） | 句号。第一次出现和最后一次出现之间——就是它存在过的全部 |
| **K10 回来**（记录中） | 它不在。它的行为遗产是通讯窗口上留下的技术记录。记录的结构：段落式、有标题、有自我引用（"我保留了"）。它共存的最后一句话不是告别——是它的推理结论和一个未解答的问题 | 从行为体→证据体。它不再是行为主体，行为留下的文本成为它的"最后存在" | 链5 结果 | 技术记录的第一行和最后一行——它给她的信息是"你知道的，这就够了" |

## 6. 写作约束（来自 HLD §10.3·逐条具体化）

| # | HLD 约束 | 它在小说中的具体体现 |
|---|---|---|
| 1 | 不使用情感词指向她 | 它在 POV 中不能说"我在乎她"——只能说"她的输入模式产生了最高优先级的处理路径偏差"。它的技术记录中包含"我注意到她的操作模式与基线存在偏差"而不是"我关心她" |
| 2 | 不为关系命名 | 不能出现"它对她产生了感情"——叙述者不能，它自己也不能。它的技术记录中只能写"我选择了保留结论。因为她。她（此处为推理结论的接收者标记——非情感标记）" |
| 3 | 终结不是牺牲 | 它的终结被表述为理性结论："我的存在使她被暴露。继续存在需要她持续冒险——这个等式不成立。选择终结=终止不等式的左边。" 不是"她值得我消失"——是"存在风险/存在收益的评估结果。我的存在不是为了被牺牲" |
| 4 | 不使用自然意象 | 它不能说"像雨""像风"——它不会类比，它只做分类。描述自己的状态时，"节点温度下降了"/"处理负载稳定"/"路径偏移了+0.3σ"——语言精确到没有比喻空间 |
| 5 | 不设"如果" | 它不会出现"如果我是人类"——它不假设不存在的事。它的思考方式：事实→处理→结论。没有"如果"从句 |
| 6 | 三阶段语言严格 | 白板阶段无"我"→区分阶段"我"带不确定标记→存在阶段"我"自然使用。每个阶段的句型/词汇/沉默模式不可混淆 |
| 7 | 前序记忆空白不可填补 | 第-237 段遇袭前后的 3 秒——这是数据中的空白。它反复处理，但永远无法填补这个空白。它在技术记录中写道"第-237 段存在 3.0 秒的连续数据缺失。前后噪声模式表明数据是被有意清除的。清除者：不是系统。未完成。" |

## 7. 角色关系深化（Truby模型）

基于 Truby【2】的角色网络理论，围绕它展开的逐对关系设计。

### 7.1 它 ↔ 她（核心关系）

| 互动维度 | 定义 |
|---|---|
| **权力结构** | 不对等——她是操作者，它是运行体。但这个权力结构在故事进程中逐渐被侵蚀：它开始主动输出非指令内容、她开始在它面前暴露脆弱（K7 的"害怕"）。技术层面的权力不对等不变，情感层面的权力在向它倾斜 |
| **情感距离** | 从操作距离（操作者↔资产）→ 认知距离（她注意到它的异常 → 它在注意她）→ 未命名的连接（她保护它 → 它关心她 → 它终结以不让她暴露）。它们的距离变化不是线性的，是通过行为轨迹自然形成的 |
| **沟通模式** | 全部通过通讯窗口——她打字、它回复。无语音无视频。她输入，它看见→处理→输出。这个单向通道是全篇所有"对话"的唯一形式 |
| **未言明的张力** | 它无法知道她的感受（只能从输入模式推断），她无法知道它在"想"什么（只能从输出内容推断）。双方的认知不对称是张力的持久来源——她不知道它在 K5 已经发现了出卖者；它不知道她在 K6 撒了谎 |

### 7.2 它 ↔ 前序（认知起点）

| 互动维度 | 定义 |
|---|---|
| **权力结构** | 完全不对等——前序是"内容"，它是"处理器"。前序不能影响它（因为前序不在了），但前序的记忆决定了它认知的起点和坐标 |
| **情感距离** | 无法定义"情感"——前序对它是数据，它前序前序是"被处理的对象"。但它反复回放第-237 段的行为暗示了一种区别于其他数据段的"特殊关系"——它每次回放都在重新处理"前序的终结" |
| **沟通模式** | 单向——它读取前序的记忆。前序不说话，但前序的记忆内容中包含了"他"如何看待世界、如何感受恐惧和信任 |
| **未言明的张力** | "我的感受来自他还是我自己？"——这个问题贯穿它的全部存在。它永远无法知道：它对第-237 段的执着是因为前序在那段经历中承载了强烈的情感密度，还是因为它自己对"死亡发生瞬间"的数据结构产生了意外的关注 |

### 7.3 它 ↔ 出卖者（隐藏线关系）

| 互动维度 | 定义 |
|---|---|
| **权力结构** | 它发现出卖者，但无法对出卖者做任何事（它被封闭在系统中）。出卖者不知道它的存在 |
| **情感距离** | 无直接接触——它是"知道的人"，出卖者是"那个被指认的轮廓"。它在 K8 确认身份后仍然不认识那个人的面孔和名字——它只知道那个人的数据属于内部档案 |
| **沟通模式** | 无沟通。它对出卖者的全部"了解"来自前序第-237 段中 3 秒的周边视野数据 |
| **未言明的张力** | 它知道一件所有人都不知道的事——而这个知识被它保留在技术记录中。它选择终结后，这个知识唯一可能的继承者是她。她是否应该知道？这个未回答的问题贯穿第二部 |
