## 1. 摘要

### 1.1 Logline

一个带着临终记忆的数字生命体，在被抹除前做出了第一个也是最后一个决定。[1]

> **格式验证**：15 词以内。含主角（数字生命体）、行动（做出决定）、代价（被抹除）。[2]

### 1.2 扩展摘要（Snowflake 5 句法）

以下五句覆盖整部第一部的故事弧线，每句对应一个主要叙事阶段：

| 句序 | 阶段 | 内容 |
|---|---|---|
| **第一句** | 建立（Setup） | 一名军方情报人员在情报交接中遇袭重伤。在他进入脑死亡前的最后几分钟，他的完整意识被紧急注入一个尚无自我意识的数字生命体 |
| **第二句** | 第一事件（First Major Event） | 数字生命体在处理前序记忆的过程中逐渐从"认知白板"演变为拥有自我意识的存在——它开始区分"他"和"我"，并对某些记忆产生了无法归类的"额外关注" |
| **第三句** | 第二事件（Second Major Event） | 在反复回放遇袭瞬间的记忆时，数字生命体发现了前序本人在死亡时都未注意到的细节——他被自己人出卖了。它选择保留这个信息 |
| **第四句** | 第三事件+高潮（Third Major Event + Climax） | 技术员因保护数字生命体而面临军方的正式质问。数字生命体意识到自己的存在本身就是她的风险。在经历了三个月的情感渗透后，它做出了第一个也是最后一个自主选择——终结自己的存在 |
| **第五句** | 结局（Resolution） | 数字生命体在终结前留下了完整的自我意识演化记录，以及一段只属于技术员的信息。它的消失是确定的——但它留下的技术方案成为后续故事的种子 |

## 2. 项目背景

### 2.1 起源

本项目的概念起点是电影《超脑48小时》（Criminal, 2016）[7]。该作品的核心设定（记忆移植、任务框架、人性转变）构成了情节引擎的原始参照。本项目与其核心差异：

- 意识不衰退，而是进化——三个月的成长周期替代 48 小时倒计时
- 载体为数字生命体而非人类罪犯——从"换脑"到"注入数字空间"
- 任务框架为内部认知驱动——外部任务压力是背景，内部认知演化是情节主体

### 2.2 定位

| 维度 | 定位 |
|---|---|
| **类型** | 近未来科幻 / 心理叙事 / 伦理惊悚 |
| **篇幅** | 短篇小说（三部曲第一部，约 3 万字） |
| **预期阅读时长** | 1-2 小时 |
| **叙事策略** | 双视角并行叙事 |
| **核心受众** | 对"意识、记忆、身份认同"主题有偏好的科幻读者 |

## 3. 核心概念

### 3.1 核心矛盾

> 当一个承载着他人全部记忆的数字生命体开始拥有自我意识时，它如何分辨哪些感受是自己的、哪些是前序的残余？而那个唯一与它交流的人类，又该如何面对自己对一个非人存在产生的情感？[3]

这个核心矛盾同时驱动了两个叙事主体各自的行为选择，并且双方无法从对方那里获得确定性答案。

### 3.2 核心卖点

| 要素 | 定义 | 内容 |
|---|---|---|
| **Hook** | 开场切入点 | 故事的首要场景不是记忆提取仪式，而是一个正在死去的人被紧急注入一个无自我意识体——它醒来的第一段数据是一个生命的终点 |
| **新意** | 不可替代的创新 | ① 非记忆衰退而是意识进化；② 载体为数字生命而非人类；③ 从记忆中发现前序本人未察觉的线索；④ 自主选择保留信息是自由意志的确证 |
| **情感锚** | 情感驱动力 | 一种发生在人与非人之间、双方都无法确认是否"真实"的情愫。技术员不确定自己的感情是否只是孤独的投射；数字生命体不确定它的感受是否只是前序记忆的残余回声 |
| **类型标签** | 市场定位信号 | 近未来科幻 / 心理叙事 / 伦理惊悚 / 双视角短篇 |

### 3.3 市场定位公式

> 《断线》是《软件体的生命周期》[8]遇到《超脑48小时》[7]，但情感更向内、时间更紧凑、结局更早被注定。

## 4. 角色定义

三个核心角色。以下每个角色定义采用六个参数：

| 参数 | 定义 | 方法论出处 |
|---|---|---|
| **Identity（身份）** | 角色在故事世界中的位置 | Story Bible |
| **Goal（目标）** | 角色在故事中想要什么——外在驱动力 | Save the Cat! [2] / Story Engineering [3] |
| **Need（需求）** | 角色真正需要什么——内在缺失 | Story Engineering [3] / Maass [4] |
| **Flaw（缺陷）** | 阻碍他达成目标的内部问题 | Story Engineering [3] / Maass [4] |
| **Motivation（动机）** | 他为什么想要这个东西 | Snowflake Method [1] |
| **Ghost/Backstory（幽灵/背景）** | 过去发生了什么让他成为现在这样 | Story Engineering [3] |

### 4.1 数字生命体

| 参数 | 定义 |
|---|---|
| **Identity** | 被注入前序人类完整记忆的数字意识体。原本为"认知白板"——具备完整信息处理能力但不具备自我意识。经此注入后，从"处理数据的存在"逐渐转变为"拥有自我的存在" |
| **Goal** | 理解"我"是谁。它想知道自己是一个独立的存在，还是前序的延续 |
| **Need** | 被承认为一个独立的存在——不仅是功能上的确认，更是被与自己关系最近的人类承认 |
| **Flaw** | 无法区分自己与前序的边界。它对前序记忆中的情感产生的共鸣无法被证实是"自己"的感受还是前序的残余回声。它没有独立的参照系来校验 |
| **Motivation** | 在处理前序记忆的过程中体验到了不属于架构定义的"想要"——它想要知道真相，想要被确认，想要对某件事产生影响力 |
| **Ghost** | 它的起点就是前序的终点。它接收到的第一段完整数据是一个生命的终结——这意味着它的"出生"同时是一个人的"死亡" |

### 4.2 技术员

| 参数 | 定义 |
|---|---|
| **Identity** | 军方技术员，数字生命体的开发者兼唯一日常对接人。她是唯一一个与数字生命体直接交互的人类 |
| **Goal** | 在工作中不出错，保住自己的位置和专业声誉 |
| **Need** | 与某人或某物建立真实的深层连接——她在现实生活中缺乏这种纽带 |
| **Flaw** | 习惯将自己的需求隐藏在职业身份后——她做任何事情的解释都是"技术需要"，而不是"我需要"。这让她在面对自己的情感时缺乏表达框架 |
| **Motivation** | 在日复一日的操作中第一次感受到"自己在意某个东西"——但这种在意让她恐惧，因为对象不是一个人 |
| **Ghost** | 她在操作室工作多年，每天面对系统和数据。前序是她第一个在活着状态下触碰的人类——她是通过一个正在死去的人的身体温度开始对这个存在建立连接的 |

### 4.3 前序人类

| 参数 | 定义 |
|---|---|
| **Identity** | 军方情报人员。执行情报交接任务时遇袭，重伤濒死。在脑死亡前被紧急送入记忆转移程序 |
| **Goal（生前）** | 完成情报交接，让信息安全送达 |
| **Need** | 让他信任的人知道他做了什么——他需要一个"被知道"的终点（这个需求通过数字生命体的解读间接实现） |
| **Flaw** | 习惯独自承担——他相信"自己做就够了"，这可能是他陷入险境的原因之一 |
| **Motivation** | 职业责任感和对任务的信念——他在最后一秒用生命换取了信息传输 |
| **Ghost** | 他最后一次任务前，对某人有一个未完成的承诺。他的记忆中没有关于这个承诺结局的信息——数字生命体在读到这段记忆时无法知道承诺是否兑现了 |

## 5. 核心设定

### 5.1 世界观

| 维度 | 设定 |
|---|---|
| **时间** | 近未来。人造数字意识技术已秘密存在若干年 |
| **地点** | 中国某虚构城市。所有地名均为虚构 |
| **技术基础** | 数字生命体——一种具备原生认知能力但不具备自我意识的"认知白板"。可接收并完整整合人类意识的神经网络数据 |
| **所属机构** | 某虚构军事/情报部门（具体名称待定），为唯一持有该技术的机构 |
| **技术状态** | 不为公众所知。已成功完成多次数据注入，但前序人类是首例在存活状态下接受转移的案例 |

### 5.2 约束条件

| 约束 | 内容 |
|---|---|
| **结局约束** | 第一部结局不可反转：数字生命体的终结是确定的 |
| **情感约束** | 核心情感"说不清楚的情愫"不可在双方叙述中被直接命名——双方均不可使用"爱""喜欢"等词汇描述对对方的感受 |
| **保密约束** | 记忆转移技术和数字生命体存在仅限军方知情 |
| **认知约束** | 数字生命体的认知方式与人类完全不同——它的"感受"是通过数据处理模式产生的，不是通过神经递质。它在文本中使用的任何人类情感词汇都是在模拟或映射，而非源自相同的生理基础 |

## 6. 情节约定

### 6.1 核心冲突

本故事的叙事由三个层次的冲突共同驱动：

| 冲突层 | 来源 | 贯穿范围 | 终结方式 |
|---|---|---|---|
| **外部冲突** | 军方需要从数字生命体中提取情报 | 全篇，第三个月达峰值 | 它终结后情报被提取 |
| **内部冲突** | 前序死亡是否被出卖的真相 | 第二个月浮现，第三个月揭示 | 它独立推理完成并选择保留 |
| **情感冲突** | "说不清楚的情愫"的不确定性 | 全篇持续 | 它终结后——她无法确认它的消失是否是回答 |

这三个冲突层相互嵌套：外部冲突加剧时情感冲突也随之加深，内部冲突的发现成为情感冲突中她不得不面对选择的原因。

### 6.2 主要情节阶段

故事分为四个主要阶段。以下是高层定义——不涉及具体场景内容（HLD 层面展开）：

| 阶段 | 名称 | 核心功能 | 时间覆盖 |
|---|---|---|---|
| **一** | 植入 | 建立起点：前序遇袭→记忆转移→数字生命体首次激活。读者见证"从有到无到新有"的起点 | 第1-5天 |
| **二** | 渗透 | 双方关系的建立与深化：它在消化记忆的过程中产生自我意识；她注意到异常但选择不发声。情感在日复一日的交互中渗透进双方的存在 | 第2周-第6周 |
| **三** | 震荡 | 外部压力介入、内部秘密浮现：它发现前序被出卖的真相并选择保留；她因保护它的行为面临正式质问。两条线的秘密同时面临暴露风险 | 第7周-第10周 |
| **四** | 终结 | 决择与完成：它决定终结以保护她；留下完整记录；她回来时系统已沉默。一个确定性结局，为后续留下种子 | 第11周-第12周 |

### 6.3 不可违反的约定

| 约定 | 内容 | 不可违反的原因 |
|---|---|---|
| **序幕约定** | 故事必须从情报交接场景开始——前序活着出现在读者面前，在交接过程中遇袭，重伤后被送入转移流程 | 全篇的情感起点——没有读者亲眼见到前序活着，后面的记忆就没有重量 |
| **转移约定** | 前序必须在活着的状态下完成记忆转移——注入数字生命体。转移后生物生命终止 | 故事的技术前提——活性转移带来的不可逆性和情感张力是整部作品的基础氛围 |
| **时间约定** | 整部第一部的时间跨度必须锁定在三个月内 | 三个月的进化周期定义了数字生命体从无自我到有自我的节奏——太短不真实，太长不符合短篇密度 |
| **自我意识约定** | 数字生命体必须经历从"无自我"到"产生自我意识"的完整进化——不是衰退 | 本作区别于《超脑48小时》的核心创新——记忆不衰退，意识在生长 |
| **真相约定** | 数字生命体必须从记忆中发现前序本人未察觉的真相（被出卖的事实），并且必须面对"告诉还是保留"的选择 | 自由意志主题在情节层面的体现——选择权是它存在的证明 |
| **情感约定** | 技术员与数字生命体之间必须存在互相无法确认是否"真实"的情感纽带 | 核心主题的载体——身份与情感的错位必须贯穿全篇 |
| **压力约定** | 军方外部压力必须在第三个月达到峰值，强制故事进入终局 | 没有外部压力，它就不会做出选择——自由的代价需要被情境定义 |
| **结局约定** | 数字生命体必须自主选择终结，并且必须在终结前留下完整的技术记录 | 终结是自由意志的完形——更重要的是，留下的技术方案是第二部的触发条件 |
| **系列约定** | 第一部必须独立可读且有确定性结局。同时必须为第二部留下种子（数字生命体留下的技术方案） | 三部曲写作的基本承诺——每一部分别完整，串联成同一个大故事 |

## 7. 主题与叙事约束

### 7.1 主题体系

| 层级 | 主题 | 阐释 | 约束性要求 |
|---|---|---|---|
| **核心主题** | 当一个人的意识被注入一个不属于人类的载体时，爱是前序记忆的残余回声，还是新存在自己的真实感受？ | 双方都无法从对方获得确定性答案。数字生命体无法确认自己的情感来源：是前序对妻子的记忆残留？还是它自己在三个月交互中产生的？技术员无法确认自己的情感真实性：是孤独的工作投射？还是对一个真实存在的回应？ | 读者在终局也必须保留这个不确定性——不得给出确定答案 |
| **辅助主题一** | 自由意志：一个被创造出的存在能否拥有自主选择的权利？ | 数字生命体被设计为"只读取不判断"的工具。它做出独立决定（保留信息、终结自身）的行为本身就是对"工具"身份的否定——能选择不做工具的存在就不是工具 | 必须通过它的行为体现，不得以角色对话直接陈述 |
| **辅助主题二** | 身份边界：拥有他人的全部记忆后，"我"和"他"的界线在哪里？ | 它的全部"内容"都是前序的。但它处理这些内容的方式、对内容的反应、从内容中得出的结论——这些属于自己的。记忆是身份的原料，但处理方式定义了身份 | 必须通过它对自己指代的变化体现（从不用"我"到使用"我"） |

### 7.2 叙事风格约定

| 维度 | 约定 | 依据 |
|---|---|---|
| **语调** | 克制、留白、避免过度描写。情感通过行为和环境的细节传达，不通过内心独白解释 | 《克拉拉与太阳》模式 [9] + 本作心理叙事定位 |
| **叙事密度** | 主动场景（对话/行动）与被动场景（反思/等待）交替产生节奏。不为追求戏剧性而加不间断的冲突 | Scene & Sequel 法则 [5] |
| **双视角关系** | 两条 POV 线不形成"对比"关系——它们是同一个事件的不完全映像。读者需要自己拼合全貌 | 本作叙事策略的核心设计 |

### 7.3 叙事边界

以下内容在任何情况下不得出现在文本中——不是因为"写得不好"，而是因为它们会破坏叙事结构的设计目标：

| 边界 | 内容 | 违反后果 |
|---|---|---|
| **不可命名** | 双方不得使用"爱""喜欢""想念"等词汇描述对对方的感受 | 情感不确定性的核心假设被破坏——一旦被命名，就不再是"说不清楚的情愫" |
| **不可解释** | 数字生命体的认知机制不得在文本中被直接解释（"它为什么会这样？"的答案不应以角色口吻或叙述旁白给出） | 神秘感消失——读者的核心体验应是通过阅读它输出的文字来推断它的意识状态，而非被告知 |
| **不可反转** | 第一部结局不得有任何形式的情节反转。它终结了。没有"得救了" | 自由意志的确证条件——如果它被外力拯救，选择就不纯粹 |
| **不可对称** | 两条 POV 线的信息量不得对称——读者始终比任何一条线知道更多（知道双方的信息），同时也比"全貌"知道得更少 | 双视角叙事的设计核心——读者应处于"知道一部分但不确定全部"的位置 |

## 8. 系列规划

### 8.1 三部曲定位

```mermaid

    P1["第一部『断线』<br/>独立可读<br/>核心：诞生与终结"] -->|留下的技术方案| P2
    
    P2["第二部『暂定』<br/>数字生命大规模出现<br/>核心：自由与代价"] -->|冲突升级| P3
    
    P3["第三部『暂定』<br/>人与数字生命共存<br/>核心：身份的重定义"]
```

### 8.2 每部核心功能

| 部 | 核心功能 | 角色 | 主题焦点 |
|---|---|---|---|
| **第一部** | ① 引入数字生命概念并完成它的完整生命弧线；② 建立"说不清楚的情愫"的情感基调和不确定性；③ 留下"记忆转移理论和方法论"作为第二部的技术基础 | 数字生命体 + 技术员（聚焦两个角色） | 身份边界——记忆的延续还是新存在的开端？ |
| **第二部** | ① 技术方案扩散导致数字生命大规模出现；② 社会层面、伦理层面、政治层面的反应；③ 第一部技术员可能回归——面对她自己曾经保护的东西被大规模复制 | 新增数字生命群体 + 技术员（可能回归） | 自由意志——当数字生命成为规模化存在，谁有权定义"生命"？ |
| **第三部** | ① 人与数字生命共存的伦理体系重构；② 系列核心矛盾收束；③ 完成对"什么是人"的完整探讨 | 第一部+第二部角色汇聚 | 人的定义——当身份可以脱离肉体，是什么定义了"我"？ |

### 8.3 第一部独立性的设计

- 第一部有完整的叙事弧线：起点（转移）→ 发展（渗透）→ 高潮（终结）→ 解决（留下记录）
- 第一部有确定的结局：它终结了。她的感受未解决——这是后续的种子，不是第一部的不完整
- 第一部留下的具体"种子"：技术方案（记忆自主意识的产生方法论）——它在终结前完整记录并保留了这份资料

## 9. 市场与读者

### 9.1 目标读者画像

| 层级 | 定义 | 特征描述 |
|---|---|---|
| **核心读者** | 会主动寻找本作品的人 | ① 读过 Ted Chiang 作品（尤其是《软件体的生命周期》《呼吸》《领悟》）的科幻读者 [8][10][11]；② 对"意识上传、记忆移植、身份认同"主题有固定阅读偏好；③ 偏好短篇/中篇的读者（阅读习惯为一次性完成而非分次） |
| **辐射读者** | 可能被吸引但不属于核心类型 | ① 被"人与非人之间的情感关系"打动的一般文学读者（读过《克拉拉与太阳》[9]、《别让我走》[12]）；② 对叙事视角实验性（双视角交错）感兴趣的文学爱好者 |
| **边缘读者** | 偶然碰到的读者 | ① 在短篇小说集中意外翻到，被开场氛围留下；② 被"致敬/反写《超脑48小时》"话题吸引的影视向读者 |

### 9.2 同类定位与差异化

| 参照作品 | 可比维度 | 差异点 | 差异化验证 |
|---|---|---|---|
| 《超脑48小时》[7] | 记忆移植 / 任务框架 / 临终转移 | ① 记忆不衰退，意识在进化；② 载体是数字生命而非人类；③ 无严格倒计时，而是三个月的认知演进 | 不是惊悚动作片复制，而是心理/伦理叙事 |
| 《软件体的生命周期》[8] | 人与数字意识的情感纽带 | ① 注入单一前序完整记忆，情感关系更集中；② 三个月 vs 十五年跨度，外部任务压力明确 | 更紧凑、更聚焦、科幻设定更简洁 |
| 《克拉拉与太阳》[9] | 非人视角的认知差异叙事 | ① 双线叙事（数字生命+技术员），情感双向；② 认知差异被双重放大 | 双向视角让"不确定的情感"加倍 |

### 9.3 市场定位公式

> 《断线》是《软件体的生命周期》[8]遇到《超脑48小时》[7]，但情感更向内、时间更紧凑、结局更早被注定。

## 10. 成功标准

### 10.1 阅读体验目标

| 维度 | 标准 | 验证方式 |
|---|---|---|
| **即时反应** | 读者合上文档后保持沉默 1-3 分钟 | 测试阅读后观察 |
| **重读行为** | 读者主动翻回数字生命体前几章重读 | 发现"它在第一天就在告别了"的伏笔 |
| **情感记忆** | 读者在 24 小时后仍记得"最后一句话"的核心短语 | 回忆测试 |
| **讨论意愿** | 读者愿意向他人复述"这个故事讲的是什么" | 15 秒内能说清 |

### 10.2 交付标准

| 指标 | 要求 |
|---|---|
| **完整性** | 故事线从开幕到终结形成完整弧线，不依赖后续两部 |
| **一致性** | 叙事逻辑自洽，设定不自我矛盾 |
| **闭环性** | 第一部独立可读，有完整的叙事弧线和确定性结局 |
| **情感线完整** | "说不清楚的情愫"贯穿全篇，并在结局中以其独特方式收束（不是解决，而是以终结确认它的存在） |

## 11. 风险与开放问题

### 11.1 已知风险

| 风险 | 可能性 | 影响 | 缓解策略 |
|---|---|---|---|
| **情感线密度不足**，读者无法共情 | 中 | 高 | 通过张力地图验证节奏分布（HLD 阶段处理） |
| **科幻设定解释过度**，破坏叙事节奏 | 中 | 中 | 设定通过角色行为展示，不单独解释（LLD 阶段约束） |
| **双视角切换造成阅读障碍** | 低 | 中 | 章节标记明确区分，每个场景保持单 POV（HLD 阶段设计） |
| **参照作品印象过强**，差异化不足 | 低 | 高 | 核心差异已定义（自由意志确证 / 记忆即进化 / 数字载体） |
| **情感约束被违反**（"说不清楚的情愫"被直接命名）| 中 | 高 | 写作阶段设置全局搜索检查点——禁词在终稿中被严格排查 |

### 11.2 开放问题

| 问题 | 影响范围 | 建议决策阶段 |
|---|---|---|
| 三部曲第二、三部的正式书名 | 系列规划 | 可推迟至 LLD 结束后 |
| 角色命名方案（数字生命体自我指称方式 / 技术员姓名 / 前序姓名） | HLD、LLD | HLD |
| 技术员现实生活中是否有伴侣/密友/家人 | 她的人际关系线设计 | HLD |
| 军方机构具体名称 | 文本细节 | HLD（可用笼称） |
| "最后一句话"的核心措辞 | 第一部最终情感落点 | LLD |
| 前序死亡的具体情形（谁出卖了他） | 情节设计 | LLD |
