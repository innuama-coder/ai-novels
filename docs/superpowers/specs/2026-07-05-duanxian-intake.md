## Intake Brief

| 字段 | 内容 |
|---|---|
| 项目名称 | 「断线」 |
| 原始 idea | 灵感源起为电影《超脑48小时》：记忆移植、任务框架、人性转变。核心差异是：被注入记忆的不是人类罪犯，而是一个数字生命体；故事重点不是记忆衰退，而是数字生命体的自我意识觉醒与进化。 |
| 创作目标 | 写一部近未来科幻心理短篇，聚焦“记忆、身份、自我意识、非人情感”的不确定性。读者读完后应感到：一个非人存在可能确实诞生过，但它的情感是否真实仍无法被完全确认。 |
| 类型与题材 | 近未来科幻 / 心理叙事 / 伦理惊悚；题材为记忆移植、数字意识、人与非人存在之间的模糊情感。 |
| 目标读者 | 偏好意识、记忆、身份认同、非人情感议题的科幻读者；能接受克制、留白、低外部冲突的心理叙事。 |
| 篇幅形态 | 短篇小说；三部曲第一部；第一部约 3 万字，需独立可读。 |
| 必须保留 | `KEEP-01` 数字生命体不是人类换脑对象，而是承载前序记忆后开始觉醒的非人意识体。<br>`KEEP-02` 核心不是记忆衰退，而是自我意识进化。<br>`KEEP-03` 数字生命体与技术员之间存在无法确认是否真实的情感纽带。<br>`KEEP-04` 第一部结局中数字生命体的终结不可反转。<br>`KEEP-05` 事件发生在中国语境，但使用虚构地名、虚构机构，不提真实国名/城市名。 |
| 必须避免 | `AVOID-01` 避免照搬《超脑48小时》的罪犯换脑、48 小时倒计时和人性改造路径。<br>`AVOID-02` 避免把数字生命体写成人类人格的简单复制。<br>`AVOID-03` 避免直接命名双方情感为“爱”“喜欢”等确定关系。<br>`AVOID-04` 避免将研究笔记、旧 PRD、HLD、LLD 中的具体场景和设定在 intake 阶段视为冻结设计。 |
| 参考对象 | 《超脑48小时》：只参考记忆移植与任务压力的情节引擎，必须避免雷同。<br>《软件体的生命周期》：参考人与数字意识之间的长期投入和回报不确定性。<br>《克拉拉与太阳》：参考非人视角的认知差异表达。<br>《皇帝魂》：参考记忆研究/重建作为任务推进机制。<br>《呼吸》：参考已知终结下的记录感和存在性张力。 |
| 叙事偏好 | 克制、留白、冷峻但有温度；情感通过行为、记录、停顿、选择体现，不靠解释性内心独白。数字生命体的认知方式应与人类不同。 |
| 开放问题 | `OPEN-01` 前序任务性质仍需在 proposal 阶段提出 2-3 个方案供选择，要求参考《超脑48小时》方向但避免雷同。<br>`OPEN-02` 技术员现实关系网仍需确定：有伴侣、无伴侣、独身或其他形态。<br>`OPEN-03` 军方/情报机构的可信设定需要在后续 proposal/PRD 中收束，但 intake 阶段只确认“虚构机构”。<br>`OPEN-04` 数字生命体、技术员、前序人类的具体命名可在 proposal 或 PRD 阶段决定。 |
| 交接状态 | `ready_with_open_questions` |
| 确认状态 | 待确认。本文基于仓库前置材料整理，需用户确认哪些内容应视为 intake 级需求。 |

## 非冻结材料说明

| 材料类型 | intake 处理方式 |
|---|---|
| 旧 PRD / HLD / LLD / writing 文档 | 只抽取与创作目标、题材边界、参考对象、禁区相关的信息；其中的角色档案、世界规则、场景设计、正文样本不在 intake 阶段冻结 |
| 参照作品 survey | 只记录“参考什么”和“避免什么”；不把方法论分析直接变成故事结构 |
| 前置研究规划 | 将用户已确认项记录为需求，将未决项列入 `OPEN-*` |
