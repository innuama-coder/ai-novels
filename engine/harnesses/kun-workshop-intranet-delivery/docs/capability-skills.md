# 能力技能目录

这些是受 harness 调用的有界能力，不是可改变阶段图的“工作流技能”。每项都必须接受工作包输入、输出引用和验证要求。

| 技能 | 主责角色 | 输入 → 输出 | 验证 |
| --- | --- | --- | --- |
| 原型取证与需求追溯 | 产品分析师 | 原型/说明 → 页面盘点、需求-验收矩阵、开放项 | 每条需求有来源或标记未确认 |
| 交互规格化 | UX | 原型/需求 → 状态流、错误/空态、权限可见性 | 覆盖关键任务与异常路径 |
| 架构与 ADR | 架构师 | 需求/NFR/现有系统 → HLD、ADR、接口与数据边界 | ADR 有备选、取舍和回滚影响 |
| 安全与权限建模 | 安全/架构 | 数据/角色/集成 → 威胁模型、RBAC、控制项 | 每个高风险项有处置或 blocker |
| 工作包分解 | 架构师 + 调度者 | 设计 → 依赖图、可验收工作包 | 每包有 owner、DoD、测试与上游引用 |
| 实现与代码审查 | 工程师 + 独立审查者 | 工作包 → 代码、审查结论、单元/组件测试 | CI 与审查门禁通过 |
| 测试设计与自动化 | QA | 追溯矩阵/实现 → 测试集、缺陷和覆盖证据 | 关键需求有正向及失败路径 |
| 发布与回滚编排 | 发布工程师 | 版本/环境资料 → 变更、部署、回滚和冒烟计划 | 目标、版本、授权、回滚均完整 |
| 预发布验收 | QA + 业务代表 | 已部署候选 → 冒烟/验收证据与偏差清单 | 证据绑定环境和版本 |
