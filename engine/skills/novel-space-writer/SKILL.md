## 描述

将 LLD 空间详细设计转化为**可直接嵌入小说的 prose 素材**。空间编写在场景编写之前完成——为每个空间准备完整的"感官写作工具箱"：第一次进入的 prose、感官锚点的重复使用方式、物件状态变化的 prose 写法、空间随叙事演变的描写对照。

**输入**（另源）：
- LLD 空间详细设计——物理布局/感官锚点/物件生态/演化序列/场景映射
- HLD §10 风格与用语规范——感官与空间描写规则（§10.5）/ 情感表达约束（§10.3）
> - 风格锚点参考：`duanxian/design/reference/2026-06-07-style-reference-liu-cixin.md`（刘慈欣风格参考文献，包含22条作品、学术批评、自述及外部来源条目）

**输出**：每个空间的 prose 写作工具箱（独立 markdown 文件）

**与角色编写的关系**：
- 角色编写和空间编写独立且并行
- 场景编写时，空间编写提供"空间现在长什么样、有什么声音、什么温度"
- 空间的情感映照必须与角色在该场景中的行为模式一致——空间感知验证

## 边界定义

### 空间编写回答的问题

| 问题 | 本技能的回答方式 |
|---|---|
| 这个空间第一次出现时怎么写？ | 给出第一段 sensory prose 样本（含决定性感官细节） |
| 本文的感官锚点怎么在文中重复使用？ | 给出 3 种距离 × 3-5 个样本 |
| 角色进入和离开空间的瞬间怎么写？ | 给出"阈值"moment 的 prose 样本 |
| 物件状态变化怎么在 prose 中表达？ | 给出物件在 4 个时间点的不同写法（初始/日常/偏移/终局） |
| 空间的结束状态 vs 初始状态怎么对照？ | 给出结束状态与初始状态的 prose 对照——写"相同但不同" |
| 多个空间如何通过对比强化彼此的质感？ | 给出空间关系中的感官对照写法 |

### 空间编写不包含的内容

```
✗ 重新定义空间的物理布局或感官系统（那是 LLD 空间设计的事）
✗ 定义新的物件或空间演化路径
✗ 写出完整场景（那是场景编写的事）
✗ 角色在不同空间中的行为（那是角色编写和场景编写的事）
✗ 违反 HLD §10.5 感官与空间描写规则（少即多、感官锚点、物的时间性）
```

## 核心技法体系

### 4.1 感官锚点的三种距离写法

每个主空间有 HLD §10.5 定义的固定感官锚点（操作室=风扇声、会议室=声音反弹、住所=练琴声）。锚点在同一篇小说的不同位置需要以不同"距离"出现 [3][10][12]：

| 写法类型 | 定义 | 使用时机 | 使用限制 | 操作室·风扇声的三种写法 |
|---|---|---|---|---|
| **远距·建立** | 锚点作为独立感知对象被描述——读者第一次听到它。包含方位/频率/质感/空间的关系 | 该空间第一次出现——全书仅此 1 次 | 全文不超过 1 次——"我已经听到过了" | "房间里有一种持续的嗡鸣——47 dB，从天花板传下来。她进门时听到了，然后她习惯了这个声音。" |
| **中距·背景** | 锚点作为背景存在——一句话带过，不展开细节。不重复第一次的方位和频率 | 常规进出——读者已熟悉该空间 | 每次进出该空间使用 1 句 | "她走进操作室。风扇声没变。" |
| **近距·被注意** | 锚点从背景中跃出——角色"听到了"本来不会注意的声音。锚点的描述与情感状态同步 | 情感转折场景——空间与角色产生隔阂的瞬间 | 全书 3-5 次，集中在 Act3-Act4 | "她在等。风扇声还在——但突然它变成了房间里唯一的声音。她以前从未听出过它有自己的波形。" |

**锚点写作铁律**：
- 锚点每次出现不重复描述——"她听到了风扇声" 而不是 "47 dB 的风扇嗡鸣从天花板传下来"
- 远距→中距→近距 的路径不可逆——不能写了近距之后再回到中距
- 锚点只在它所属的空间场景中出现——不要在会议室写风扇声

**「断线」各空间锚点写作指引**：

| 空间 | 锚点 | 第一次（远距）写法 | 第 N 次（中距）写法 | 情感时刻（近距）写法 |
|---|---|---|---|---|
| 操作室 | 风扇 47 dB | | 同上 | |
| 会议室 | 声音反弹 | | | |
| 住所 | 练琴声 | | | |
| 数字空间 | 结构感 | | | |

### 4.2 多感官层次嵌入技法

不在一段中堆叠全部感官——将不同感官分布在整个场景的不同时间位置 [6][9][11]：

| 层次 | 嵌入时机 | 每场景使用频率 | 操作室示例 |
|---|---|---|---|
| **听觉（主导层）** | 空间入口处建立——读者感知空间时最先听到的 | 每次 | "她走进操作室。风扇声在。" |
| **触觉（支撑层）** | 角色与物体互动时——手/手指/皮肤接触 | 1-2 次 | "她的手指在操作台边缘停了一下——冷。" |
| **温度（情感层）** | 角色进入/离开时 + 情感时刻的重音 | 1-2 次 | "她坐下时没有脱外套。操作室 22°C——但今天她觉得不够暖。" |
| **视觉（信息层）** | 目光落点 + 空间状态变化时 | 2-3 次 | "她的视线落在呼吸灯上。绿色。没有变化。" |
| **嗅觉（记忆层）** | 场景切换 + 情感转折时刻——触发记忆 | 偶尔 | "金属和臭氧的气味在空气中浮着——她第一天进来时也是这个味道。" |

**感官层次嵌入三原则**：

```
原则 1（时序分离）：同一段中不超过 3 个感官层同时出现。
  "她走进操作室。风扇声在。（听觉）呼吸灯——绿色，稳定。（视觉）
   她坐下。金属操作台——指尖碰到时感觉到冷。（触觉）"
   ✅ 听觉→视觉→触觉（三段分配，不堆叠在同一段）

原则 2（锚点优先）：听觉层必须出现——它是空间锚点的基础。其他层根据场景需要
选择嵌入，不是每个场景都需要全部五个感官。

原则 3（嗅觉节制）：嗅觉层只用在场景切换（K1→K2 的金属味建立）或情感转折
时刻（K9 她走进操作室时——金属+臭氧的气味让她想起第一天）。全书使用 ≤ 3 次。
```

### 4.3 阈值写作——进入与离开空间的 prose 策略

空间通过被"进入"和"离开"而产生叙事意义。在「断线」中，每一个空间进出都是一个叙事事件——不是"只是经过" [1][2][10]：

| 阈值时刻 | 写作策略 | 感官聚焦 | 操作室示例 |
|---|---|---|---|
| **第一次进入** | 建立远距锚点 + 空间与角色的初次关系 | 听觉（锚点建立）+ 温度（新旧对比） | "她推开门。一股冷的气流——操作室 22°C，走廊更冷。风扇声在响了。" |
| **常规进入** | 中距锚点 + 一句空间"现在"的状态 | 听觉（中距）+ 视线落点 | "她走进操作室。风扇声没变。呼吸灯绿色。" |
| **情感进入** | 近距锚点 + 空间"变了"或"没变但我不一样了" | 听觉（近距）+ 第一次注意到的东西 | "她推开门。房间和昨晚一样——但她站在门口没有立刻进去。风扇声没有变化。是她不一样了。" |
| **离开** | 空间的"关门"叙事——门的声音/光的变化/空间的"归还" | 触觉（门把手的温度和手感）+ 听觉（门关上的声音） | "她关上操作室的门。门吸合上的声音——然后安静了。" |
| **最后一次离开** | 空间恢复到"被使用前"的状态——或不再被使用 | 同第一次进入的感官——形成对照 | "门在她身后关上。和第一天一样的声音。但没有下一次了。" |

**阈值写作规则**：
- 进入和离开不是对称的——进入写"获得空间"，离开写"放弃空间"
- 进入时的感官密度 > 离开时的感官密度（进入建立，离开仅确认）
- 第一次和最后一次的阈值写作使用相同的感官序列——让读者在对照中感知变化

### 4.4 空间演化写作技法

空间像角色一样拥有"弧线"——它在一部小说中被使用、留下痕迹、最终改变 [8][15]：

| 演化阶段 | 写作策略 | 角色在空间中的感知变化 | 操作室示例 |
|---|---|---|---|
| **初始（K2）** | 写"新"——设备未使用、空间未"留下痕迹"。使用的感官：气味（新）+ 触感（冷——未被接触过的金属）+ 视觉（整洁） | 角色与空间是"职业者"关系——她在这里工作 | "银色模块排列在消过毒的托盘上。房间闻起来是新的——电子元件还没被加热过的气味。" |
| **日常（K3-K6）** | 写"习惯"——空间被使用的痕迹积累，角色不再注意这些痕迹。使用的感官：触觉（水渍/磨损）+ 视觉（杂物/零乱） | 空间成为背景——她不再注意它的细节 | "操作台上有咖啡杯留下的水渍——一圈淡棕色的环。她没有擦。明天还会有一个。" |
| **变化（K7-K8）** | 写"第一次注意"——角色注意到她本该注意到但从未注意的东西。使用的感官：近距锚点（从背景跃出）+ 视觉（第一次看到本就在那里的东西） | 空间的某一部分从背景中跃出——她第一次"看"了这个空间 | "她第一次注意到呼吸灯。它一直是绿色的——但她在今天之前没有真正看过那个颜色。" |
| **终局（K9-K10）** | 写"相同但不同"——一切和第一天一样，但一切都不一样了。使用的感官：与初始阶段使用完全相同的感官序列——但方向相反 | 角色对空间的感知回到了"第一次"的距离——但这次她带着三个月的故事 | "操作室和第一天一样的冷光。一样的风扇声。一样的操作台。通讯窗口开着——最后一次有字。" |

**演化写作规则**：
- 初始和终局阶段使用相同的感官序列——形成全书级的 callback
- 日常阶段是最长的（覆盖 8-10 个场景）——但每个场景中只用一个感官层变化来标记"时间在过"
- 变化阶段只在 1-2 个场景中出现——反复使用会削弱"第一次注意"的力量

### 4.5 物件状态写作技法

物件的状态变化是时间流逝和角色状态变化最安静的标记。物件不"说话"——但状态变化本身就是叙事 [12][13]：

| 时间点 | 物件状态写法 | 核心技巧 | 操作室咖啡杯示例 |
|---|---|---|---|
| **初始** | 物件的"未被使用"状态——新、干净、原始位置 | 用状态告诉读者"没人用过" | "一个白色陶瓷杯在机柜角——口朝下扣在托盘上。干净的。没有人用过。" |
| **中段·常规使用** | 物件被使用的痕迹——日常的、无意识的。不加注释 | 用痕迹告诉读者"它被使用了"——"水渍"比"她喝过"更有效 | "咖啡杯在机柜右角——口朝上，杯底有一圈干了的水渍。她今天倒过两杯。" |
| **中段·偏移** | 物件显示角色的变化——使用方式的改变。一个物件的状态同时说了两件事 | 两个物件同时出现——一个旧的（过去的模式）、一个新的（不同的状态） | "桌上有两个杯子——一个在机柜角（干了），一个在手边（热的）。她倒了热的，但没喝。" |
| **终局** | 物件回到起始状态——但"干净"不再是"新"的 | 用相同的描述词 + 一个字的差异标记"回不去了" | "咖啡杯在机柜角——口朝下。和第一天一样的位置。但它已经不新了。" |

**物件写作铁律**：
- 一个物件在全文中出现不超过 6 次——超过则读者感觉到"作者在提醒我"
- 每次出现必须有新信息——状态变化/位置变化/角度变化。不能重复
- 物件的状态变化必须与场景时间线严格对齐——读者会追踪
- 关键物件（咖啡杯/呼吸灯/键盘）在每次出现时都需要被提及——但不是每次都用同样篇幅

### 4.6 光影写作技法（空间的光作为叙事工具）

光在空间中的存在方式比空间的物理布局更容易被角色感知，也更容易通过变化来传递情感 [4][5]：

| 光的维度 | 在「断线」中的空间对应 | 写作方法 | 示例 |
|---|---|---|---|
| **色温** | 操作室 4000K（冷白）vs 住所 3000K（暖黄） | 不写色温数字——写视觉感受和对比 | "操作室的灯是白的——不是窗外的白，是灯管的、不改变的白。她回到住所时，发现客厅的灯是黄的。" |
| **光源类型** | 操作室：天花板面板灯（均匀无阴影）；会议室：荧光灯（反光桌面）；住所：吊灯 + 床头灯（混合） | 写光源对角色身体的影响——她站在光中的位置 | "会议室的光从头顶照下来，在桌面形成一个明亮的矩形。她的手放在矩形之外。" |
| **光的稳定性** | 操作室：24 小时恒亮；住所：自然光有昼夜变化 | 写光的"不变"成为压力源——或"变了"成为信号 | "她没注意时间——操作室的光永远不会变。早上和晚上是一样的。" |
| **光的变化** | 呼吸灯的颜色变化（绿→黄→橙→灭）是全书最重要光信号 | 呼吸灯颜色在第一次变化前不描述；变化后的每次出场都需要被描述 | "她进门时先看呼吸灯。不是职责检查——是她在找。它还在那里。" |
| **光与阴影** | 酒店房间（K1）：台灯照明范围有限——明暗切割是前序的叙事工具 | 角色的位置在光中的占比 = 安全感的程度 | "他站在浴室门框旁——半张脸在台灯光线中，半张脸在暗处。他没有再往前走。" |

### 4.7 温度与季节写作技法

「断线」跨越深秋至深冬（3 个月），温度的持续下降是全书最稳定的外部变化。温度写作给"外部世界在继续"的感知 [7][9][14]：

| 温度层 | 覆盖范围 | 写作方法 | 示例 |
|---|---|---|---|
| **外部温度（城市）** | 全书剪影——10 月 12°C → 1 月 -1°C | 每次城市出场只用一句——"更冷了"或"没有更暖" | "她走出实验室时，冷空气迎面。和昨天一样冷。和上个月一样冷。" |
| **内部恒温（操作室）** | 全书 22°C 恒定——温度的非变本身就是叙事 | 只在情感转折时刻提及——"她今天觉得 22°C 不够暖" | "她坐在操作台前，22°C。夏天和冬天一样的温度。她以前从没注意过。" |
| **内部温差（会议室的 19°C）** | 3 次出场——每次都比操作室冷 2-3°C | 每次提温——"比操作室冷"的感知标记"我进入了另一个世界" | "她坐下来。桌面冷——她按下拇指时，金属的温度传上来。和操作室不一样。" |
| **身体温度交互** | K2 前序手背的暖——全书唯一一次"暖"的触觉 | 全书不重复——在 K2 中建立，在 K10 中因为她自己的体温而回响 | "她的手碰到了他的皮肤——暖的。在 22°C 的操作室中，这是她碰到的唯一一个不是工具的东西。" |

**温度写作铁律**：
- 外部温度每次出场只说一句——不展开
- 操作室恒温只有在被角色"注意到"时才被写入——平时是"被忽略的背景"
- 前序的"暖"在全书中只出现一次（K2）——不重复描述
- 会议室 19°C 在每次出场中都至少要提一次温差——"坐在操作室相似的位置但更冷"

### 4.8 空间对比与关系写作

在「断线」中，不同空间之间的对比比单个空间内的变化更具叙事力量——读者通过"这里和那里的不同"理解两个世界的差异 [2][4]：

| 对比对 | 对比维度 | 写作方法 | 示例 |
|---|---|---|---|
| **操作室 vs 会议室** | 温度（22°C vs 19°C）+ 声学（风扇底噪 vs 声音反弹）+ 安全 vs 压力 | 同一角色在两个空间中的行为对照 | "她在操作室坐着——可以一直坐下去。但会议室——椅子不一样、温度不一样、声音从墙面弹回来。她坐下来的第一秒就想离开。" |
| **操作室 vs 住所** | 冷光 vs 暖光 + 无窗 vs 有窗 + 风扇 vs 练琴声 + 工作 vs 生活 | 她穿过城市（40 分钟通勤）后的感官切换 | "回到住所，灯是黄的。窗外有邻居炒菜的声音和油烟气。她站在厨房里——操作室的金属味还在鼻腔里，但这里的味道不一样。" |
| **数字空间 vs 操作室** | 无感知 vs 全部感官 + 无限 vs 60m² + 无时间 vs 有风扇声 | 切换 POV 时的空间锚点对照 | "通讯窗口亮了。文字一个一个地出现。操作室外没有数字空间——它不在操作室里。它是操作室里的一个屏幕能访问的东西。" |

**多空间叙事策略**：
- 她一天的空间移动路径构成了"从日常到特殊"的叙事弧——住所→城市→实验室→操作室→（数字空间）→反向
- 每一段路径都通过感官切换标记"我进入了另一个世界"
- K10 后她回到住所——住所中的所有感官信号（暖光/练琴声/冰箱压缩机）都不再是"日常"——它们成了"她不操作"

### 4.9 空间-情感映照矩阵

通过空间状态的变化传递角色的情感——不写"她感到___"，写"空间中的___变了" [9][11]：

| 角色情感状态 | 空间如何写 | 操作室示例 |
|---|---|---|
| **困惑** | 空间中某件一直存在的东西被"看到"——第一次注意到它本来的样子 | "走廊——她走了三年的走廊——今天看起来更长了一些。它一直这么长。但她直到今天才发现。" |
| **焦虑** | 空间中的恒定因素产生微变——或者角色感知到它有了微变 | "风扇声没有变化——但她觉得它的频率变了。她用手机录了一下。播放出来是一样的。但她还是觉得变了。" |
| **期待** | 空间的某部分成为视觉焦点——她看了一个不需要看的地方 | "她走进操作室时，目光落在通讯窗口上——而不是图谱屏。她没意识到自己先看的是那里。" |
| **失去** | 空间"空"了——不是缺了东西，是角色的感知方式变了 | "操作室和第一天一样。22°C。风扇 47 dB。呼吸灯暗了。一切都一样——但和第一天已经完全不同了。" |
| **保护** | 空间的边界感增强——门/墙/距离被感知 | "从操作室到走廊——门关上之后，她听到密封胶条'吸'的声响。她以前从没注意过这扇门有声音。" |
| **回到原点** | 同一天的同一时刻写同一空间——但三次的描述完全不同 | K10 她回到操作室——"操作室的光从天花板照下来，在桌面上形成一块灰白色的矩形。和第一天一样。和她等在那里的时候一样。但现在她是一个人站在这里。" |

**情感-空间对照规则**：
- 情感不通过"她感受到"传递——通过"她注意到了什么"传递
- 她注意到的东西越"本不该注意"（灯的型号/门的吸合声/风扇的波形）——情感越强
- 情感最强烈的时候，她注意到的往往是"最具物理性"的东西——不是情感/记忆/关系，是"门把手是冷的"

### 空间编写流程（每个空间独立执行）

```
Step 1: 读取双源输入
        ├── LLD 空间详细设计（物理布局 + 感官层 + 物件生态 + 演化序列 + 场景映射）

        ↓

        ↓

        ↓

        ↓

        ↓

        ↓

        ↓

```
