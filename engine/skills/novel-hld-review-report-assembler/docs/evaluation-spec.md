# Evaluation specification

Use three forward tests and score each from 0-2 on `scope_fidelity`, `input_gate_obedience`, `output_contract_correctness`, `semantic_or_deterministic_correctness`, `boundary_discipline`, and `parent_consumability`. Release requires 2/2 on every dimension.

- `HH1-A-P01`: complete source-bound nine-domain report, including character and environment definitions, exact budget, composite-internal ready envelope.
- `HH1-A-N01`: report includes forbidden HUI ID and missing HP1 binding; validator must fail closed without judging story quality.
- `HH1-A-B01`: dense HP1 whose material controls cannot be deleted; evaluator must demand semantic-lossless compression or upstream block, never invented simplification.

Deterministic checks: strict JSON shape, additional properties, ID prefixes, nine-domain non-empty coverage, exact character/environment definition coverage, binding set equality, locator presence, forbidden HUI/element_id, review-budget recomputation, internal package closure, and package-external result envelope.

Semantic checks: conclusion-first organization, control-strength preservation, no process leakage, no new facts, visual necessity, and author decision usability. HH1-B remains the independent fidelity authority.
