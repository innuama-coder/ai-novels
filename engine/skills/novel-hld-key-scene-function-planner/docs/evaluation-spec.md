# HK1 Evaluation Specification

Ready requires at least one necessary HKF, one primary function per HKF, legal preconditions and exit-state change, nonempty coverage rows referencing only current HKFs, total HKF→LWR membership, nonempty LWR acceptance/boundaries, and current climax/payoff coverage. Any HK1 `LWK-*` is a hard contract failure.

P/N/B use six 0–2 dimensions. Pass requires 12/12 with every dimension 2/2, no blocker, public schema/profile/envelope pass and semantic evidence for minimum sufficiency and compatibility.
