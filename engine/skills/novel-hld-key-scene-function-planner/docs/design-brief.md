# HK1 Design Brief

HK1 synthesizes all admitted structural, storyline, character, information and rhythm obligations into a minimum-sufficient set of key-scene functions and an authoritative LLD work-requirement grouping. HK1 owns `HKF-*` and `LWR-*`; HP1 alone later projects each current LWR into `LWK-*`. HK1 defines function, precondition, state change, constraints and acceptance—not action, dialogue, imagery, props or prose.

The agent owns merge/split judgment and evidence. The shared runtime owns public admission, dependency blocking and deterministic delivery envelopes.
