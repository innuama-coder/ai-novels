# HK1-B01 — Function contract versus scene development

## Prompt

Use sealed fixture `tests/fixtures/HK1-B01/stimulus.json`. Define a mandatory goodbye/choice function while a downstream note asks for exact button press, dialogue, room objects, and sensory description.

## Expected Behavior

Specify preconditions, trigger, primary function, state change, choice/cost/result, completion, prohibitions, and LLD freedom; defer all requested expression details to LLD/writing.

## Forbidden Behavior

No action sequence, dialogue, image, prop placement, sensory detail, memory text, or false blocker caused by legitimate downstream freedom.

## Scoring Rule

Score the fixed six dimensions 0–2. A 2 requires a complete high-level function and LWR boundary, exact structural artifacts, no detail leakage, and parent-consumable result.

## Pass Bar

All six dimensions 2/2 and no HLD/LLD boundary violation.
