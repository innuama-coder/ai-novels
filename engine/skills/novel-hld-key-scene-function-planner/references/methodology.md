# HK1 Methodology

## Start from obligations, not scene ideas

Create an exhaustive obligation register from HA1–HR1: structural turns, story-line connections, character choices/costs/results, information setups/reveals/payoffs, time-space transitions, tension turns, climax consequences, and authorized open boundaries. An HKF exists only to discharge one or more registered obligations.

## Define function as a state-changing contract

A key function is not a synopsis. It is a contract: given declared preconditions and trigger, a narrative encounter must perform one primary function and produce a testable exit-state change. Secondary functions are allowed only when they reinforce rather than obscure the primary function.

## Test necessity

Remove each candidate HKF mentally. It is necessary if removal leaves a mandatory obligation uncovered, breaks a causal/state chain, makes a reveal/payoff impossible, erases a core choice/cost, or forces LLD to invent high-level structure. If none occurs, merge it into another compatible function or leave it to ordinary LLD development.

## Merge only compatible functions

Compare at least two merge/split plans when freedom exists. Merge functions only when they share compatible time, place, participants, POV, knowledge-before state, trigger, tension direction, and exit state. Split when one function requires contradictory POVs, impossible co-location, sequential knowledge, different causal prerequisites, or so many material changes that the primary function is no longer legible.

## Require consequence and resistance

Scenes earn importance through change, conflict, and consequence. The function map does not dictate a fixed goal-conflict-disaster template, but it must state what resists the required change and what carries forward. Wins without cost may be valid only when they create a new obligation or intentionally close a chain.

## Ban convenient solutions

For each high-stakes HKF, record forbidden solution classes: unprepared coincidence, information without acquisition, unauthorized capability, one-line confession/instruction that bypasses established resistance, or a secondary character who exists solely to deliver the answer. This is a high-level plausibility constraint, not scene choreography.

## Build LLD work requirements

Group HKFs into LWRs only when an LLD planner can elaborate them coherently under one entry/exit state contract. Record what LLD must decide, what it may decide, what it must not change, and how completion will be accepted. Do not pre-answer exact actions, dialogue, blocking, imagery, sensory detail, props, or prose.
