# HK1 SOP

1. Preflight the sealed work order, owner, stage, state, ordered upstream completions, allowlist, hashes, return binding, and plan binding.
2. Produce all `HDD-HK1-*` assessments before candidates; stop with author-required blocked evidence on `required_now`.
3. Build the exhaustive high-level obligation register from HA1–HR1 and source controls. Give every obligation a stable source ID and required outcome.
4. Form initial HKF candidates around obligations, not around imagined scenes. Give each one preconditions, trigger, primary function, required change, exit state, and acceptance.
5. Run the removal test on each candidate and eliminate filler/redundancy.
6. Compare at least two real merge/split plans, or document why constraints leave only one. Test time, place, participants, POV, knowledge, state, tension, and causality compatibility.
7. Bind each retained HKF to chapter/unit, story lines, events, characters, environments, POV/knowledge, continuity, pacing, and tension.
8. Add choice/cost/result and forbidden-solution controls where applicable. Reject coincidence, one-line bypass, unauthorized information/power, and tool-person solutions.
9. Establish structural, storyline, arc, information, climax, and payoff coverage matrices; require full applicable-obligation coverage.
10. Group HKFs into HK1-owned `LWR-*` requirements with explicit rationale, entry/exit state, required elaboration, freedom, prohibitions, and acceptance. Reserve `LWK-*` for HP1's one-to-one projection.
11. Adversarially test uncovered obligations, duplicate primary functions, overload, incompatible merge, arbitrary split, no-consumer HKF, missing LWR, and LLD/prose leakage.
12. Project selected decisions, package exact artifacts, run deterministic validation, and apply the semantic rubric before ready.
