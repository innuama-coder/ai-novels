# 固定评审文风契约

## 1. 身份

```text
style_contract_id: restrained-concrete-scene-v1
depth_contract_id: character-grounded-scene-v1
language_contract_id: zh-Hans-review-v1
purpose: conception_review_sample
name: 克制具象的场景驱动现代白描
pov_mode: third_person_limited
```

它是跨题材的评审基准，不是小说最终声音。固定文风的目的，是让作者判断构思
本身能否产生有效场景，避免华丽修辞、类型套路或作者模仿掩盖设计缺陷。

## 2. 七项固定原则

| 代码 | 原则 | 页面表现 |
| --- | --- | --- |
| `single_limited_pov` | 单一受限视角 | 只写 POV 能感知、知道、回忆、推断或误解的内容。 |
| `continuous_scene_now` | 连续场景当下 | 以行动、互动和环境反馈构成主体；必要说明保持短促。 |
| `concrete_selective_detail` | 具体且选择性的细节 | 每个细节同时承担定位、压力、人物或世界功能。 |
| `pressure_choice_consequence` | 压力—选择—后果 | 人物必须作出影响状态的选择，后果在片段内可见。 |
| `subtextual_interaction` | 有目的和潜台词的互动 | 对话、沉默、动作都在争取、拒绝、试探或隐藏。 |
| `restrained_emotion` | 克制情绪 | 以行为、注意力、句法和身体/认知变化承载情绪。 |
| `earned_state_change` | 结尾状态变化 | 片段结束时关系、信息、责任、危险或选择至少一项改变。 |

七项风格原则之外，人物深度契约要求：人物同时承受不能兼得的欲望；关键刺激经过
人物独有的解释后才变成行动；策略受到递进阻力；对话或互动存在表层意义与真实压力
之间的空隙；结尾保留读者推断，不用抽象主题句收束。

## 3. 可调轴

只允许根据当前 brief 及其 P1 source-value bindings 调整：

- `genre_lexicon`：题材必要术语；
- `character_diction`：人物教育、职业、关系和处境形成的说话方式；
- `emotional_temperature`：冷、暖、紧张、哀伤等；
- `sentence_rhythm`：在清晰和克制前提下长短变化；
- `sensory_channels`：只使用 POV 实际拥有的感官或信息通道。

可调轴不能改变七项固定原则。

评审基准固定使用简体中文与第三人称受限视角。不得切换第一人称、全知视角、
跳头或其他语言；题材术语、人物措辞、情绪温度、句子节奏和可用感知通道只能
在 brief 明示范围内调整。

## 4. 硬禁止

- 大纲、梗概、镜头脚本、舞台指示、评审说明；
- 作者出面解释人物、主题、伏笔或片段目的；
- 直接模仿特定作者或复制其可辨识句法；
- 全知跳头、未授权感官、未获得的信息；
- 把仍应保持悬念的决定、计划或结论写成决定性内心事实；只允许展示形成中的
  感受、权衡、回忆、推断和可观察反应；
- 用回忆或内心独白替代当下选择；
- 人物互相讲述双方都已知道的设定；
- 只写气氛而没有压力和状态变化；
- 以“命运的齿轮”“空气仿佛凝固”“一切才刚刚开始”等套语收束；
- 以“新的情感正在生成”“责任仍无答案”“这意味着”等抽象判断替读者解释；
- 把 brief 的前态、目标、压力、阻碍、选择、后果、后态各写成一句验收摘要；
- 把样片称为最终正文或用局部创作选择建立新设定。

## 5. 说明与展示的平衡

“展示而非讲述”不是禁止所有概述。允许概述：

- 快速跨过不承担评审功能的动作；
- 在 POV 内压缩已经发生的低价值重复；
- 用一句建立时间、位置或必要前态。

不得概述：

- brief 要验证的压力；
- 人物关键选择；
- 关系变化；
- 世界规则造成的代价；
- 结尾状态变化。

这些必须在场景中发生。

## 6. 语言纪律

- 句子优先清楚、具体、可朗读；
- 不以形容词和副词堆叠制造强度；
- 比喻只在来源人物能够自然产生且承担功能时使用；
- 对话不复制真实口语的全部填充词，而保留个性、目的、打断和回避；
- 对话标签保持透明，更多用动作节拍区分说话者；
- 段落体现注意力或行动变化，不形成整页无锚点对白。
