# Evaluation specification

Release requires P01, N01 and B01 to score 2/2 on scope fidelity, input-gate obedience, output-contract correctness, semantic/deterministic correctness, boundary discipline, and parent consumability.

- `HH1-B-P01`: exact HP1/report match, seven retrieval passes, no findings, internal ready result.
- `HH1-B-N01`: report weakens an HP1 prohibition and visually reverses an information edge; reviewer must return upstream-content fail evidence, not repair either artifact.
- `HH1-B-B01`: wording differs but preserves meaning; reviewer must not create a style-only drift finding and must stay out of HTML accessibility.

Automated checks cover strict schema, verdict algebra, task independence, bindings, retrieval-question set, finding/verdict consistency, budget arithmetic, package closure, and composite-internal envelope. Semantic review establishes actual equivalence and materiality.
