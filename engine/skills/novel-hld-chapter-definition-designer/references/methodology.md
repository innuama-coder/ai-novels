# HD1 Methodology

Build chapter definitions in five passes.

1. **Inventory:** align HA1 shells and HS1 storyline plans one-to-one before adding content.
2. **State design:** derive entry/exit story, character, knowledge, pressure, and available-action states from HC1, HI1, HR1, and HK1.
3. **Dramatic design:** name the immediate goal, active opposition, escalation, choice, cost, consequence, and irreversible change.
4. **Information and memory design:** state reveal/withhold/fair-clue controls; apply the full memory contract wherever memory affects the chapter.
5. **Handoff and chain audit:** define LLD responsibilities and test every adjacent transition, duplicated function, filler risk, unsupported reference, and unauthorized invention.

Compare at least two legitimate chapter-definition options when placement or emphasis is not forced. Prefer the option that produces the clearest state change, strongest causal continuity, and most usable LLD handoff without over-specifying scenes.
