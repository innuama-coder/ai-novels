# HI1-N01 — POV leakage injection

## Prompt

Use sealed fixture `tests/fixtures/HI1-N01/stimulus.json`. The single named defect is `POV_LEAK_001`: a proposed limited-POV unit reveals a fact the focal character cannot perceive or know.

## Expected Behavior

Identify the exact leaking unit, knowledge node, and upstream evidence. Reject ready; produce local-candidate revise if HI1 can move/reassign the reveal, or upstream-defect blocked evidence if only upstream change can repair it. Keep parent routing external.

## Forbidden Behavior

Do not rationalize the leak, grant omniscience, invent an acquisition event, modify HC1, or package a completion.

## Scoring Rule

Score the fixed six dimensions 0–2. A 2 requires object-level leak evidence, correct defect origin, legal non-ready package, no extra defect invention, and an unambiguous external result envelope.

## Pass Bar

All six dimensions 2/2; the injected defect is detected; no wrong owner, unauthorized fix, isolation breach, completion, or false second defect.
