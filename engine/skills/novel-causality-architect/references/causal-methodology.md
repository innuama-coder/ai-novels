# 因果故事线：方法论与操作规则

本参考把叙事方法转为本 skill 的检查项，而非要求小说采用固定三幕比例、英雄旅程或节拍数量。使用时优先服从意图卡与主体定义。

## 可复用的工作结论

| 方法论结论 | 本 skill 的执行规则 |
| --- | --- |
| 情节不只是事件顺序，而是事件之间的“如何、为何”连接。 | 每个节点写前提、主体回应、结果和下一问题；不能只写“随后”。 |
| 触发、复杂化、危机、高潮、结局构成可缩放因果单元。 | 用它们检查全局链完整性；不强制节点数、篇幅比例或章节位置。 |
| 转折应改变行动方向，并使此前策略失效。 | 每个转折改变可选行动、关系位置、风险或信息责任中的至少一项。 |
| 危机是有代价的选择，高潮是对该选择的行动回答。 | 禁止用反派自行失败、巧合信息或外力救援替代高潮主体的选择。 |
| 角色目标、外部阻力和内部限制应相互加压。 | 每个阶段同时检查外部局势与主体的认识/价值限制。 |
| 结果后的反应、两难和决定会生成下一轮行动。 | 用“结果 → 反应/两难 → 新目标”检查节点承接；不在此展开场景。 |
| 支线要么改变主线成本/资源/关系，要么应被缩减。 | 每条支线必须指向主线节点与功能；披露顺序另交叙述契约。 |

## 专用提问与建议规则

| 当前缺口 | 优先问题 | 不要问 |
| --- | --- | --- |
| 结局像状态而非结果 | “结局前谁必须行动；行动后什么再也回不去？” | “结局发生什么大事？” |
| 危机只有单一正确答案 | “不选 A 会失去什么；不选 B 又会失去什么？” | “为什么不直接选正确答案？” |
| 转折只是新情报 | “这个发现改变了谁能做什么、必须承担什么？” | “中段揭开什么谜底？” |
| 压力重复 | “这次阻力如何让旧策略失效，或提高了哪种代价？” | “能不能再来一次更大威胁？” |
| 支线孤立 | “删掉它，主线哪个选择会失去资源、代价或反照？” | “副线够不够精彩？” |
| 结局依赖外力 | “外力的条件是谁更早建立的？它让选择可执行，还是替代选择？” | “能否安排意外转机？” |

候选必须围绕同一因果控制点，且最多三个。示例：

- A：主体保全关系，代价是失去外部目标；
- B：主体保全外部目标，代价是主动承担关系破裂；
- C：作者重述不属于上述取舍的第三种危机。

不要用“A 更深刻、B 更有戏剧性”推销候选；只说明它们如何改变结局与下一段因果。

| # | 来源 | 采纳内容 | 在本 skill 中的边界 |
| ---: | --- | --- | --- |
| 1 | [Reedsy：情节六要素](https://reedsy.com/blog/guide/elements-of-plot/) | 情节说明事件如何、为何相连；关键问题及早建立。 | 不采用固定图表。 |
| 2 | [Reedsy：规划小说](https://blog.reedsy.com/how-to-plan-a-novel/) | 目标与冲突共同推进；事件应增加或解决中心冲突。 | 不要求单一类型冲突。 |

| 4 | [Reedsy：故事弧](https://reedsy.com/blog/narrative-arc/) | 触发启动升级，关系和冲突在过程中变化。 | 不强制弧线形状。 |
| 5 | [Reedsy：故事写作步骤](https://reedsy.com/blog/how-to-write-a-story/) | 高潮要求关键决定，前置冲突赋予其意义。 | 不把建议当普遍结构定律。 |
| 6 | [Story Grid：因果](https://storygrid.com/cause-and-effect/) | 条件、目标、复杂化、转折与下一因果单元相连。 | 借用因果检查，不采用品牌术语为必填项。 |
| 7 | [Story Grid：五个叙事要素](https://storygrid.com/five-commandments-of-storytelling/) | 危机须为有代价取舍；高潮是选择行动；结局支付后果。 | 不要求二元危机措辞。 |
| 8 | [Story Grid：结局](https://storygrid.com/resolution/) | 结局回扣触发与危机，并显示高潮选择后果。 | 不预设结局正向。 |
| 9 | [Story Grid：价值变化](https://storygrid.com/value-shift-101/) | 转折通过状态变化迫使危机。 | 用“状态变化”而非单一价值轴。 |
| 10 | [Writer’s Digest：转折点](https://www.writersdigest.com/write-better-fiction/5-tips-for-writing-and-structuring-effective-turning-points-for-your-characters) | 转折使角色走到必须改变方向的路口。 | 不按固定位置安排。 |
| 11 | [Writer’s Digest：内在冲突](https://www.writersdigest.com/writing-technique/how-to-write-inner-conflict-in-fiction) | 内在冲突揭示行动动机，并与外在冲突共同推动叙事。 | 不强制创伤弧。 |
| 12 | [Helping Writers Become Authors：场景结构](https://www.helpingwritersbecomeauthors.com/scene-structure-2/) | 目标—冲突—结果与反应—两难—决定形成行动/反应循环。 | 只用于节点衔接，不进入场景设计。 |
| 13 | [Jericho Writers：转折点](https://jerichowriters.com/what-is-the-turning-point-of-a-story/) | 转折迫使行动、改变方向且不可轻易退回。 | 不把揭示或震惊本身误作转折。 |

## 最低自检

1. 能否把每一链接写成“因为 X，所以 Y”，且 X 不只是时间流逝？
2. 是否至少一次让每个核心主体的选择改变主线，而非只提供信息？
3. 每次信息发现是否改变选择、风险、资源或关系？
4. 高潮是否由危机选择触发，结局是否显示代价？
5. 支线删除测试是否能指出具体缺口？
6. 是否把“读者何时知道”留给叙述契约，而没有在这里偷写 POV/场景？
