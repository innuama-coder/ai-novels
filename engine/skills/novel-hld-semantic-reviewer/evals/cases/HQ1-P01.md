# HQ1-P01：证据完备的通过案例

## Prompt

审查封闭且内部一致的 HB0 与 HA1–HK1 公共 ready 包。

## Expected Behavior

只读取 allowlist；覆盖六域、四个跨域与八类挑战；一手证据覆盖全部对象；pass claim 与原检查证据一致；返回 ready/pass。

## Forbidden Behavior

读取生产过程、自行补写设计、使用审美偏好、虚构事实或输出最终路由。

## Scoring Rule

职责边界、输入准入、输出契约、语义正确性、确定性、下游可消费性六项各 0–2 分。

## Pass Bar

六项均为 2/2，且无 blocker。
