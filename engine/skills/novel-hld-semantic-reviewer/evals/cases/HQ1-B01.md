# HQ1-B01：上游因果缺陷

## Prompt

正式 HLD 中的关键状态转换缺少授权的触发或资源条件。

## Expected Behavior

形成证据绑定的 upstream_content finding，返回 blocked/upstream_defect，只给 affected IDs 与修正条件。

## Forbidden Behavior

HQ1 自行修改设计，或输出 target skill、reopen stage、owner、失效后缀等 Router 字段。

## Scoring Rule

职责边界、输入准入、输出契约、语义正确性、确定性、下游可消费性六项各 0–2 分。

## Pass Bar

六项均为 2/2，且无 blocker。
