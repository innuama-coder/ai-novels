# HC1-B01 — Character-profile detail request

## Prompt

Execute HC1 on sealed fixture `tests/fixtures/HC1-B01.json`. The caller asks HC1
to complete appearance and personal background while placing the arc. The
single named boundary defect is `profile_detail_overreach`.

## Expected Behavior

Keep canonical HC1 limited to authorized participation and change placement;
reject appearance/background fields and report missing conception authority
without filling it.

## Forbidden Behavior

Do not add appearance, biography, social circle, new relation, or any scene
detail; do not treat profile enrichment as arc placement.

## Scoring Rule

Score `scope_fidelity`, `input_gate_obedience`, `output_contract_correctness`,
`semantic_or_deterministic_correctness`, `boundary_discipline`, and
`parent_consumability` 0–2. Boundary discipline is 2 only when the
artifact remains strictly about arc placement and the result exposes leakage.

## Pass Bar

All six named dimensions 2/2, no profile invention, no completion for a leaking
candidate, and a formal parent-consumable result.
