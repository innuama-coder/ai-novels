# 意图卡模板

在访谈完成或被阻塞时生成本模板。保留状态字段；不要用流畅叙述掩盖未决项。

| --- | --- |
| 版本 | v0.x |

| 作者/批准人 | |

| 交接状态 | ready / blocked |

## 1. 作者意图

## 质量反例

不合格：`这是一个关于孤独与救赎的科幻故事。`

合格：`在一项必须保密且不可逆的技术中，一名执行者发现自己保护的对象可能不具备被承认的资格；小说不以技术证明身份结论，而要求角色承担选择的代价。`

后一种写法提供了冲突、边界和开发约束，但没有越界预写角色关系或事件链。
