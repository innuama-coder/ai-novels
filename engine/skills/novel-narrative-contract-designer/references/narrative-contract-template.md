# 叙述契约模板

使用此模板生成 `narrative-contract.md`。只记录会控制开发选择的规则；不填写章节表、场景动作、连续样稿或具体对白。

## 目录

1. 基本信息与继承边界
2. 读者体验、聚焦权限与披露台账
3. 时间组织与表达原则
4. 决策、审计与交接
5. 最小会话记录
