## 2. 描述工具箱

### 2.1 决定性细节

| 决定性细节 | 写法 |
|---|---|
| **椅背上的外套**——有人但人不在的标记 | "操作台前的椅子空着——椅背上搭着一件外套。人不在——去食堂了，或去走廊接电话了。" |
| **键盘声**——有人在但不在视线内的标记 | "她经过走廊时，某个房间里传来持续的键盘敲击声——有人在正常地做自己的工作。" |
| **走廊上模糊的对话声**——周围有活人的标记 | "走廊尽头有人在打电话——声音模糊，听不清内容。她经过时没有减速。" |

### 2.2 可复用 prose 片段

**片段 A：Act1 同事存在·正常生态**
```
走廊上有人经过。她没抬头——不需要。脚步声是熟悉的节奏——这个时间段的换班交接。
```

**片段 B：Act2 同事存在·背景噪声**
```
她从走廊尽头走过来时，有个人靠在窗边打电话。她没有减速。那个人没有抬头。她在 K3 未上报后第一次经过走廊——她感觉到了"我没有被注意到"这个正常的事实的重量。
```

**片段 C：Act4 同事存在·撤退**
```
这段时间走廊上的人比平时少——还是她来得早了？她不知道。以前她会注意哪个工位的人今天在不在——她现在不知道了。
```

## 3. 行为工具箱

集体行为模式——不变化、不介入、不出现在关键场景。

| 阶段 | 集体行为 | 描写 |
|---|---|---|
| Act1 | 正常日常工作——走廊有人/工位有人/交接正常 | "走廊上有人经过。""工位上有键盘声。" |
| Act2 | 照常工作——沈逾不再注意他们 | "她从走廊尽头走过来时——有人靠窗打电话。她没有抬头看是谁。" |
| Act4 | 项目关闭阶段——环境安静了 | "走廊上比平时安静了——还是她来得晚了？她不知道。" |

## 4. 对话与声音

同事的对话如果出现——字数不超过 5 个字，内容限于日常事务，不递送情节信息。

> "今天冷。"
> "走了。"
> "明天见。"

## 5. 场景编写指引

| 场景 | 群体状态 | 叙事呈现 |
|---|---|---|
| Act1 走廊 | 正常——有人在经过 | "走廊上有人经过。她没抬头。" |
| Act2 走廊 | 正常——沈逾不再注意 | "她从走廊尽头走过来——有人靠在窗边打电话。她没减速。" |
| Act4 走廊 | 安静——或注意力不在 | "走廊上比平时安静了。她不知道是因为人少了还是她来得早了。" |

## 6. 禁写清单

- 不个别化——无名字、无特征、无个人对话（除 5 字内日常问候）
- 不出现在关键场景——K3/K6/K8/K9
- 不承载情感功能——不对沈逾变化产生反应
- 数量不指明——用"有人""走廊上有人"暗示存在

## 7. 角色间关系写作对照

### 同事 ↔ 沈逾

- 物理距离近但认知距离远——工位很近但对彼此的生活所知极为有限
- 他们的"不变"为沈逾的"变"提供了刻度：同事仍然正常上下班→沈逾加班的时间越来越长
- 纪菱承担的"担心"功能——同事不承担

### 同事 ↔ 它

- 无任何关系——同事不知道它的存在

---

*同事是全书最轻量级的角色——他们的存在不是为了被记住，是让沈逾在独自走回操作室的路上，她不是完全独自一人。*
