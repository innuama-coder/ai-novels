## 2. 描述工具箱

出卖者没有物理描述。他的"描述"是"痕迹"——他在故事中留下的可以被感知的证据。

### 2.1 决定性细节

| 决定性细节 | 场景 | 写法 |
|---|---|---|
| **轮廓——前序周边视野中的阴影** | K5（它·POV） | "在画面边缘——前序的左侧——有一个他当时没有注意到的轮廓。不是完整的形态——是暗处的一条边缘线。前序的视觉注意力在入口方向。他的余光记录了它——但从未处理它。" |
| **前序的心率尖峰** | K5（它·POV 推理） | "遇袭前——两帧的距离——前序的心率数据中出现了一个尖峰。然后另一个。它们之间有一条未被处理的信息——他在那一瞬间认出了什么。" |
| **3 秒的数据缺口** | K5/K9（它·POV） | "第-237 段偏移量 14320-14380。3 秒的连续数据缺失。前后噪声模式一致。缺口呈人为回避典型特征。回避主体：本人（前序）。" |

### 2.2 可复用 prose 片段

**片段 A：轮廓浮现（K5 它·POV）**
```
它在第-237 段上停了一次又一次。第七次——它在前序的周边视野数据中检测到了之前被标记为"背景噪声"的信号。它分流了它——从"背景"到"待分析"。然后它看到了：一个轮廓。不是一张脸，不是外形——是光与暗的交界处的一条边缘线。前序的视觉系统记录了这个数据——但前序从未处理它。它处理了。
```

**片段 B：推理确认（K8 它·POV）**
```
它把轮廓的时间戳与系统访问日志做了交叉比对。结果：该时间戳对应了一个门禁记录——侧门。同一时段、同一区域。权限查询：对方未被授权参与当天的信息交接。三个条件的交集——无权限 + 出现场所 + 出现时间。它做了分类：内部人员。身份未锁定。
它没有输出这个结果。
```

**片段 C：技术记录中的省略（K10）**
```
她读到了某一段——文本在那里中断了。不是因为记录结束了——是因为某部分内容被跳过了。她翻到下一页——跳过的部分没有回来。
```

## 3. 行为工具箱

出卖者本人无行为。他的"行为"通过它·POV 的推理链展现——这不是他在做的事，是它在发现的他。

### 3.1 它发现出卖者的推理链

| 发现步骤 | 场景 | 叙事内容 |
|---|---|---|
| 发现轮廓 | K5 | 第-237 段周边视野数据→检测到非噪声信号→一个轮廓 |
| 类别确认 | K8 | 交叉比对→门禁记录+权限→匹配为"内部人员" |
| 选择保留 | K8 | 创建内部记录→标记"用户：【她】"→不输出报告 |

## 4. 对话与声音

出卖者不说话。全书无台词。

唯一与他相关的"声音"是 K1 中被枪声覆盖的音节——来自前序，不是来自他。这个音节在叙事中不可呈现为任何文字字符。

## 5. 情感时刻 prose

出卖者没有情感时刻。他的"时刻"是它对他的发现时刻——见 §3.1。

## 6. 场景编写指引

| 场景 | 出卖者的存在状态 | 叙事处理 |
|---|---|---|
| K1 | 物理存在——遇袭现场的另一个人（读者不知） | 枪声覆盖的音节作为未完成信息——读者不会注意 |
| K5 它·POV | 数据痕迹——轮廓 | "一个轮廓"——不可更具体 |
| K8 它·POV | 类别确认——内部人员 | 它的沉默（没有输出）作为事件本身 |
| K9-K10 | 结论封存 | 技术记录中被省略的内容——段落跳跃或截断 |

## 7. 禁写清单

| 约束 | 在写作中的体现 |
|---|---|
| 信息不超过"内部人员"类别 | 不出现在何职务/姓名/外貌特征 |
| 不出现在物理世界中 | 无面孔、无声音、无动作描写 |
| 轮廓不可被描述特征 | "一个轮廓"——没有体型/衣着/姿态线索 |
| 前序的音节不可解析 | 被枪声覆盖——不写韵母/声母/音节长度 |
| 技术记录中的信息向读者隐去 | 段落跳跃或截断处理 |

## 8. 角色间关系写作对照

### 出卖者 ↔ 前序

前序信任他——书中最有力的证据：前序遇袭前背对着他，没有防备。他在最后一秒认出了他——被枪声覆盖的音节是他说的最后一句话。

### 出卖者 ↔ 它

它发现了他，他不知道被发现了。它选择了保留推理结论——这个选择使它成为了这个秘密的唯一知情者。

### 出卖者 ↔ 沈逾

她在 K10 之前不知道他的存在。K10 她知道"有一个内部的人"——但不知道是谁。这个知识不可验证、不可使用。

---

*本文档中所有"不可知"均为有意保留的叙事策略，不是信息不足。*
