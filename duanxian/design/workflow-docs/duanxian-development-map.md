## 不可违反项

- R-07 是由顾衡记忆形成的新主体；当前没有视听、身体或自我感知，现实外界只能以文字与其交流。
- 顾衡过去的感官经验只能作为当前文字触发、可中断的记忆片段出现；R-07 启动后不再有第二条主线。
- 项目启动归团队/上级；沈逾的选择是知情后接受执行与交流职责。
- C5 后 R-07 已形成终止计划，开发不得再进入其内部 POV；不能用压住它明知的内容制造悬念。
- 袭击必须经 R-07 情报、团队行动、专家/硬件/授权核验而被完全避免；R-07 不能直接操作外部系统。
- R-07 的当前主体不可逆终止。沈逾相信可能重载；读者凭外部证据确认 R-07 知道当前终止不可逆；两国关系未恢复互信。

## 排序与依赖

```text
M01 → M02 → M03 → M04 → M05 → M06 → M07 → M08 → M09 → M10
```

- M01 与 M02 可在同一现实时间窗交错，但 M02 的接受职责必须在 M03 前完成。
- M03 后不再开启独立顾衡线；M04—M10 只沿沈逾—R-07 共同主线推进。
- M05 是权限边界：此后所有 R-07 信息只能来自实际屏幕文字、沈逾可获得的系统/行动反馈和外部可回看证据。
- M07 不可被合并为一句“情报得到证实”；它承担防止外援和全知信息替代主角选择的前提功能。
