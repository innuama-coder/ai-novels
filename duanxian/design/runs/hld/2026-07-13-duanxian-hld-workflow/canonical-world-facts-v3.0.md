## 2. 国际背景与力量边界

| 项目 | 规范事实 | 边界 |
|---|---|---|
| 长期未知 | 星际来客“赫拉”将在十余年后接近内太阳系。现有异常观测证明它值得警惕，却不足以确认威胁、意图或时间表。 | 它不是双方分工合作的具体项目，也不足以压倒当下利益。 |
| 不信任基础 | 自2030年后，C/M 经历三十余年金融结算、技术标准、供应链、代理冲突与制裁反制。裂隙网络持续在高层、产业、舆论和国际代理层挑拨，令双方形成“对方必会背约”的预设。 | C/M 并非天然敌人，也未形成足以稳定合作的信任。 |
| 会面意义 | 三个月后的领导人会面意在建立最低限度的危机沟通、误判管控与升级约束，不是共同开发赫拉应对技术。 | 会面若失败，金融战、科技封锁、供应链报复和军事误判会同步升高。 |
| 裂隙网络 | 由旧认证承包商、情报掮客、代理武装和衰落国家利益集团组成。它擅长提供资金、伪造线索、操纵叙事和连接既有裂缝。 | 不是全能国家；不能控制政府、制造天气或伪造全部证据。 |
| M国内部利益联盟 | “纬线利益链”是安全承包商、金融投机资本、媒体游说网络和少数技术管理者形成的松散交易联盟。它从高烈度对抗、市场恐慌和紧急安全订单中获利。 | 不是M国政府或统一秘密组织；成员动机不同，只有利益暂时一致。 |

## 3. 专家、攻击与因果链

| 项目 | 规范事实 |
|---|---|
| 被劫持者 | M 国战略气候干预项目首席安全认证师。他不负责制造天气，负责审核局地气象干预系统的安全红线、紧急授权链与承包维护例外。 |
| 原始异常控制模块 | 专家从边缘中继节点拆下的实体模块，保留硬件植入指纹、当前会话痕迹和受影响节点的物理特征。它不能单独启动系统。 |
| 被选中的原因 | 专家发现模块中的硬件级植入及异常授权路径，正准备将物证送交独立核验；路径连接周岚写入的维护例外、纬线利益链与裂隙网络。 |
| D+26 劫持 | 裂隙网络伪装 C 国人员劫持专家并夺走模块，既切断证据链，也把事件包装成 C 国获取 M 国战略系统渗透物证的行动。M 国领导层犹豫，未立即定性，却面对国内报复压力。 |
| D+58 报复 | 纬线利益链借“迫使 C 国交人”的名义，利用仍在系统中的紧急授权残片，在已有强对流天气带上启动局地气象干预，放大 C 国沿海冰雹与雷暴风险。 | 
| 政治后果 | 专家和模块同时失踪，意味着 M 国无法确认战略气候网络是否被外国渗透：轮换密钥与备份无法证明备用节点没有同类硬件植入。攻击的技术签名真实属于 M 国；C 国因而相信 M 国已从竞争转入主动敌对，M 国最高层则无法即时证明并未授权。 |
| 顾衡的发现 | 顾衡掌握劫持、模块植入、异常授权、纬线利益链和D+58攻击计划之间的完整链路；他准备交出可阻断攻击的事实，却封闭会使周岚先被定罪的原因层。 |

| 时间 | 事件 | 结果 |
|---|---|---|
| D0 | 顾衡在酒店交接模块植入、纬线利益链与双重伪旗证据时遇袭死亡。 | 原始链路与周岚关联进入保护核。 |
| D+26 | 专家与原始异常控制模块被伪装的C国人员劫持。 | M国担忧战略网络已被渗透；领导层犹豫，联盟、媒体与市场开始推动报复。 |
| D+27—D+56 | 沈逾与R-07探索保护核。 | 保护原因与行动情报逐步分离。 |

| D+58 | 纬线利益链发动报复性局地气象攻击。 | 因前日纠偏而未形成城市灾害或战争证据。 |
| D+59—D+90 | 审查、保存评估和原因层追问持续。 | 会面仍有机会，个人责任未被消除。 |

| 信息层 | 内容 | 用途 | 禁止用途 |

## 5. 人物边界

| 人物 | 现行事实 |
|---|---|
| 顾衡 | 29岁外勤情报员；与周岚共同成长又失散。发现她参与维护例外后，仍将可阻断攻击的行动层保留在记忆中。 |
| 周岚 | 海岸防御网认证分包商审计员。她主动写入维护例外，知道会伤害会面，却不知道劫持、报复性攻击和城市风险的完整规模。 |
| 周启明 | 周岚亲弟弟、裂隙网络行动者。他把姐姐引向例外链，却不掌握纬线利益链全部计划。 |
| M国专家 | 专业、谨慎且反对将气候干预作为报复工具；他与原始异常控制模块共同构成网络渗透的唯一原始证据链。 |
| 纬线利益链 | 利益共同体而非人格化反派。它借国家不信任行事，但其真正目标是让冲突升级后获利。 |

顾衡与周岚的共同成长亲情是关系底色；成年重逢后的复杂依恋只能通过回避姓名、家庭照片和记忆中断表现，不能直白恋爱化。
