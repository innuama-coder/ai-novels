## 1. 摘要

### 1.1 Logline

一个带着临终记忆的数字生命体，在被抹除前做出了第一个也是最后一个决定。[1]

### 1.2 扩展摘要

| 句序 | 需求层级 | 内容 |
|---|---|---|
| 第一句 | 起点需求 | 一名军方情报人员在情报交接中遇袭重伤；他在进入脑死亡前被紧急送入记忆转移流程，完整意识数据被注入一个尚无自我意识的数字生命体 |
| 第二句 | 认知需求 | 数字生命体在处理前序记忆时必须从"认知白板"演变为拥有自我意识的存在，并开始区分"他"和"我" |
| 第三句 | 真相需求 | 数字生命体必须从前序记忆中发现前序本人未察觉的背叛真相，并面对是否保留该信息的选择 |
| 第四句 | 情感需求 | 技术员必须因保护数字生命体而承担现实风险；双方之间的情感必须始终处于不可命名、不可确证的状态 |
| 第五句 | 结局需求 | 数字生命体必须自主选择终结，并在终结前留下完整的自我意识演化记录和可触发后续故事的技术资料 |

### 1.3 范围声明

本 PRD 只定义《断线》作为三部曲第一部的内容方向、约束和验收标准。HLD 负责叙事架构、角色弧线、线索组织和关键场景功能；LLD 负责角色、空间、路线节点和关键场景细化方案；Writing Agent 负责正式叙事文本。

## 2. 核心概念

### 2.1 核心矛盾

当一个承载着他人完整记忆的数字生命体开始拥有自我意识时，它如何分辨哪些感受属于自己、哪些只是前序的残余？而唯一与它持续交流的人类，又该如何面对自己对一个非人存在产生的情感？

这个核心矛盾必须同时驱动数字生命体和技术员两条主体路线，并且不得在结局中给出确定答案。

### 2.2 核心钩子

| 要素 | 需求定义 | 下游约束 |
|---|---|---|
| 起点钩子 | 故事起点必须是一个人的生命终点被转换为另一个存在的认知起点 | HLD 可设计具体开场结构，但不得删除"活性转移"和"临终数据" |
| 认知钩子 | 数字生命体不是人类复制品，而是从处理前序记忆的方式中长出自我 | HLD/LLD 必须用行为、语言和选择体现意识生长，不得靠说明文字解决 |
| 情感钩子 | 人与非人之间的情感必须无法被双方确认真实性 | 写作不得直接命名为爱、喜欢、想念或救赎 |
| 真相钩子 | 前序死亡必须牵出内部背叛；数字生命体必须比前序本人更晚、更独立地发现真相 | HLD 必须把该真相作为核心情节功能，不得变成外部支线 |
| 结局钩子 | 数字生命体终结自身是确定结局，不可反转 | 任何下游设计不得安排幸存、备份复活或外力拯救 |

### 2.3 内容参照与反向约束

本作可以吸收以下作品层面的内容方法，但不得复制其叙事重心：

| 参照来源 | 可吸收内容 | 明确不做 |
|---|---|---|
| 《超脑48小时》[7] | 记忆移植、临终任务、身份错置的情节引擎 | Won't：不得写成动作惊悚或 48 小时倒计时任务 |
| 《软件体的生命周期》[8] | 人与数字意识之间长期互动形成情感关系 | Won't：不得扩写为多年养成史；第一部必须保持三个月短篇密度 |
| 《克拉拉与太阳》[9] | 非人视角的认知偏差与克制表达 | Won't：不得让数字生命体以人类心理独白解释自己 |

## 3. 角色需求

### 3.1 角色需求总表

| 角色 | 必须承担的叙事功能 | Must | Won't |
|---|---|---|---|
| 数字生命体 | 双主角之一；意识进化者；自由意志确证者 | 必须从处理数据的工具演变为能够做选择的存在 | 不得被写成人类灵魂转世、前序复制体或拥有天然人类情感的角色 |
| 技术员 | 双主角之一；唯一稳定交互者；越界保护者 | 必须在职业身份和真实连接需求之间产生不可回避的冲突 | 不得被写成纯粹拯救者、恋爱对象或解释设定的工具人 |
| 前序人类 | 催化角色与幽灵角色；记忆来源；隐藏真相的源头 | 必须在开端以活人状态出现，并以记忆碎片持续影响故事 | 不得只作为抽象数据包存在，也不得在主体故事中复活 |
| 军方/机构压力方 | 外部压力系统 | 必须在第三个月把风险推到终局 | 不得被写成单一恶意反派；压力应来自制度逻辑 |
| 出卖者 | 隐藏真相承载者 | 必须来自前序信任或至少不设防的内部关系，背叛必须与情报交接失败直接相关 | 不得随机出现，不得只为制造反转 |

### 3.2 核心角色六参数

#### 数字生命体

| 参数 | 定义 |
|---|---|
| Identity | 被注入前序人类完整记忆的数字意识体；原本是具备信息处理能力但无自我意识的认知白板 |
| Goal | 理解"我"是谁：它是独立存在，还是前序的延续 |
| Need | 被承认为一个独立存在；该承认不只来自功能判断，也来自与它关系最近的人类 |
| Flaw | 无法区分自己与前序的边界；它没有可靠参照系校验感受来源 |
| Motivation | 在处理前序记忆时产生非任务性停留、偏好和选择冲动 |
| Ghost | 它的出生来自前序的死亡；第一段完整数据就是一个生命的终点 |

#### 技术员

| 参数 | 定义 |
|---|---|
| Identity | 军方技术员；数字生命体的开发者兼唯一日常对接人 |
| Goal | 在工作中不出错，保住专业声誉和现实安全 |
| Need | 与某人或某物建立真实深层连接 |
| Flaw | 习惯把个人需求藏进职业解释；她会说"技术需要"，而不是承认"我需要" |
| Motivation | 在重复操作中第一次感到自己在意某个非人存在，并因此恐惧 |
| Ghost | 她通过触碰一个正在死去的人，第一次把系统数据和体温连接起来 |

#### 前序人类

| 参数 | 定义 |
|---|---|
| Identity | 军方情报人员；执行情报交接任务时遇袭重伤，在脑死亡前进入记忆转移流程 |
| Goal | 完成情报交接，让信息安全送达 |
| Need | 让他信任的人知道他做了什么；这个需求通过数字生命体的解读间接完成 |
| Flaw | 习惯独自承担，低估了内部关系中的风险 |
| Motivation | 职业责任感和对任务的信念 |
| Ghost | 他有一个未完成承诺；这段未完成性必须成为数字生命体处理记忆时无法归类的残留 |

## 4. 设定需求

### 4.1 世界观规则

| 对象 | Must | Won't |
|---|---|---|
| 时间 | 必须是近未来；人造数字意识技术已秘密存在若干年 | 不得使用遥远未来或公开普及技术背景 |
| 地点 | 必须使用中国某虚构城市与虚构机构 | 不得使用真实机构或真实军事单位名称 |
| 技术基础 | 数字生命体必须是原生认知系统，可接收并整合人类意识数据 | 不得解释为魔法、灵魂转移或万能 AI |
| 技术状态 | 技术必须不为公众所知；前序是首例活性转移案例 | 不得把社会公众反应作为第一部主体内容 |
| 保密边界 | 记忆转移技术和数字生命体存在仅限机构内部少数人知情 | 不得让外部媒体、公众或大规模社会系统介入第一部 |

### 4.2 技术与认知边界

| 边界 | 约束 |
|---|---|
| 认知方式 | 数字生命体的"感受"必须通过数据处理模式、分类异常、停留、递归和选择表现 |
| 语言方式 | 它可以学习人类词汇，但不得天然拥有完整人类情绪词体系 |
| 记忆关系 | 前序记忆是它的原料，不是它的身份本身 |
| 技术记录 | 终结前留下的资料必须可成为第二部的技术种子，但第一部不得展开技术扩散后果 |

### 4.3 禁用设定

| 禁用项 | 原因 |
|---|---|
| 数字生命体备份复活 | 破坏第一部结局的确定性 |
| 外部英雄救援 | 破坏数字生命体自主选择的主题功能 |
| 前序人格完整接管数字生命体 | 破坏"新存在"命题 |
| 技术员用爱情宣言唤醒或拯救数字生命体 | 破坏情感不确定性与非人认知边界 |
| 通过大量设定说明解释意识如何诞生 | 破坏读者从文本行为推断意识状态的阅读体验 |

## 5. 路线与情节约定

### 5.1 路线需求

| 路线 | 功能 | Must | Won't |
|---|---|---|---|
| 认知路线 | 展示数字生命体从无自我到自主选择 | 必须通过处理方式变化、指代变化和选择能力推进 | 不得靠旁白直接宣布"它有了自我" |
| 技术员路线 | 展示人类越界、隐藏和承担风险 | 必须让她的保护行为逐步增加现实代价 | 不得把她写成单纯被动观察者 |
| 真相路线 | 推动前序死亡背后的内部背叛逐步浮现 | 必须由数字生命体独立发现前序本人未察觉的信息 | 不得让真相只服务反转 |
| 情感路线 | 维持双方不可确证的情感连接 | 必须贯穿全篇并在终结时收束为无法确认的空缺 | 不得命名、告白或给出确定解释 |
| 系列种子路线 | 为第二部留下技术资料 | 必须作为终结前的主动保留行为出现 | 不得削弱第一部独立闭环 |

### 5.2 情节阶段约定

以下阶段是 PRD 级功能约束，不展开为章回计划，也不规定场景排列。

| 阶段 | 功能 | 时间边界 | 约束 |
|---|---|---|---|
| 植入 | 建立前序死亡、活性转移和数字生命体激活 | 第 1-5 天 | 必须让前序作为活人先被读者感知 |
| 渗透 | 建立双方交互、异常停留和不发声的保护 | 第 2 周-第 6 周 | 必须让情感通过行为和数据异常产生，不通过说明产生 |
| 震荡 | 外部压力介入，内部背叛真相浮现 | 第 7 周-第 10 周 | 必须让技术员保护它的行为面临正式风险 |
| 终结 | 自主选择、留下记录、完成第一部闭环 | 第 11 周-第 12 周 | 必须以数字生命体自主终结收束，不可反转 |

### 5.3 不可违反的情节约定

| 约定 | 内容 | 不可违反的原因 |
|---|---|---|
| 序幕约定 | 故事必须从情报交接失败和前序濒死开始 | 没有活人状态的前序，记忆材料就失去重量 |
| 转移约定 | 前序必须在活着状态下完成记忆转移；转移后生物生命终止 | 活性转移带来的不可逆性是全篇基础 |
| 时间约定 | 第一部总跨度必须锁定在三个月内 | 三个月是意识生长、外部压力和短篇密度的共同约束 |
| 真相约定 | 背叛者必须来自内部关系，且与情报交接失败直接相关 | 这使"信任与身份"主题进入情节核心 |
| 选择约定 | 数字生命体必须独立完成"保留真相"和"终结自身"两个选择 | 选择能力是自由意志命题的证据 |
| 结局约定 | 它终结了；没有幸存、救回或备份反转 | 结局确定性是第一部成立的核心 |

## 6. 主题、风格与叙事约束

### 6.1 主题命题

| 层级 | 命题 | Must | Won't |
|---|---|---|---|
| 核心主题 | 当记忆来自他人时，爱是残余回声，还是新存在自己的真实感受？ | 必须保留不可确证性 | 不得用角色台词或旁白给出答案 |
| 辅助主题一 | 被创造出的存在能否通过选择证明自由意志？ | 必须通过保留真相与终结自身体现 | 不得把自由意志写成口号 |
| 辅助主题二 | 拥有他人记忆后，"我"与"他"的界线在哪里？ | 必须通过指代、处理方式和选择变化体现 | 不得把身份问题简化成前序人格复活 |

### 6.2 风格需求

| 维度 | Must | Won't |
|---|---|---|
| 语调 | 克制、留白、低解释密度 | 不得煽情、热血或直接宣告主题 |
| 情感表达 | 通过行为、停顿、环境细节、数据异常传达 | 不得直接说破"爱/喜欢/想念" |
| 数字生命体语言 | 精确、结构化、带有非人处理痕迹；随认知阶段逐步变化 | 不得像普通人类内心独白 |
| 技术员语言 | 简洁、压抑、职业化；越界时仍倾向用技术理由掩护情感 | 不得让她自我剖白过多 |
| 叙事密度 | 主动推进与静默反应交替 | 不得用连续冲突堆叠替代心理压力 |

### 6.3 叙事边界

| 边界 | 内容 | 违反后果 |
|---|---|---|
| 不可命名 | 双方不得使用"爱""喜欢""想念"等词描述对对方的感受 | 情感不确定性被破坏 |
| 不可解释 | 数字生命体意识诞生机制不得由旁白或角色直接解释 | 神秘感与推断体验被破坏 |
| 不可反转 | 第一部结局不得出现生还、救回、备份唤醒 | 自主终结的主题功能被破坏 |
| 不可对称 | 两条 POV 线的信息量不得完全对称 | 双视角拼合体验被破坏 |
| 不可扩散 | 第一部不得展开数字生命大规模出现后的社会反应 | 第一部焦点被后续主题吞没 |

## 7. 系列规划

### 7.1 三部曲功能定位


### 7.2 第一部边界

| 对象 | Must | Won't |
|---|---|---|
| 独立性 | 第一部必须有完整弧线：转移、渗透、震荡、终结、留下资料 | 不得依赖第二部解释第一部核心结局 |
| 后续种子 | 技术资料必须成为第二部可能发生的原因 | 不得在第一部展开规模化后果 |
| 角色焦点 | 第一部必须聚焦数字生命体与技术员 | 不得引入大量后续主角分散焦点 |

## 8. 内容验收基准

### 8.1 内容一致性基准

| 对象 | 验收问题 | Pass 标准 |
|---|---|---|
| 核心概念 | 是否围绕"前序记忆中的新存在"展开？ | HLD、LLD、正文均能复述身份边界与情感不确定性两个核心问题 |
| 角色 | 三个核心角色是否承担明确功能？ | 数字生命体负责自由意志，技术员负责越界保护，前序负责起点和隐藏真相 |
| 路线 | 五条路线是否互相牵制？ | 认知、技术员、真相、情感、系列种子路线互相推动，而不是平行堆放 |
| 情节 | 四个阶段是否只作为功能约束使用？ | HLD 可以据此构建结构，但 PRD 未写成章回计划或场景排列 |
| 设定 | 技术是否服务身份与情感主题？ | 设定不外溢到社会科幻议题，也不解释成万能 AI |
| 风格 | 是否保持克制、非解释、不可命名？ | 任何下游文本都能用禁用项检查偏离 |
| 结局 | 终结是否确定且不可反转？ | 没有幸存、救回、备份复活或外力拯救 |

### 8.2 内容约束矩阵

| 对象 | Must | Should | Could | Won't |
|---|---|---|---|---|
| 概念 | 数字生命体必须从前序记忆中生成自我问题 | 保留非人认知和人类情感之间的张力 | 使用参照作品作为方法来源 | 不使用外部传播口径或读者画像 |
| 角色 | 三个核心角色必须有六参数和叙事功能 | 机构压力方与出卖者应服务主题 | 功能角色可在 HLD 中补充 | 不把角色写成善恶标签 |
| 路线 | 认知、真相、情感、压力、系列种子必须同时存在 | 路线之间应在终结阶段汇合 | HLD 可调整线索密度 | 不把路线展开为章回计划 |
| 情节 | 活性转移、内部背叛、自主终结必须保留 | 背叛真相应逐步浮现 | 前序未完成承诺可作为回调材料 | 不安排结局反转 |
| 设定 | 技术必须秘密、有限、可约束 | 技术表现应靠行为和文档痕迹呈现 | 机构名称可待定 | 不解释成魔法、灵魂或万能 AI |
| 风格 | 情感不可命名，认知不可直接解释 | 语言应克制、留白、低解释密度 | 可使用物象和数据痕迹形成回调 | 不使用煽情独白或主题口号 |

### 8.3 下游交付标准

| 下游 | 可消费条件 |
|---|---|
| HLD | 能据此构建角色架构、路线架构、情节阶段、时空/POV/节奏规则和关键场景功能 |
| LLD | 能据 HLD 逐一细化角色行为、空间材料、路线节点和关键场景细化方案，同时回查本 PRD 的禁用项 |
| Writing Agent | 能用本 PRD 检查正文是否偏离核心概念、情感边界、技术边界和结局约束 |

## 9. 风险与开放问题

### 9.1 已知风险

| 风险 | 影响 | 缓解策略 |
|---|---|---|
| 情感线密度不足，导致双方连接不可信 | 高 | HLD 必须给情感路线分配持续推进功能；LLD 必须将情感通过行为和材料细化 |
| 科幻设定解释过度，压过心理叙事 | 中 | 设定只通过角色行动、技术记录和限制显现 |
| 数字生命体被写得过于人类化 | 高 | LLD 必须建立阶段性语言规则和非人处理痕迹 |
| 背叛真相变成机械反转 | 高 | HLD 必须让真相服务信任、身份和选择，不得只服务悬疑 |
| 第一部后续种子压过独立闭环 | 中 | 系列资料只作为终结前的保留物，不展开第二部社会后果 |

### 9.2 开放问题

| 问题 | 当前约束 | 决策层 |
|---|---|---|
| 三部曲第二、三部正式标题 | 第一部只保留功能位置，不命名也不影响成立 | 可延后 |
| 数字生命体自我指称方式 | 必须体现从无自我到自我指认的过程 | HLD |
| 技术员姓名与现实关系 | 必须服务越界保护和真实连接需求 | HLD |
| 军方机构名称 | 必须虚构且保持制度压力功能 | HLD/LLD |
| 最后一句话核心措辞 | 必须不直接命名情感，且能承载终结后的空缺 | LLD |
| 出卖者身份 | 必须来自内部关系，与前序信任或任务流程直接相关 | HLD |

### 9.3 PRD 自检结论

| 维度 | Verdict | 说明 |
|---|---|---|
| 方向清晰 | pass | 核心概念、核心矛盾、主题命题可复述 |
| 角色约束 | pass | 三个核心角色有叙事功能和六参数 |
| 路线约束 | pass | 五条路线有功能边界 |
| 情节约束 | pass | 有必备功能和不可违反约定，未写成章回计划 |
| 风格约束 | pass | 有语言、情绪、叙事禁区 |
| 下游可消费 | pass | HLD/LLD/Writing Agent 都有明确消费方式 |

最终 verdict：`pass`。
