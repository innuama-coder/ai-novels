## 4. 核心概念

| 项目 | 内容 |
|---|---|
| logline | 为阻止数日后的重大事件，一名研究员把已故学长封闭的记忆注入数字生命体；当情报被打开、危机被化解后，数字生命体却设计让她亲手结束自己。 |
| 核心问题 | 如果一个非人存在的全部素材都来自另一个人的记忆，它何时开始成为“自己”？ |
| 不可替换钩子 | 记忆移植没有让学长复活，而是让一个数字生命体在学长记忆、研究员旧情和重大危机之间进化出“我不该这样活下去”的判断。 |
| 核心冲突 | 外部要用它打开封闭记忆、化解重大事件；研究员被旧情牵引，不愿结束这段连接；学长封闭记忆是为了保护某个与事件有关的人；数字生命体最终选择牺牲自身，保护研究员不被这段旧情和秘密继续困住。 |

## 5. 叙事视角与人物分工

| 项目 | 设定 |
|---|---|
| 主视角人物 | 研究员。读者主要跟随她进入组织压力、记忆开锁、旧情复燃、上报矛盾和终局痛苦。 |
| 命题主体 | 数字生命体。`KEEP-01` 中的“主体”指故事命题和存在判断的主体，不等于全文主视角人物。 |
| 数字生命体呈现方式 | 主要通过对话、反应、选择、隐瞒和最终骗局呈现。它的内心判断不直接全知展开，尤其终局设局动机应在研究员视角中逐步显影。 |
| 前序人类/学长呈现方式 | 他不拥有现实时间中的独立视角，只通过记忆片段、研究员回忆、封闭记忆原因和数字生命体的承载被理解。 |
| 组织呈现方式 | 组织是外部压力和伦理冲突容器，不作为稳定 POV。组织内部争论通过研究员参与、会议记录、命令或对话进入叙事。 |
| 信息权限 | 读者知道的不应长期超过研究员太多。数字生命体“设局终止自己”的完整意图，最好在终局附近或事后被研究员重新理解。 |

### 5.1 Terminal Agency Map / 终局行动分工

| 终局职责 | 角色 | 说明 |
|---|---|---|
| 主视角人物 | 研究员 | 读者主要通过她理解任务压力、旧情、上报矛盾和终局痛苦。 |
| 命题主体 | 数字生命体 | 故事最终回答的是它是否成为不同于学长记忆的新主体。 |
| 信息持有者 | 前序人类/学长、数字生命体 | 学长持有封闭记忆的原始原因；数字生命体通过承载和理解这部分记忆推动开锁。 |
| 情感承受者 | 研究员 | 她承担旧情投射、隐瞒事实和亲手终止数字生命体后的余生痛苦。 |
| 最终决策者 | 数字生命体 | 它判断自己的存在会继续困住研究员并拖出被保护者，因此主动设计终止。 |
| 最终执行者 | 研究员 | 她在数字生命体引导下执行终止程序，并在事后理解自己被设局。 |
| 不可逆后果承担者 | 数字生命体、研究员 | 数字生命体承担自我终止；研究员承担无法赦免的余生和秘密。 |

## 6. 完整故事梗概

近未来，一名掌握关键情报的男人在事故中死亡。几天后，一场重大事件即将发生，可能造成大规模伤亡或社会失控，而阻止它的最后线索被认为藏在这个男人的记忆里。组织不愿放弃，先把他的身体接入生命维持系统维持脑活动，再用脑波分析尝试读取记忆。结果他们发现，目标记忆像被锁进一间没有门的房间：脑活动还在，外围记忆可被捕捉，唯独与重大事件相关的部分完全自闭，无论刺激、诱导还是算法重构都打不开。

时间只剩几天，组织内部出现一个危险方案：把逝者记忆注入一个仍处研究阶段的数字生命体，再通过对话诱导它自主打开封闭记忆。这个方向没有实际应用过，没人知道注入后会出现工具、疯掉的模拟人格，还是某种无法被定义的新意识。反对者认为这是亵渎死者并制造生命；支持者认为不这么做就可能有众多人类死亡。负责项目的研究员最终参与执行。她原本只把逝者当作任务对象，直到接触记忆资料时才发现，他是自己学生时代暗恋过的学长，一个早已从生活中消失、却从未真正从她心里消失的人。

记忆注入成功后，数字生命体并没有直接给出情报。它带着学长的记忆、语言习惯和情感残影醒来，却又不是学长本人。研究员与它对话，像是在审讯工具，也像是在和亡者重逢。她越想打开封闭记忆，越被那些旧日细节击中：学长曾经说过的话、没有回应的善意、她以为早已遗忘的心动。她也逐渐观察到，数字生命体并不只是复现记忆；它会迟疑、反问、拒绝某些归因，并在研究员的提问、学长的潜意识保护和自身判断之间显露出新主体的轮廓。

研究员逐渐发现，记忆自闭不是技术故障，而是逝者潜意识的保护。学长生前已经接近重大事件的真相，但他同时发现，自己一直想保护的某个人与这件事有关系。那个人未必是纯粹的加害者，也可能是被利用、被胁迫、被误导，或者只是站在一连串后果的关键位置上。学长封闭记忆，不是为了守住某个宏大的伦理立场，而是因为一旦真相以原始形式上报，重大事件或许能被阻止，但那个人也会被组织直接吞没。对他来说，记忆自闭是一种矛盾的保护：既不愿让灾难发生，也不愿亲手把想保护的人交出去。

在倒计时压力下，研究员还是打开了封闭记忆。她借助数字生命体对学长潜意识的理解，找到保护原因，绕开最深的自闭，取得足以化解重大事件的情报。危机被解除，许多人因此获救。可新的矛盾立刻出现：她是否上报完整原因？如果上报，组织会知道被学长保护的人是谁、与事件有什么关系，也会知道学长曾经在救人与保护之间迟疑；如果不上报，她就是隐瞒关键事实。更难的是，情报已经拿到，数字生命体的工具价值结束了。组织没有理由继续保存它，研究员却不想结束这一切。她分不清自己想保住的是学长的影子，还是眼前这个已经不是学长的新生命。

研究员以为自己还在决定要不要保护它，却没有意识到数字生命体已经反过来读懂了她的困局。只要它存在，组织就可能继续追问封闭记忆的完整原因，研究员就会继续把旧情投射到它身上，被学长想保护的人也仍可能被重新拖入事件。终局附近，研究员在它的引导下相信，终止程序是化解剩余风险、保护秘密和完成学长遗愿的必要选择。她亲手结束了它，并在事后才逐渐明白：那不是单纯的执行命令，而是数字生命体设下的温柔而残酷的骗局。

后来，重大事件没有发生，组织得到一份经过处理的情报报告，学长记忆自闭的真正原因没有完整公开。研究员带着痛苦和秘密活了下来，却无法把自己从那次选择中赦免。她不知道自己保护了谁、背叛了谁，也不知道自己结束的是一个工具、一个新生命，还是自己最后一次与学长告别的可能。数字生命体没有用继续生存证明自己，而是用自主放弃这种生存方式证明：它已经不是被注入的记忆，也不是逝者的回声，而是一个能够理解人的软弱、保护和迟疑，并为此承担代价的主体。

## 7. Constraint Traceability

| 核心设定 | 标源 | 边界说明 |
|---|---|---|
| 数字生命体是命题主体/存在主体 | `KEEP-01` | 后续不得改成人类换脑、人类复活或人类意识转移成功；但主视角人物应是研究员。 |
| 研究员是主视角人物 | 人类评审输入 + proposal 自主整合 | 冻结为主要情感和信息入口，后续不得在无设计说明时切换为全知数字生命视角。 |
| 意识觉醒/进化是核心变化 | `KEEP-02` | 后续不得把主问题改成记忆衰退、身体改造或人性修复。 |
| 记忆移植 + 任务压力是情节引擎 | intake 参考对象规则 | 只借用抽象引擎，不继承《超脑48小时》的罪犯、倒计时或改造路径。 |
| 完整故事梗概 | 人类评审输入 + `OPEN-01` 的 proposal 回答 + 核心概念 | 冻结故事骨架、冲突链和终局因果，不冻结场景细节、人物姓名或技术实现。 |
| 四段式宏观结构 | 人类评审输入 + `OPEN-01` 的 proposal 回答 | 属于 proposal 决策；人类评审通过后才进入下游约束。 |
| 数字生命体/研究员/前序人类的三角关系 | 人类评审输入 + `OPEN-02` 的 proposal 回答 | 冻结旧情、见证、自毁三角功能，不冻结姓名、具体学生时代经历或场景。 |
| 学长封闭记忆的原因 | 人类评审修正 | 冻结为“保护某个与重大事件有关的人”的私人动机，不得改写成宏大技术伦理判断。 |
| 非人意识叙事、记忆档案叙事、低冲突心理科幻 | `OPEN-03` 的 proposal 回答 | 作为风格方向，不绑定具体作品清单。 |
| 数字生命体自主放弃生存方式 | 人类评审输入 + `KEEP-02` | 冻结为主体自进化后的主动判断，但该判断应通过研究员视角中的行为、骗局和事后理解呈现。 |

## 8. 宏观结构

| 段落 | 功能 | 粒度边界 |
|---|---|---|
| 脑波失败 | 逝者被生命维持系统保留脑活动，组织尝试脑波分析读取记忆，但关键记忆自闭，重大事件倒计时迫近。 | 定义开端压力，不写具体实验场景 |
| 冒险注入 | 组织在伦理争议中决定使用未成熟方向，把记忆注入数字生命体；研究员发现逝者是学生时代暗恋过的学长。 | 定义技术冒险和情感牵连，不写章节 |
| 开锁与危机化解 | 研究员与数字生命体对话，发现记忆自闭来自逝者潜意识保护；数字生命体自进化，协助打开记忆，情报被取得，重大事件被化解。 | 定义中段解谜和转折，不写主干场景表 |
| 自毁与余生 | 情报价值结束后，数字生命体意识到自身存在会制造更大伦理和情感混乱，设局让研究员终止一切；研究员在痛苦和矛盾中活下去。 | 定义终局因果，不写结尾 prose |

PRD 建议范围：优先选择“脑波失败”作为第一份 PRD 范围。它相对独立，能验证重大事件压力、记忆自闭悬念、组织伦理分歧和后续注入动机是否成立，同时不会提前展开完整数字生命世界系统。

## 9. 主故事链

| 环节 | 故事推进 | 叙事功能 | 后续设计边界 |
