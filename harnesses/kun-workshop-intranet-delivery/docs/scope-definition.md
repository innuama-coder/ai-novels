# Scope Definition

## Mission

建设一支可复用的 AI 团队，以“可交互原型 + 产品说明文档”为入口，完成鲲工坊
内网系统的需求基线、设计、开发、测试以及授权的预发布部署与验收。

## Non-Goals

- 不替代业务方对需求、数据分级、上线窗口或预发布变更的批准。
- 不直接发布生产环境，不执行生产数据迁移，也不自动申请基础设施权限。
- 不承诺某一技术栈；架构师必须根据现有仓库、环境与约束提出可审计选择。
- 不将未经确认的原型行为、接口、权限或验收标准当作事实。

## Target Runtimes

Codex 是完整适配的首选运行时。Claude、Gemini、OpenClaw 和 Hermas 可运行核心
文档与门禁，但多代理调度、工作区隔离、环境部署与证据采集可能需要运行时人工桥接；
具体限制见各 adapter 的 `mapping.md`。

## Assumptions

调用方提供可访问的原型、产品文档、目标代码仓库、预发布环境接入方式及负责人。
“上线预发布”指在已批准的变更窗口内由拥有环境权限的发布工程师执行；没有这些
条件时团队可以完成发布候选和部署计划，但最终状态只能是 `partial` 或 `blocked`。
